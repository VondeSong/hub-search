# 选完技能文件夹后，继续检查和保存（#48）

日期：2026-11-15。使用日常 Windows Hub 和真实资料库，没有另建测试资料库。

## 用户原来遇到什么

从「技能 → 管理技能 → 检查方法文件夹」选择正确目录后，系统选目录窗口关闭，技能菜单也跟着消失。用户看不到检查清单，更没有完成保存。此前两次实际尝试均未生成固定版本，失败记录继续保留。

## 原因和修复

系统选目录窗口暂时接管焦点，原来的菜单把这当作用户离开 Hub，于是自动关闭。外层菜单关闭后会移除技能管理页面；该页面收到选目录结果时已经不在，因此按原有保护规则放弃结果。

现在选目录期间保留菜单，选好、取消或报错后回到原页面，并恢复焦点。平常点击菜单外面、切到其他程序和按 Escape 仍能正常关闭。导出技能时使用的选目录窗口也沿用这项保护。没有放宽文件检查、保存确认或权限。

源码依据：`useAgentPopover.ts` 的窗口失焦与外部焦点关闭逻辑；`AgentInvestigation.tsx` 的菜单关闭后条件卸载；`AgentSkillPackages.tsx` 的存活检查及原生选目录调用。它们确认了一条能复现现场现象的失败路径，不把前两次窗口操作中的所有异常归为同一原因。
