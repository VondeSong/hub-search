# 标签页液态玻璃视觉优化

## 设计判断

- 产品蓝只承担导航、选中、焦点和操作反馈；各标签原有颜色继续承担内容分类与识别。
- 液态玻璃只应用于侧栏、分段控件、搜索框、标签页切换和筛选控件。
- 标签属性、标签卡片和正文保持清晰的普通白色内容表面，避免多层透明材质叠加。

## 调整

- 标签侧栏使用与全局导航一致的冷灰蓝材质与系统字体层级。
- “固定 / 层级 / 分组”改为半透明分段控件，选中态统一为 `#0a84ff`。
- 搜索框、添加分组按钮、固定标签区域采用轻量玻璃材质与清晰焦点环。
- “全部标签 / 全局健康检查”和具体标签的选中态统一为软件现有蓝色体系。
- 标签属性卡改为清晰白色内容卡；“内容 / 内容补标 / 标签关系”改为玻璃分段切换。
- 标签概览筛选、布局切换采用玻璃控制层，标签卡保持白底并优化悬停与按压反馈。
- 增加减少动态效果、减少透明度和高对比度回退。

## 验证

- 88 个测试文件、320 项前端测试全部通过。
- TypeScript 与 Vite 生产构建通过。
- 1280×720：标签侧栏 240px，主标签页切换完整，无页面横向溢出。
- 760×760：标签侧栏默认收起，展开抽屉为 260px；主内容和标签页切换无横向溢出。
- 分类切换和工作区标签切换均保持正确的可访问状态与蓝色选中反馈。
- 未修改真实标签、真实笔记或资料库数据。
