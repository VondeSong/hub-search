# 工作区交互优化 · 第一阶段

## 已实施

- 标准、紧凑、专注三种侧栏布局，保存布局选择；专注模式仍保留全局导航。
- 紧凑模式下闪卡直接使用牌组侧栏，去除重复的 Hub 上下文侧栏；保留拖动、键盘调宽和恢复默认。
- 统一顶部模块名称与资料库范围选择。任务按资料库 ID 真实过滤，来源数量与当前范围一致。
- 闪卡明确标识独立牌库，禁用无效的来源切换；不改变原有学习数据归属。
- 任务、闪卡显示已生效筛选，可单项移除或统一清除；空结果提供恢复入口。
- 内容密度收进视图配置，低频任务同步检查收进更多工具。
- 本次运行期间保留模块搜索词、任务选择、任务滚动位置、闪卡牌组/搜索/类型/状态/排序和主区滚动位置。已有显示偏好继续使用原有保存机制。
- 补齐闪卡 Ctrl+K 搜索快捷键。
- 沿用现有中性配色、蓝色强调、可见键盘焦点和减弱动态效果规则，不增加大面积玻璃与装饰渐变。

## 验证

- 生产前端构建通过。
- 相关组件、会话恢复和任务范围测试 16 项通过。
- 浏览器示例数据验证：三种布局切换、专注后保留全局导航、牌组与搜索切出再恢复、清除筛选、键盘调整牌组宽度。
- 全量检查：最初运行 297 项通过、7 项失败；随后新增的任务范围测试也通过。失败集中在未改动的标签测试：TagGovernanceInbox.pagination 的模型列表模拟返回缺失，以及 TagPropertiesCard.scan 的旧元素选择器。未以修改无关业务来规避这些失败。
- 视觉验证使用示例数据，不代表真实资料库端到端同步验证；本次未触发外部同步或修改用户内容。

- 全部内容/标签/日志的选中条目与各自列表滚动位置恢复；目前只恢复相应搜索词，日志日期保留。

## 使用

退出旧版 Hub 后启动新的 WorkspaceInteraction 免安装 EXE。在窗口右上角的“布局”选择标准、紧凑或专注；推荐紧凑模式。无需安装，不覆盖之前的免安装文件。
