# 工作区第三阶段：操作连续性

交付：`src-tauri/target/release/bundle/portable/Hub_0.16.141_x64_portable_WorkspacePhase3.exe`。通过 `npx tauri build --no-bundle --features custom-protocol` 构建，无安装包，保留旧版。

## 已实现

- 闪卡复习切换模块后自动暂停；返回后显式继续。保留待复习队列、输入答案、选择项、排序及揭晓状态。
- 复习计时不包含暂停时长；会话仅保留在当前应用内存，不声称跨重启恢复。
- 评分使用同步互斥；离开页面期间完成的评分仍推进一次。提交失败保留答案，统计刷新失败与评分失败分别提示。
- 继续前重新读取卡片：移除已删除或复习计划已变更的卡片；当前卡片内容发生变化时重置答案。离开页面时取消恢复结果，避免异步重开。
- 主页面新增本机编辑草稿入口，可找回或明确丢弃；编辑器关闭时可选择保留草稿。找回只填入编辑器，不自动写入卡片。
- 替换其他卡片的草稿前确认；保留草稿存储失败时保持编辑器打开。恢复原卡片/牌组不存在时保留草稿并说明原因。
- 恢复条采用现有中性灰、蓝色动作、小圆角；窄窗口按钮换行，无新增大幅动画。
- 修正 5 项标签分页测试缺失的模型接口模拟；将 2 项已移除扫描入口测试更新为属性卡的当前职责与切换行为。没有把旧扫描入口重新加回产品。

## 验证

- 前端全量测试：320 项（88 文件）通过。
- 浏览器示例数据验证：输入 T29 → 切换内容模块 → 返回 → 继续，输入保留；检查答案 → 评分后剩余数量 3→2。
- 草稿：新建输入 → 关闭 → 保留草稿 → 找回，字段内容恢复；保留后焦点回到搜索，找回后进入问题编辑框。
- 实际截图检查：1280 宽和 760×760，恢复条无按钮裁切；窄窗口仍能找回草稿。
- 示例使用独立浏览器模拟数据，未修改真实资料库或进行真实远端同步。

## 范围与限制

- 复习进度不跨应用退出；已成功评分仍由原后端持久化。
- 编辑草稿沿用单份本机存储，不同步到其他设备。
- 未对 Android、真实 WebDAV 合并、原生屏幕阅读器、深色/高对比模式做端到端测试。
- 生产构建仍有原有的大包体积与 Rust 未使用代码警告。
