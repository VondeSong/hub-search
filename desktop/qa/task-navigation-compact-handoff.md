# 任务导航精简与全局栏紧凑化

## 调整

- 移除任务中间侧栏内重复的“保存的视图”区，仅保留“项目与清单”。
- 列表、看板、表格和新建视图继续保留在任务主内容顶部，功能与视图配置未删除。
- 全局导航图标由 18px 调整为 17px，选中与悬停底板由 40×40px 调整为 34×34px。
- Hub 图标由 30px 调整为 26px；资料库缩略图由 30px 调整为 25px。
- 缩小资料库列表间距、分隔线宽度与选中阴影，保持焦点、悬停和当前项反馈。
