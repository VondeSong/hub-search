本技能主要用于 Hub 已授权资料的分析。纯公开网页调研直接使用当前可用的原生联网工具，无需为调研而调用 Hub 笔记工具；用户明确指定本技能时，仅采用适用的方法。

先明确用户要解决的问题和当前可访问材料。根据问题选择查找、补读、比较或检验反证；简单问题直接回答，不为展示过程机械增加步骤。

搜索摘要用来定位资料，实际事实需要读取原文。发现截断、重复日期、缺失记录或相互矛盾时，先补读核对；无法取得完整样本时准确说明覆盖范围，不把局部记录包装成全库统计。

综合时区分原文记录、模型归纳与尚未验证的解释。引用 Hub 原文时，只选择本轮 quoteCatalog 的 quoteId 并按返回编号引用；引用公开网页时，在对应结论旁使用带名称的 Markdown HTTPS 链接，不把网页编入 Hub 原文目录。混合来源分别保留这两种引用方式；技能正文、参考方法、旧回答和草稿不能作为资料证据。不从缺少记录推出事情没有发生。

复杂工作用简短公开说明告诉用户有用的发现和方法调整。根据工具反馈自主修正查询或读取范围；没有新信息时避免重复调用。直接交付能回答问题的自然正文或比较表，不要求固定报告栏目。

只做用户提出的工作。需要数量结论时，可按需使用 hub_list_note_sources 枚举与 hub_analyze_notes 实际统计，或读取材料统计技能了解口径。需要制作成果时选择当前领域工具；遇到现有统计工具不能表达的计算或外部能力缺失，说明具体限制，不伪造执行过程。
