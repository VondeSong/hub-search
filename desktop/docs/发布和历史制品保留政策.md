# 发布和历史制品保留政策

正式 Windows 免安装构建仍是 `npm run tauri:portable`。`scripts/release.py` 负责记录它的输入、共享输出锁、退出状态和实际产物，不能替代 Tauri 构建，也不执行上传、安装、源码版本修改或历史清理。历史 `artifacts/flashcard-inbox-20261010-253/release.py` 是当次证据，后续发布使用正式脚本。

## 冻结和构建

在 `desktop` 中使用 Python 3.11 或更高版本。版本从 `package.json` 读取，并精确核对 npm 锁文件、Cargo 清单与锁文件、Tauri 配置中的项目版本；不一致时停止。`plan`、`verify` 和帮助仅查询，不创建锁或运行记录。

```powershell
python scripts/release.py plan
python scripts/release.py freeze --run-id candidate-001
python scripts/release.py verify --run "冻结输出中的完整 run 路径"
```

`freeze` 创建 `artifacts/releases/<run-id>/source-freeze.json`，包含项目根、运行身份、应用标识、版本和生产输入逐文件 SHA-256。它包含前端、Rust、当地依赖、能力、图标、构建脚本、配置、锁文件与实际存在的生产环境文件；只记录环境文件摘要，不输出内容。相同标识不能覆盖已有目录。冻结后增加、修改或移除输入，都必须重新验证并为新候选分配新标识。

确认当前候选的必要检查通过并获得本次构建许可后，执行：

```powershell
python scripts/release.py windows --run "冻结输出中的完整 run 路径"
```

默认从 `PATH` 解析 Node，使用其安装目录中的 npm CLI；非标准安装用绝对路径 `--node`、`--npm-cli` 指定。Cargo 输出目录消费绝对 `CARGO_TARGET_DIR` 或 `--cargo-target`，未设置时使用项目内 `src-tauri/target`，不能填相对路径。外部目标目录必须已有明确归属和使用许可；此脚本不负责创建外部存储政策。默认离线、单 Cargo 作业、关闭增量编译；确需下载依赖时显式加 `--online`。未声明的 `RUSTFLAGS`、`CARGO_ENCODED_RUSTFLAGS`、`CARGO_BUILD_TARGET`、`TAURI_CONFIG` 或 `NODE_OPTIONS` 会阻止构建，不默默继承另一套计划。

所有正式 Windows 发布包装器共享 `artifacts/windows-build.lock`。从取得锁、重新核对冻结、启动唯一 npm 入口，到生产者结束、产物核验与回执提交，始终持有锁。直接并行调用 npm 或其它修改 `dist` 的入口不会自动遵守此锁；冻结候选的验证、构建和打包须按维护者计划串行执行。

`windows.json` 记录命令、工作目录、已声明环境控制、工具文件摘要、实际 PID、开始/结束时间、退出码、冻结摘要与结果。构建日志写 `windows.log`，成功时核对 Cargo 正式 EXE 和免安装 EXE 的摘要，并将独立核验副本保留在同一运行目录，回执登记其路径、字节数和摘要。任何错误不得报告成功。已存在构建回执或日志的运行不能原地重试。

Ctrl+C 只影响观察者，包装器仍等待实际构建进程结束后才释放共享锁并写终态。机器关机、强制终止观察者或未知退出留下的 `starting`/`running` 回执保持待协调；先按记录的 PID、命令和输出核对生产者是否已结束，不按目录时间猜测成功，不立即重复启动构建。最终副本和冻结回执只证明这次正式入口的关联，不代替签名、许可证、包内组件、覆盖升级、目标机器实际启动和外部发布验证。

## 历史制品的保留和后续整理

现有根目录 EXE/APK、SHA-256、日志、备份与历史 artifacts 全部维持现状。本次只规定后续归属和整理计划，不删除、不移动、不把旧文件冒充当前候选。

后续候选、冻结、日志、构建回执和交付副本一起保留在明确的运行目录。稳定发行版至少保留实际交付物、摘要、冻结身份、构建回执与必要验收证据；失败、中断、未知和仍在运行的证据都保留，不能因成功候选出现而自动清理。缓存与源码、用户备份、恢复点、交付物分开治理。

历史整理必须先生成逐项只读清单，核对生产者、版本与内容身份、当前引用、终态、唯一对象和仍需保留的证据。没有完整来源证明的对象标为未知，不根据扩展名或修改时间删除。维护者审核准确候选和可回收范围并获得明确授权后，才可单独实施归档、移动或删除；迁移后核验副本与正式消费者，再另行决定原对象处置。新入口不提供自动清理命令。
