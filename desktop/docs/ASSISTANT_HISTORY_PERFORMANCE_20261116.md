# 助手历史性能与引用预览修复（2026-11-16）

归属：#31，Agents／桌面；父任务 #43。本次修复日常桌面缺陷，不改变站点、来源权限或模型运行流程。

## 原因与改动

- 打开助手先查询历史，再恢复选中的对话。原历史 SQL 的相关子查询在筛选、排序中反复扫描 `agent_records`；SQLite 实际计划出现多次 `SCAN p`。删除后的列表刷新也受同一问题影响。
- 历史查询改为一次提取各 Work 的最新历史偏好，物化有限列；先确定 21 条分页候选，再统计这页的消息数。保留原有标题搜索、来源锚点、置顶、归档、删除／撤销和游标规则，不读取回答正文，不新增数据库迁移。
- 切换历史立即收起菜单，等待时遮住旧正文并禁止发送；成功才替换当前对话，失败仍保留原对话。选择当前对话直接返回，不重复读取。初次恢复不再同时展示新聊天欢迎页和“正在恢复对话”，只有超过 180ms 才出现轻量占位。
- 删除等历史偏好保存成功后立即更新对应行、清除当前绑定并提供撤销，历史列表在后台更新；后台刷新失败与保存失败分别反馈，不把刷新失败说成删除失败。
- 书本按钮原来把预览放在长对话末尾，且存在 Hub 全局原文预览容器时不滚动过去。现改为助手正文区域内的原文视图，点击立即显示核对状态，加载成功突出引文，失败显示原因。关闭恢复原会话、草稿、滚动与引用按钮焦点。读取仍经过原 `source` 授权／版本核验，取消和范围变化继续丢弃过期结果。
- 引用编号继续打开 Hub 对应原页面；书本用于在助手中就地核对引用上下文，两者用途保留。
