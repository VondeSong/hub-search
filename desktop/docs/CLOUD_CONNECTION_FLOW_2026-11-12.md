# 云连接原型对齐与真实验收（2026-11-12）

关联 [Issue #3](https://github.com/VondeSong/hub-search/issues/3)。本轮补齐云连接页与已确认站点原型的差距，沿用已有概览、三模块附件策略和 WebDAV 退出结果，不发布版本。

## 原型对应与真实行为

视觉与流程依据为 `sites/hub-workspace/app/CloudSyncCenter.tsx` 和 `cloud-sync.css` 的连接页：默认显示连接名称、云位置和当前连接标记；“更新凭据／检查连接／更换云空间”分别按需展开。连接名称同时用于概览。日常不显示整张长表单，不增加新的视觉方向。

首次连接和更换云位置采用“位置 → 检查与确认”两步；凭据更新只有密钥字段。取消清空本次输入的 Secret 并恢复摘要；切换云同步内部页面保留未提交草稿。操作中锁定表单和页面切换；已保存但概览刷新失败时明确区分两种结果。

真实产品保留 Hub 设置外壳，使用实际 AccessKey ID／Secret；地域为支持现有全部 OSS 地域的文本输入，没有照搬原型的三个示例选项。原型演示状态选择器和假失败控制不进入产品。小屏沿用同一层级、文字换行和纵向滚动，不横排一张配置表。

新入口 `save_cloud_connection` 在固定同步锁内校验操作类型，先检查候选目录的真实列表、上传、下载与读回权限，再保存配置和安全存储密钥。失败保留原连接和密钥；检查产生控制对象，不代表内容同步成功。首次连接与凭据更新允许在暂停时执行，保持暂停和模块／附件策略，不开始内容传输。

凭据入口不能换云目录；等价目录的别名修改不触发迁移。真正更换 OSS 云位置仍要求本设备开启、其它设备已暂停，并执行既有完整复制与读回验证，通过后才切换。绑定速记的空间继续拒绝迁移；未上传的本地速记不被误判为已绑定。旧 `save_flashcard_oss_config` 保留配置接口兼容，新界面不再调用它；旧 WebDAV 命令和传输没有恢复。
