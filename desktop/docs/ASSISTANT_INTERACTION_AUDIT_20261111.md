# Agents 原型交互复核与修复

本页前半部分记录 v72 的复核；v77 同步与后续 v80 苹果风格修正见末节，后续明确的交互取舍优先。

## 对照依据

以当前 [Hub 站点](https://hub-workspace-von11.song02211368537057.chatgpt.site) 的独立源码为准。已读取 Sites v72（`a18aa9a89f3396ff340f1cba48bc549abca512ff`），其相对 v71 的变化是主题预览；`Assistant*.tsx`、`TagAssistant.tsx` 和 `assistant.css` 没有变化。本轮修改桌面，不改站点，不发布安装包。

此前的业务回归没有发现用户截图中的实际排版错误。本轮使用真实生产组件和样式做独立无头渲染，替换的只有本机接口与合成数据；没有操作用户的浏览器或软件窗口，没有调用模型或写入用户外部资料。

## 本轮发现及修复

1. 顶栏的后代按钮/标题规则影响整个菜单：链接被限制为 32px 宽，双行模式选项被限制为 32px 高。限制改为只作用于顶栏直接按钮，菜单分别设置尺寸、颜色、字体和换行。模式选项实测恢复至约 57px 高，链接不再竖排。
2. 模型菜单沿用旧字体和名称。列表按原型使用 12px，说明 11px；GPT 名称的分隔与 DeepSeek 的版本副标题按参考展示，官方图标保留。只改变展示名称，不改模型 ID、实际目录和能力。思考档位文案统一为低、中、高、超高等；DeepSeek 的实际关闭/推理档位仍由目录决定。
3. 对话详情仍是旧列表。改为“资料与工具”“进度与成果”两组，补上图标、资料范围、工具、记忆和任务状态。旧对话的记忆状态未核对时不借用新聊天偏好冒充；仅依据材料时显示本轮不使用。任务状态入口直接打开独立状态面板。
4. 更多按钮会被外部关闭事件先关闭、点击事件随后重新打开。弹窗把外部触发按钮纳入关闭判断，二次点击可以关闭；Esc、关闭按钮和任务状态入口返回原触发位置。任务状态打开时先把焦点移入面板。
5. 有效专题此前点击即应用，跳过原型核对步骤。现在先展示资料与策略，确认后才应用，并阻止重复确认。失效/变化来源继续要求复核，不扩大范围。
6. 专题展开后缺少单项移除。补上页面、其他核心来源、资料库和专题技能的独立移除；只调整当前对话，从下一轮生效，不修改已保存专题，不删除手选内容。
7. 置顶区补齐空状态提示、技能用途、专题策略/数量、当前专题标识、取消置顶以及返回任务模式。技能库由底栏魔杖进入，删除与当前原型不符的重复“全部技能”链接。技能指令不再直接成为聊天标题。
8. 布局样式限定到带结构化摘要的行，避免把原有笔记固定方法专题的文字挤入图标列；字体沿用应用字体，保留已有原生功能。

## 保留差异与尚未验收项

- 模型数量、可用推理档位、加速、MCP 及保存权限按真实能力展示，不把站点固定示例目录当作在线服务返回。
- 原有固定方法/按期笔记专题仍保留专用入口；通用专题不替换其绑定和授权。
- 专题审阅页目前保留“用当前选择的资料修复专题”的真实操作。原型的审阅页直接进入范围编辑的快捷路径尚未完全等同；当前可从资料范围调整，再保存/更新专题。该差异记录到 #29，不隐藏能力差异，也不阻塞其他交互。
- 无头组件渲染不等同于 Windows 原窗口的逐屏人工验收；没有进行真实 Craft/Obsidian/滴答写入或新一轮模型质量验证。#29/#31 因这些剩余验收继续保持打开。
- 思考摘要与原生运行层均保持现状。本轮不改变执行预算、上下文容量或自动续行规则。

## v80 苹果风格修正与展开状态核验

用户提供六张本地截图，指出展开后的资料策略、真实资料库列表、推理档位、回答操作及技能管理仍有错乱，并明确要求采用 Apple UI 设计流程。本轮先更新原型并发布 v80（Sites `29ed068217aebecbba4ae83a249b3058d38fe88d`，部署成功），再同步桌面。

主参考为用户图 6 与现有原型的信息分组。只读核对了 Craft main 设计参考库的实时 schema 与案例；查看 [Updater 原图](https://r.craft.do/ROHvuzrhCb)，仅借用管理页分组与状态靠近对象的结构。保留 Hub 主题及系统字体、Windows 窗口和文件操作，不复制 macOS 窗口按钮或引入 Apple 字体文件。控件标题 13px、说明 11–12px、管理页标题 15px，均为本项目 CSS 尺寸，不冒称 Apple 原生点值。

- 修复两处根因：资料范围概览的后代 span/small 对齐规则污染了策略和库元信息；通用菜单的 span 弹性布局把推理柱状图标也拉成一整列。对齐规则收窄到概览直接子项，图标列固定 24px，正文按可用宽度换行。资料库保留图标、标题和紧邻元信息，整页只由外层内容滚动。
- 删除回答中的“Hub 助手”作者横幅，保留可访问的“助手回答”区域。复制、插入页面、新建笔记和创建任务整合为同一轻量工具栏。保存仍绑定各条历史回答、原版本与授权；失效成果、待核验业务回执和后续操作继续走原合同。关闭保存面板返回实际触发按钮。
- 技能管理分为本机技能、方法包、折叠说明；刷新放到标题旁，文件夹入口采用带用途说明的列表行。真实检查、导入、更新、核对、导出和源文件操作保留；原型对应入口只演示界面和说明，不访问本机文件。
- 详情沿用“资料与工具 / 进度与成果”，统一行高、图标、状态、正文缩进和字体。网页补充说明根据当前模型、资料策略及联网偏好生成；配置项仍可编辑，长说明与实际外部 MCP 配置收进独立折叠项，不把示例服务状态当作真实连接。
- 原型目录继续是示例；桌面保留提供方真实模型和推理档位，额外的 Ultra 显示为“极限”。未修改模型 ID、推理强度值、预算、原生执行或公开思考过程组件。

另行只读核对本次“只显示用时”的记录：Hub 请求 detailed 公开摘要，当前 Codex 会话最终记录 summary 为 none；该轮原始记录只有最终回答，没有公开摘要、commentary 或工具调用。没有可恢复的隐藏过程，不能从耗时推定一定存在摘要，也没有补造过程文字。现有公开过程组件定向回归 38 项通过。

本轮相关前端回归 673 项通过、11 项既有跳过；保存焦点与公开过程专项分别通过，结果包含重叠，不相加。TypeScript/前端生产构建及差异检查通过，保留既有包体积提示。无 Rust 更改，不重跑无关原生测试。

独立生产组件渲染 12 组、336 项断言通过：覆盖 360/520/980px 宽度、浮窗两种高度及侧栏、浅色/暖色/深色配色，展开三种策略、六个合成资料库、推理档位、技能管理与外部 MCP 设置，并核对回答操作、历史回答身份和关闭后的焦点。实际查看了资料范围、推理、详情、浅/深技能管理及回答工具栏截图。证据保存在本机 `desktop/.local/assistant-apple-*.json`、构建日志与 `apple-*.png`，不提交合成运行文件和产物。
