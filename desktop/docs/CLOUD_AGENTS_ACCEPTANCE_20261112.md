# 云端 Agents 部署与验收记录（2026-11-12）

关联 [#32](https://github.com/VondeSong/hub-search/issues/32)。本轮用户指定使用 Android 模拟器验证；模拟器不等于实体手机或 Windows 主机关机测试。未发布 Release、标签或正式安装包。

## 部署

- 现有 Debian 13 VPS 使用专用 `hub-agents` 账号运行正式 `hub-agents.service`，状态位于 `/var/lib/hub-agents`。服务只监听 `127.0.0.1:8787`。
- 复用同一台 VPS 上已经授权的官方 Codex 0.167.1 和 ChatGPT 登录，未配置 API Key。真实 `account/read` 返回 ChatGPT / Pro Lite，模型为 `gpt-6.1-sol`。额度可读，测试时七天额度已用 97%；无法核对单次生成的具体扣额。
- 使用公网 IP 的受信任 HTTPS，入口为 9443；原有 443 服务保留。80 仅提供 ACME 验证文件，其他 HTTP 请求返回 404。反代保留认证，上传上限 17 MiB，限速 10 请求/秒、突发 30。
- Certbot 5.4.0 配合 Let's Encrypt `shortlived` IP 证书，每六小时检查续期，成功后检查并重载 Nginx。正式证书签发、外部证书链/IP 校验、续证 dry-run 及 deploy hook 均通过。客户端未关闭证书验证；无设备密钥访问返回 403。
- Windows、Android 模拟器和预留手机分别使用独立设备密钥。手机连接信息保存在本机受限目录，不写入 GitHub、安装包或聊天正文。原有 sing-box、飞书机器人和连接监控保持运行。

## 真实服务验证

以下生成通过正式 Hub 服务调用真实 Codex，不是模型桩测试。

| 项目 | 结果 |
| --- | --- |
| 文字、同一线程追问、合成四色 PNG | 完成，分别约 4.86、4.44、3.64 秒；观察到部分文字增量 |
| 相同请求编号和内容重发 | 返回同一轮记录，没有新增重复轮次 |
| 服务正常重启 | 历史与线程保留，重启后追问准确复述原编号，约 4.03 秒 |

加入模拟器相机和视频测试后，服务 cgroup 本轮短测峰值 `297623552 B`（约 284 MiB），一次空闲回读 `192614400 B`；该统计包含 cgroup 中的内存与缓存，不是单个 Codex 进程的 RSS，也不是长期并发指标。使用既有 VPS 和免费证书，未新增付费 API；订阅额度仍按服务方规则计算。

## Android 与桌面联调

使用独立 API 35 x86_64 模拟器 `Hub_QuickCloud_20261112`，通过系统 ARM64 桥运行真实 Hub APK。未操作其他任务的模拟器。

- Android 通过正常连接界面保存 HTTPS 地址与独立密钥，真实模型回复 `HUB32-5893`。
- Windows 开发版打开同一云端会话，继续追问并得到相同编号；Android 自动取回桌面消息及回答。
- Android 通过系统选图器上传红/蓝测试图。发送后启用模拟器飞行模式，界面显示连接中断及待确认；桌面仍能看到服务正在执行。恢复网络并重连后取回完整结果，本机待确认状态消失，没有新增重复轮次。
- Windows 可打开 Android 上传的真实附件，画面与“左边红、右边蓝”的回答一致。
- Android 点击停止生成后显示“已停止”。强制停止、重开及覆盖安装新包后，连接信息仍可恢复；通过对话列表取回原编号、桌面追问及图片回答。
- 最终 ARM64 包中，顶部对话列表按钮已位于状态栏下方。键盘显示时输入框和发送按钮可见且可点击，收起键盘后恢复完整高度。`adjustResize` 单独设置不足，原生窗口还需按 IME 高度调整 WebView 可用区域。
- 系统相机完成拍摄、确认、JPEG 回传和模型回答。该照片来自模拟器虚拟相机，不是实体手机相机测试。
- 用同一段 3 秒红/绿/蓝 H.264 视频重测：0.50、1.50、2.50 秒的上传图片平均 RGB 分别为 `[254,0,1]`、`[2,128,1]`、`[4,0,254]`，模型回答正确。三帧 JPEG 合计 2,933 B，原片 2,352 B；Base64 和 JSON 另有开销，抽帧不保证比原视频更省传输体积。

## 本轮修复

1. 应用 CSP 的 `media-src` 增加本机 `blob:`，允许解码用户主动选入的本地视频；未放宽网络连接策略。
2. Android 的 `seeked` 事件可能早于新画面到达，直接绘制会让图片落后一帧。改为在 `requestVideoFrameCallback` 中绘制，记录实际画面的 `mediaTime`；不支持可靠抽帧的设备明确提示更新 WebView 或改为图片。
3. Agents 顶部工具栏增加 Android 安全区内边距，避免状态栏遮挡对话列表按钮。主 Activity 设置 `adjustResize` 并处理 IME insets，使软键盘弹出时 WebView 实际缩小，收起时恢复原有内边距。
4. 声明系统拍照 Intent 的可见性，使 WebView 能发现系统相机，不把“拍照”静默退回相册；不申请遍历全部应用的权限。

- 前端相关测试 17 项通过（媒体、移动窗口、连接设置、导航），TypeScript 检查通过；Vite 构建通过，已有大分块提示保留。
- Hub 服务 Python 集成测试 2 项通过。它们使用模拟 Codex，覆盖恢复、停止、重发冲突和错误分类；与上面的真实模型验证分别记录。
- VPS 的 Nginx 配置、续证 systemd 单元和部署 hook 语法检查通过。
- Android 原生 ARM64 编译后，Windows 因创建符号链接权限不足不能由 Tauri CLI 自动继续。将本轮实际编译的库复制到 JNI 目录，按锁定 Tauri 版本生成 JVM 文件与 ProGuard 规则，再通过 Gradle 正常构建、签名。未用旧 APK 替换库充当完整新包。
- 最终 APK 的 v2/v3 签名、16 KiB 对齐和模拟器覆盖安装通过。SHA-256：`50b44049c45cf8f6079b08ad79ed76a24946ddb9925e4946557a722110a18aa2`。安装包不含设备密钥或 Codex 登录凭据。
- 本地主分支的 Windows Tauri 开发实例自动重编译并重启成功，主进程重新创建，Vite 返回更新后的取帧逻辑和安全区样式，所属 WebView 经 `::1:1420` 连接开发服务。新窗口打开云端 Agents 后恢复原有连接并显示真实模型/套餐；没有另开第二套主项目运行环境。

## 验证边界

未做实体手机、Windows 主机关机、真实账号过期/额度耗尽及跨多天证书自然续期观察。登录不足和额度错误的自动化覆盖不能冒充真实耗尽。短视频仅传关键帧，没有音轨或完整视频理解，帧间短暂动作仍可能遗漏。上述真实运行限制继续在 #32 中跟踪。
