## 环境与证据边界

- Android API 35 Google APIs x86_64 模拟器，通过 `libndk_translation.so` 运行正式源码编译的 ARM64 native；这不是 ARM 实机或性能验收。
- 使用独立 `com.craftsearch.desktop.integration` 联调应用，未卸载、清空或改写模拟器中的正式应用。Windows 使用独立数据目录、独立 WebView 目录及外置测试 Obsidian 库。
- 两个实际运行的应用经真实 OSS 互传，目录位于既有连接的唯一 `_integration/emulator-20261112-<随机值>` 子目录。连接凭据仅在进程内使用；个人正文、正式同步范围与个人云对象未修改，远端测试对象未删除。
- 阅读由正式本地 Markdown 来源接入；闪卡由正式导入和创建命令产生；速记由手机正式暂存附件和采集命令产生。大多数数据矩阵通过真实 Tauri 命令边界驱动，不将其写成全部通过触摸界面操作。

## 发现与修复

1. **本地来源的阅读附件不能上传。** 本地 Obsidian 接入为旧版本兼容保留 `reading_cloud_items` 标记，附件上传却仅据该标记排除来源。自动排队、附件状态和手动上传现在统一区分本地所有者与纯云接收端；保留旧标记，纯接收端仍不能反向上传。
2. **Android 已下载附件无法登记为本地原件。** 沙盒禁止应用数据硬链接，导致读取成功后发布本地副本报 `Permission denied`。Android 改用 `renameat2(RENAME_NOREPLACE)` 系统调用完成原子、不覆盖发布，不依赖 API 30 才提供的 libc 导出符号；只有内核不支持该调用时才回退旧路径。未放宽权限、哈希校验或覆盖保护，Windows 路径不变。
3. **自动恢复后概览保留旧错误。** 可见轮询原先只更新阅读与速记，闪卡结果和上次统一同步错误不刷新。现在更新三个模块结果，恢复后清除同步错误，保留设置保存等其他错误；旧轮询结果不能覆盖较新的手动操作结果，也不重置未保存连接表单。
4. **主按钮悬停时文字难以辨认。** 通用悬停背景覆盖了深色主按钮，文字却仍为白色；移动端点击后也可能保留该状态。主按钮现在在悬停时保持自身的背景与文字对比。
