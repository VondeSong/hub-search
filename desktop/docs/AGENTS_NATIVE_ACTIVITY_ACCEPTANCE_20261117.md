# 原生能力与工作过程验收（2026-11-17）

对应 [#14](https://github.com/VondeSong/hub-search/issues/14) 的原生能力补充方案和 [#56](https://github.com/VondeSong/hub-search/issues/56)。用户授权依次实施、AI 自主评估整改与验收；未使用 Ponytail，未启动无关旧 V4 候选、Android/VPS 开发或正式版本发布。

## 本轮决定与结果

Hub 过去关闭原生 shell、多代理和插件发现，确实缩小了模型可以采取的行动范围。已有受控计算、授权图片、网页、Hub 技能及共享记忆继续保留。限制不能仅靠图标解决，也不等于推理强度被调低。

本轮选择接通 Windows 独立工作区命令/文件及受限原生委派，保留现有匿名只读 MCP 并验证；提供逐项[能力合同](AGENTS_NATIVE_CAPABILITIES.md)。没有具体服务、账号和操作依据的私有 OAuth、第三方 stdio、写插件，以及浏览器/电脑操作不批量开启。当前公开 app-server 也不能证明支持 Codex 桌面的全部专有功能。

工作区和委派是每个对话的独立选择，不沿用全局凭据、插件或原资料库文件权限。使用本机 Codex 0.169.0 协议、MXC minimal read、独立目录可写、网络关闭、2 GiB/32 进程限制；子代理最多两个、一级委派。来源写回仍经过 Hub 原有草稿、版本、回执、未知结果核对和索引流程。

冻结材料额度暂不支持工作区；冻结 Token 额度暂不支持子代理。命令输出/子请求尚不能完整纳入相应冻结额度时，启动前拒绝，不静默绕过。主线程和观察到的子线程用量分别记录，缺少的计量为未知，不补零。

## 工作过程合同

- 新事件使用结构化 operation、真实服务/代理身份及首次序号；中文标题只作为历史数据回退。单行与折叠汇总共用一个图标解析器，混合组不冒用第一种操作的图标。
- 首次创建时间与序号固定，更新时间独立保存，首次完成时间保留。迟到的开始通知不能重开已完成的普通事件；真实子代理可以在同一身份下开始后续轮次。
- 原生 commandExecution、fileChange、collab/subAgentActivity 投影为公开事实；真实子身份才生成稳定几何头像。公开摘要、进度、工具回执、未核验答复和正式交付保持不同语义，不展示隐藏原始推理。
- 站点按有效公开来源去重，以固定 16px 图标显示。GitHub/Notion 的本地品牌资产独立于操作图标；favicon 不代表成功访问或完整阅读，失败保留地球占位。
- favicon 只接受当前有效对话中已出现的公开站点，读取站点根路径与图标，不带原来源路径/查询、浏览器 Cookie 或 Referrer。每次跳转做 URL/DNS/IP 校验，限制时间、重定向、字节及尺寸，只展示 PNG/ICO，拒绝 SVG。缓存按站点/主题保存，24 小时、最多 256 个文件。
- 公开显示记录每轮最多 1024 条/512 KiB，独立于业务执行记录额度。达到上限保留明确提示与已有事件终态，合法任务继续，最终交付仍可保存。活动投影上限为 4096 条、最近 20 轮；没有新增无限历史分页。
- 失败、中断和部分网页失败继续单独呈现；来源变化/撤销仍隐藏不再有效的正文。总时间仍称“用时”，不把工具等待冒充模型思考时长。

## 可作出的结论

本轮补齐了可核验的原生执行/委派入口，并修复工作过程的结构化身份、图标、排序和容量问题。并不据此承诺完整插件生态、任意宿主终端、跨端一致性或与 Codex 全任务质量等价。

当前应用以既有浅色主题为验收目标，未新增全局深色主题；网站图标按应用主题选择，不能只看操作系统偏好。其他 DPI、深色系统、减少动态偏好及大规模长期并发的完整矩阵不冒充本轮实测；保持现有无额外图标动效及键盘语义。没有同模型、强度、输入、工具全部一致的广泛对照，不宣称推理质量、完成率或耗时达到 Codex 同等水平。

#14 保留旧 V4 候选的历史范围；本次仅完成选定的原生能力阶段。#56 的桌面展示实现与本轮限定验收独立记录；云端/手机 #32 没有因此完成。
