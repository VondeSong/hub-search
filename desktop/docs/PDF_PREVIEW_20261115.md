# PDF 搜索预览交付记录（2026-11-15）

对应 [#11](https://github.com/VondeSong/hub-search/issues/11)，归资料库模块 #35，平台为桌面。

## 本轮实现

- 在现有预览区输入原文页码并跳转；拒绝非整数、0 和越界输入。新结果首次打开使用其搜索页码，不沿用上一份文档的翻页位置。
- 50%–300% 缩放和恢复适合宽度。缩放只改变当前页图像的显示，不重新调用原生渲染，不触发 OCR 或整份转图。
- 全文／仅命中页切换；后者按当前 PDF 正文索引返回的真实原文页码导航，另行显示命中页序号。切回全文保留当前原文页；输入非命中页会切回全文并说明。
- 可聚焦页图区域，用 PageUp/PageDown、Home/End 翻页，加减键缩放，Ctrl/Cmd+0 恢复适配。页码表单和缩放选择也可直接用键盘操作。
- 区分未搜索、未提取、已处理但没有文字、提取失败、当前已索引页内未命中及旧版本文字。未索引页面不会被描述为没有命中；历史未绑定文件版本的文字会单独提示。
- 页码优先读取实际 PDF。原文件损坏时仍允许阅读已有提取文字，明确说明页数暂按提取记录显示；此时不生成假称已核验的当前页原文链接。
- 打开原 PDF 和复制当前页链接使用经过哈希核验的独立工作副本，并附 `#page=N`。本地已编辑副本不会被覆盖，原始备份不交给外部阅读器编辑。外部阅读器能否定位须依其链接支持判断。

## 查询、响应和资源边界

页级检索沿用现有 Tantivy 索引，只在当前 PDF 的有效内容项中搜索正文；不使用全局结果最多五项的子命中列表推断整份 PDF 的命中页。标题、文件名、拼音和模糊补召回不冒充正文页命中；非正文显式字段查询会说明无法建立页级命中序列，全文浏览仍可使用。默认全局搜索的分组行为保持原规则。

有明确输入版本且已过期的文字被排除，命中的索引正文还会与当前数据库正文核对。最多扫描 10,000 个内容块、返回 1,000 个命中页；达到边界会标注结果不完整。单页渲染最长边上限 1,600 像素；快速翻页只保留一个在途渲染和一个最新等待请求，切换文档后旧响应不能覆盖当前预览。关键词的页级检索有短暂延迟及同类请求合并，避免随输入积压。

## 验收边界

本轮没有重启、强制结束无响应的日常 Hub 进程，也没有另开一套日常客户端。原生窗口的完整交互、搜索输入与翻页同时进行时的主观流畅度，以及外部阅读器的实际页码定位，仍需在日常窗口恢复后检查；后台探针耗时和原型浏览器验收不能代替这些结果。

在上述必要窗口验收完成前，#11 保持打开／待验证，模块父任务 #35 保持打开；源码和站点交付不等于已经关闭功能验收。
