2026-11-18。关联 [#32 移动端 Agents](https://github.com/VondeSong/hub-search/issues/32) 和 [#58 知识库能力完整化](https://github.com/VondeSong/hub-search/issues/58)。本轮用现有 T29 报告、同一云端回答和原保存回执验证，沿用 [T17 的原始证据](T17_ANALYSIS_HANDOFF_20261118.md)。

## 故障与修复

Android 可在 Rust 进程继续运行时换掉宿主 Activity。之前 Hub 接到最后一个窗口销毁的消息后，向已销毁的页面请求保存退出。新 Activity 没有对应的 WebView，用户看到白屏。本轮将系统窗口回收与 Hub 主动退出分开。Activity 销毁和新建可以交错发生，Hub 等 Wry 清掉旧 WebView 回调、Tauri 释放旧窗口，再用原配置和权限创建主窗口。

Tauri 升级到 2.12.4，JavaScript API 与同一小版本对齐。新版本的插件管理器为每个 Activity 注册自己的文件选择和权限回调。Hub 的来源插件也在每次调用时获取当前 Activity。未发送的 Android 助手草稿按设备连接和会话存到本机。点击发送时，同一存储事务将草稿移交待确认队列，保留原消息编号与避免重复发送的规则。

清洁打包前曾遇到插件类缺失引发的启动闪退。对 Android Gradle 产物清理后，用进程内 Kotlin 编译，逐项检查 APK DEX 中的 Activity 和原生插件类，再覆盖安装。首次同进程重建能新建 WebView，但仍发生页面加载错误。旧 WebView 的清理与新窗口共享标识，修复加入 Android 消息队列清理完成条件。现场和日志均保留。
