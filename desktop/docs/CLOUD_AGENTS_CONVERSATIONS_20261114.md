## 实现范围

- 进入 Agents 先显示完整列表，包含真实连接信息、消息摘要、更新时间和当前／已归档／全部数量。列表保留底部五项导航，聊天使用完整高度。
- 搜索标题及全部历史用户消息和回答，按字面处理百分号、下划线等内容。搜索与归档范围组合，异步旧响应不覆盖新查询。
- 选择会话或新建后进入聊天，顶部保留列表、加号、连接设置与关闭入口；已有会话增加重命名、归档／恢复选项。
- Android 返回先回列表，保留查询、范围、滚动位置及本次打开期间的各会话草稿。新会话草稿与旧会话输入相互独立。
- 归档只收起会话，保留消息、附件与线程身份；归档后禁用发送，恢复后可继续。服务端在同一事务核对活动轮次与归档状态，拒绝运行中归档、拒绝归档后的新请求，保留原编号重试。
- VPS 增量添加归档字段，原有设备鉴权与传输限制继续使用；未知字段、非法名称、非法状态或超长查询明确拒绝。
