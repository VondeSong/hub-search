# 运行组件与安装

Hub 的 Windows 安装包包含共享记忆所需的 Python、Basic Memory、中文检索模型和原生运行库。使用者不需要安装 Python、选择解释器或配置模型目录。模型服务的账号登录与提供方配置属于模型使用设置。

首次展开「共享记忆」时，Hub 在现有数据目录的 `cache/memory` 下自动准备并检查组件。准备期间界面显示状态；成功后可以保存和使用记忆。程序目录只保存随包分发的资源，用户数据仍由 Hub 原有存储设置管理。

正文保存在 `shared-memory/notes`，项目、确认、版本与使用资格保存在 Hub 数据库。组件更新或修复不改写这些记忆。完整备份继续保存正文和管理记录，运行组件属于可重建缓存。

更新时关闭 Hub，再运行新版安装程序。相同组件身份复用已经准备的组件；新组件先在临时目录完成校验和功能检查，再启用。组件损坏时可以点击「修复本地记忆」。安装资源自身缺失或损坏时，需要重新运行 Hub 安装程序。

安装包同时携带 WebView2 离线安装程序，供缺少桌面显示组件的 Windows 使用。免安装分发为完整 ZIP；解压后保留 Hub.exe 与相邻资源文件，再运行 Hub.exe。

为兼容 Windows 原生库和模型加载器，Hub 会在解压前核对真实路径长度。数据目录过深时会给出准确提示，避免写完后才发现组件无法加载。通常的应用数据目录无需调整。

开发与发布：`scripts/memory_distribution.py prepare` 接受准确的已核验解释器、包、模型与 CRT 来源，生成确定性的组件包及 `assets/shared-memory-runtime.json`。`verify` 核对完整归档。正式 `release.py freeze/windows/installer` 将同一份资源纳入内容冻结，先构建，再生成 NSIS 安装包；安装与免安装包共用 Tauri 的资源清单。第三方包许可、来源和模型许可随安装文件提供。

0.16.290 已完成本机隔离安装、真实文档导入、记忆保存、重启、损坏修复和 0.16.289→0.16.290 覆盖升级。首次准备约 25.7 秒，修复约 27.2 秒；这是本机从界面操作到就绪凭证的测量，不是所有电脑的时限承诺。升级前后的五张记忆管理表及六份历史 Markdown 正文逐项一致。安装包和完整免安装 ZIP、校验与边界见 `artifacts/runtime-delivery-20261020/delivery.md`。

本批交付的是共享记忆的本地运行环境。Codex 连接、登录及账号仍由既有 Codex 入口负责，Hub 继续复用其登录态，不新增 Hub 内的 Codex 登录、账号管理或独立模型提供方。没有替换个人现用安装。干净 Windows、缺少 WebView2 的系统和物理断网场景尚未实测；安装包已携带 WebView2 离线安装程序。
