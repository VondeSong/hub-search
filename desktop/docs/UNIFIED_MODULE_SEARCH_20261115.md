# 阅读与闪卡进入主搜索（#4）

本项归搜索模块父任务 #37，平台为跨端。阅读、闪卡原有模块内搜索保持可用；新增的是主搜索中的独立内容类型、完整预览及原条目定位。没有新增云端采集、模型调用或第二份持久化索引。

## 实现范围

- 主搜索合并可见资料库文档与本机阅读、闪卡。闪卡匹配题目、答案、解释；阅读匹配现有正文渲染器生成的内容。仅名称模式只匹配卡片题目或阅读标题。
- 桌面内容类型、手机直切及筛选表单、保存的智能筛选均增加阅读与闪卡。旧“全部类型”自动包含新类型；旧受限类型选择和显式空范围不会被放宽。
- 全局范围包含无来源资料库的自有闪卡及本机阅读。明确选择资料库时，闪卡必须有对应来源，阅读必须有该库已验证的保存副本；空资料库列表返回空。文件夹、页面及日期条件继续生效，关联隐藏或停用资料库的闪卡不进入结果，阅读仍是模块独立保存的本机条目。
- 归档、删除和放弃的阅读不进入结果；删除、非活动/暂停状态或已失去牌组的闪卡不进入结果。打开预览前再次检查条目和来源是否有效。
- 阅读与闪卡使用自己的类型和稳定条目身份，不伪装成 Craft 页面。精确标题、标题包含、正文包含依次排序，同分按日期和身份稳定排列。每种类型内去重，结果数量有上限。
- 结果摘要受长度限制，完整内容另行读取。正文哈希参与预览缓存身份，避免同一秒编辑后仍显示旧内容。图片和附件到原条目查看。
- 从搜索可打开指定阅读条目或指定闪卡。阅读使用临时精确条目查询，不受原列表分页或已保存筛选遮挡，也不改写原阅读视图。闪卡复用已有草稿保护，不自动开始复习或评分。
- 手机从预览转入模块时替换当前预览历史层，返回能回到搜索，不留下无效的旧预览层。原搜索文字和范围保留。
- 主搜索中的阅读/闪卡隐藏不适用的来源页面收藏、来源拖拽及来源助手入口；复制操作复制完整内容。

## 真实数据与接收

Windows 日常数据库以只读方式查询：749 张卡、1,728 条阅读。实际命中指定条目并读取完整预览，没有写入来源、模型调用或记录正文到提交。首次测得闪卡 20 ms、阅读 5,780 ms；阅读逐字段的较重转换已调整为与最终匹配一致的 Unicode 小写处理，最终复测闪卡 2 ms、阅读 854 ms。该单次数据规模下的测量不等同所有查询的性能承诺。

Android 模拟器沿用日常数据与正式 OSS 连接。先经正常设置改为手动同步，临时启用闪卡/阅读，并关闭闪卡四类附件自动下载；点击“立即同步”，接收 749 张卡和 95 条阅读，界面明确显示本轮结束。阅读仍有后续待接收批次，不将本轮描述为全量云数据接收完成。

接收后已通过正常设置恢复原全局自动同步、闪卡关闭、阅读关闭和四类闪卡附件自动下载；legacy mediaPolicy 保持 all。已接收缓存保留。#16 负责人独立只读对照双方 749 卡、108 不可变事件、3 撤销及 1 参数组，排程零差异；这是正式同步数据保全的共用证据，不替代本项搜索界面验收，也不重复计为本项新增测试。
