## 验收中修复的问题

- 二级窗口误用桌面云对话容器样式，继承固定宽高，导致手机列表和操作越界。现使用独立样式，列表独立滚动，保存窗口也固定于视口，不依附单条回答的位置。
- Android 返回原先可能切走底层会话而留下二级窗口。现在先关闭当前窗口；保存处理中阻止离开。
- 开发预览重复挂载会提前撤回返回记录，造成窗口打开即退或残留额外返回层。StrictMode 回归先复现失败，修复后通过；只在真实卸载后释放该窗口自己的记录。
