# 桌面日志属性式筛选对齐 v103

本轮接续 [#22](https://github.com/VondeSong/hub-search/issues/22)，将已发布的工作台 v103 迁入真实桌面客户端。依据为 [原型交付 9b09722](https://github.com/VondeSong/hub-search/commit/9b097226f7f74918b341a9cc3fee5a959344950d)、Site 来源 `1d52d6bcdcd45c889909b40c7cbcc624dae12ca3`、部署 `appgdep_6afab51b2ec08191949b8c82476fbae1`。本轮没有重新发布 Site。

## 实现

- 搜索默认收为放大镜，点击在顶栏展开。无条件时不占第二行；有条件时显示可编辑和独立移除的标签。
- 筛选先选择日期、资料库或内容类型，再进入对应编辑器。日期编辑模式本身不应用条件，有效日期或月份才生效；Escape 从子层返回属性层，再关闭弹层。
- 资料库使用客户端真实来源。保留 `null` 全部、`[]` 明确空选及已断开的历史来源 ID；不会植入原型示例库。
- 搜索作为临时查找，不令保存视图变脏；保存、更新、复制不写搜索词，切换、恢复与默认视图保留当前搜索。既有 v1 保存数据仍可读取，不批量清除历史 query 字段。
- 更新和恢复移入视图菜单，名称旁小点提示布局或条件未保存。弹层通过 ResizeObserver 和动画帧重新定位，保持现有拖窗、布局与预览入口。
- 搜索的第一次 Escape 清词，第二次收起并恢复按钮焦点；组合输入期间不执行该快捷键，不覆盖全局 Ctrl/Cmd+K。

仅修改前端视图与配置语义，沿用真实分页、原生速记和任务读取。未改 Rust、OSS、OS 日记格式或写入回执协议；没有创建或修改来源笔记。
