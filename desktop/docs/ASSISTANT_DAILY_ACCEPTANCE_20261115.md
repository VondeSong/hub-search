## 范围确认与本轮用户问题

补测开放研究时，Work `work-aIpIDHEKpZrRYaS1xu1r5Sww` / Run `run-u245vGrDVpYJloFgbkztE9G1` 在 34.138 秒内返回 completed，却只说下一轮使用三份材料，没有检查项和引用。实际 input/output 为 38,406/320，读取 12,639 字符、联网 disabled。这一轮判为交付失败，不能因为旧验收脚本只检查“正文非空”就算通过。

原因是首次应用专题的 `replaceResearchScope` 会写入一条宿主生成的范围确认，历史投影又把它标成普通问题，覆盖了最初的问题。修正将范围确认保留为历史中的 scope 事件，并从模型当前问题、问题上下文及目标核对的用户要求清单中排除这类管理回执；本轮仍处理最近的真实用户问题。已有记录通过宿主生成的身份前缀、固定确认文字及完整范围前后记录兼容识别。包含真实问题的普通资料变更继续保留为问题，不删除授权审计，不重复发送用户问题。

现有范围应用/取消回归增加了原问题保留、旧记录兼容、历史不重复、后续真实问题保留及同 Work/预算/固定方法保护；新旧管理回执均不算用户要求，真实追问正常加入。真实验收也增加当前问题等于配置原问题、最终引用覆盖三份所选来源的检查；期望拒绝的预算负例单列，不强行要求它生成报告。
