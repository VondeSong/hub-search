# Hub 原生能力接入合同

对应 #14（2026-11-16 补充方案），工作过程展示对应 #56。2026-11-17 用户恢复本轮实施并授权 AI 自主验收。旧 V4 的新来源、退出应用后的调度、远程正文编辑等候选仍按各自范围管理。

## 能力清单

此表描述实现边界，不用配置项存在或模型名称推定宿主支持。实际接入取决于已安装 Codex；Windows 首轮协议取证版本为 0.169.0。运行参数、授权和事件分别保存，测试结果另记验收文档。

| 能力 | 当前入口及范围 | 原生缺口/限制原因 | 恢复条件与验证所有者 |
| --- | --- | --- | --- |
| 资料计算 | `hub_compute`；Windows MXC、授权 excerpt 副本、20 秒、JSON 输出 | 不开放原库/凭据/联网；适合短计算 | `cli/agent/compute.rs`；验证输入只读、输出、取消与隔离，不替代通用工作区 |
| 工作区命令/文件 | 对话内显式选择独立工作区；原生 shell/unified_exec、文件编辑；MXC minimal read、工作区可写、网络关闭；2 GiB 与 32 进程上限 | 首期 Windows；无联网安装依赖和任意原文件访问 | `cli/agent/capabilities.rs`；实际命令、产物、外部读取拒绝、取消；不回退宽权限 |
| 子代理 | 单独选择、依赖工作区；一级、最多两个子代理，继承工作区边界 | 子代理不调用 Hub 业务工具；冻结 Token/材料额度时拒绝，防止绕过计量 | 原生适配器；真实父子身份/事件/取消、错误及用量观察；主线程与子线程计量分开保存，缺失计量为未知 |

| 技能/记忆 | Hub 已选技能及共享记忆已有 | 宿主技能发现、原生记忆/钩子关闭，避免跨任务指令与资料混入 | 分别定义选择、版本、作用域和恢复；不重复描述为“没有技能/记忆” |
| 图片输入 | 已有授权图片输入 | `view_image` 关闭不代表不能理解输入图片；工作区图片查看未验证 | 分别验证输入、工作区文件查看、图像生成，不互相代替 |

## 工作区与来源一致性

默认对话继续采用 Hub scoped tools。授权原生工作区后，使用独立 CODEX_HOME 和命名权限配置；不导入用户级 MCP、插件、技能、环境密钥或其它工作区。shell 环境不继承宿主环境。网络关闭；系统运行时只按 MXC minimal 范围读取。沙箱不支持时返回失败，不降级为 broad workspace-write 或 full-access。

工作区目录根据资料 grant、授权版本、研究策略、联网和 MCP 选择生成稳定身份。范围改变时切换目录；旧产物保留但不作为新范围的可读内容。入口允许打开当前授权范围的工作区文件夹，不能由模型提供任意路径。原生文件产物不是 Obsidian/Craft/滴答保存回执，也不能直接进入来源索引。

Hub 来源继续通过既有版本检查、草稿、幂等、结果未知核对、权威回读与索引更新流程写回。原生 shell 不直接取得原库路径的读写权限，不增加第二条竞争写回路径。

## 委派与恢复

主代理调用 Hub 工具，子代理仅处理工作区任务。适配器拒绝子线程的 Hub 动态工具请求，不能依靠提示词授予业务权限。原生公开 collab 事件保留 receiver 身份与状态；公开命令/文件事件按稳定 item ID 更新。原始隐藏推理不进入展示。

本轮结束、失败、取消或进程退出时关闭该运行的 Windows Job，覆盖其后代进程。未结束的公开活动在历史回读中显示中断。子代理不在 Hub 退出后后台运行；恢复依靠已保存事件、工作区产物和后续新运行，不能声称旧子进程仍然存活。

计量区分主线程累计差值与观察到的子线程累计值；没有收到的子计量是未知，不补零、不重复累计。冻结 Token 额度对话在启动前拒绝子代理，直到可对所有子请求做完整预留与核算。冻结材料额度对话在原生命令输出能够完整计入额度前拒绝工作区。未冻结对话仍采用本轮取消/运行时控制和原生委派数量边界。

## 验收原则

以实际安装版协议、真实项目文档和日常库为依据。隔离临时工作区可保存真实职责文档的副本用于原生运行验收；不向日常资料库注入合成测试内容。单元测试的临时 fixture 不代表日常库验收。

功能是否存在、工具是否发生、界面是否显示、任务答案是否正确分别验证。同模型不等于同等环境；不据本轮接入宣称完整 Codex 功能或质量等价。跨端 #32 仍是独立运行/展示链路。
