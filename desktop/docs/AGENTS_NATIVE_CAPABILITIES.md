# Hub 原生能力接入合同

对应 #14（2026-11-16 补充方案），工作过程展示对应 #56。2026-11-17 用户恢复本轮实施并授权 AI 自主验收。旧 V4 的新来源、退出应用后的调度、远程正文编辑等候选仍按各自范围管理。

## 工作区与来源一致性

默认对话继续采用 Hub scoped tools。授权原生工作区后，使用独立 CODEX_HOME 和命名权限配置；不导入用户级 MCP、插件、技能、环境密钥或其它工作区。shell 环境不继承宿主环境。网络关闭；系统运行时只按 MXC minimal 范围读取。沙箱不支持时返回失败，不降级为 broad workspace-write 或 full-access。

工作区目录根据资料 grant、授权版本、研究策略、联网和 MCP 选择生成稳定身份。范围改变时切换目录；旧产物保留但不作为新范围的可读内容。入口允许打开当前授权范围的工作区文件夹，不能由模型提供任意路径。原生文件产物不是 Obsidian/Craft/滴答保存回执，也不能直接进入来源索引。

Hub 来源继续通过既有版本检查、草稿、幂等、结果未知核对、权威回读与索引更新流程写回。原生 shell 不直接取得原库路径的读写权限，不增加第二条竞争写回路径。

## 委派与恢复

主代理调用 Hub 工具，子代理仅处理工作区任务。适配器拒绝子线程的 Hub 动态工具请求，不能依靠提示词授予业务权限。原生公开 collab 事件保留 receiver 身份与状态；公开命令/文件事件按稳定 item ID 更新。原始隐藏推理不进入展示。

本轮结束、失败、取消或进程退出时关闭该运行的 Windows Job，覆盖其后代进程。未结束的公开活动在历史回读中显示中断。子代理不在 Hub 退出后后台运行；恢复依靠已保存事件、工作区产物和后续新运行，不能声称旧子进程仍然存活。

计量区分主线程累计差值与观察到的子线程累计值；没有收到的子计量是未知，不补零、不重复累计。冻结 Token 额度对话在启动前拒绝子代理，直到可对所有子请求做完整预留与核算。冻结材料额度对话在原生命令输出能够完整计入额度前拒绝工作区。未冻结对话仍采用本轮取消/运行时控制和原生委派数量边界。

## 验收原则

以实际安装版协议、真实项目文档和日常库为依据。隔离临时工作区可保存真实职责文档的副本用于原生运行验收；不向日常资料库注入合成测试内容。单元测试的临时 fixture 不代表日常库验收。

功能是否存在、工具是否发生、界面是否显示、任务答案是否正确分别验证。同模型不等于同等环境；不据本轮接入宣称完整 Codex 功能或质量等价。跨端 #32 仍是独立运行/展示链路。

## 2026-11-17 应用和浏览器补充

本轮真实账号、日常来源、评论发布与历史接续的结果见 [Apps 与浏览器验收](AGENTS_CONNECTED_TOOLS_ACCEPTANCE_20261117.md)。

MCP、Apps、浏览器都从 Hub 主代理的工具调度进入，复用工具步骤、材料字节账本、真实结果保存、授权检查和事件顺序。发现侧车可以读取较大的正式工具目录（4 MiB 帧）；主模型帧限制保持 512 KiB。完整网关可能返回未启用应用的工具，必须按注册连接器身份过滤，模型仅取得已选择工具的 schema。所选目录超过 48 KiB 时拒绝，不能静默缺工具。

连接器绑定稳定账号 scope 与 provider link 指纹，不绑定会刷新的 access token。账号切换、连接变更、工具目录变更或撤销都要求重新授权；不自动换账号、重新 OAuth 或导入第三方密钥。Apps 返回不能冒充 Hub 的版本化原文、索引或业务写回。Hub 管理的 Craft / Obsidian / 滴答写入继续走原一致性入口。

GitHub 仅支持 `github.add_comment_to_issue` 写适配，要求明确的 `owner/repository`。模型调用只生成不可变草稿，绑定本轮决定、授权、连接、目标和正文。用户确认后先持久化执行状态，再发送一次；精确正文及 host 动作标记回读唯一匹配后记为 verified。中断 / 传输错误 / 回读失败保留 unknown；只能核对已有评论，不自动重发。已核验回执重复确认不重新写入；同决定的相同草稿沿用身份。新决定可重新准备从未发送的过期草稿；执行中、未知及已核验动作跨决定仍沿用原身份，不借重新准备重发。

浏览器使用 Playwright MCP 的实际 accessibility snapshot / target，不用公共网页抓取冒充交互。原生浏览器脚本和文件工具未暴露；所有页面与子资源请求经过 method / origin 校验，CONNECT 代理只连接本次预先校验的公共 IP。重定向也须重新通过代理。跨域字体、脚本等未授权资源会失败，并在真实回执中列出；不能据页面标题声称已完整读取。只在内联快照实际返回后记录来源。GET / HEAD 是请求方法约束，不保证任意远端 GET 端点没有副作用。

每轮保存实际授权的应用、工具及浏览器范围。浏览器只持续到该运行结束，下一轮重新导航；历史回读保留活动事实，不声称旧标签仍然打开。工作区的网络关闭约束不因外部工具或浏览器开启而改变。

通用 Apps 读取在技术上约束账号、连接、目录和具体工具及参数 schema；对象范围仍须遵守本轮任务授权，不能宣称任意连接器都具备 Hub 本地资料库的逐对象版本守卫。只有明确选择外部工具后才能查询该账号可访问的数据；“仅依据材料”会禁止外部调用。GitHub 评论另有精确目标仓库及 Issue / 正文绑定。
