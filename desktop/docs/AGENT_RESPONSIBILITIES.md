# Hub Agent 决策与执行职责

适用版本：0.16.393 起。模型自主选择方法，Hub 提供能力、反馈执行事实并守住执行边界。

## 决策归属

模型决定工具及 Skill 的选择、调用顺序、恢复策略、回答内容和未完成项。Hub 不以是否采用某个建议判定任务完成，也不强制简单问题查询资料。

Hub 自动负责参数校验、授权和预算、用户取消、消息持久化、上下文事件归属、写入幂等及回读、崩溃恢复。业务动作内部的可靠性步骤由同一执行入口完成，不拆成依赖模型逐次调用的必选步骤。

## 模型可用入口

| 入口 | 适用时机与返回性质 | 副作用及恢复方式 |
| --- | --- | --- |
| 搜索、`hub_read` 与共享读取工具 | 寻找相关材料、取得当前来源及引用；返回范围与版本，摘要不是原文 | 只读；按实际 schema 分页，来源变化需重新核对 |
| `hub_loadSkill` / `hub_readSkillReference` | 任务需要某种方法时按目录选择并加载 | 加载方法不增加授权；普通问答不强制使用 |
| `hub_toolSchema` | 不清楚参数或复杂工具采用按需格式时 | 只读本轮工具格式；不能取得未开放工具的权限 |
| `hub_traceResult` | 回查同事项已保存的完整工具结果 | 按摘要与授权核验，不重发原操作；历史结果不自动成为当前引用 |
| `hub_draftContext` / `hub_prepareDraft` | 需要制作内容时取得材料与格式并提交候选 | 准备草稿不等于保存到来源；按实际反馈修正 |
| `hub_inspectDraft` | 检查已有草稿、状态和回执 | 不重发写入；未知结果先核对原动作 |
| `hub_prepareArchive` | 需要保存阅读材料时准备来源、目标绑定的归档方案 | 可能消耗模型额度；不直接执行远程保存 |
| 已开放的业务写入工具 | 用户意图与现有授权允许时请求执行具体动作 | Hub 核验版本、身份与幂等，返回真实回执；禁止新建动作绕过未知结果保护 |
| `hub_citations` / `hub_finish` | 绑定当前引用或交付当前结果 | 不执行业务保存；形式及证据核验不等于通用语义正确性证明 |

工具实际可用性及输入范围以本轮公开目录、inputSchema 和执行守卫为准。上表不扩大权限，也不新增工具。小型参数错误直接返回格式，大型格式通过现有查询入口按需读取。

## 反馈与停止

`runtimeGuidance` 是宿主观察和可选恢复建议，不是新增用户指令。模型可以修正参数、选择其它获准方法、继续有目的核验，或说明证据缺口。

同一用户绑定、上下文代次、请求及错误连续重复时，在反馈已发送且出现新的公开模型输出项后提供一次提醒。反馈发送不证明提供方已经处理。后续没有新的信息时不重复提醒，也不因达到第四次失败而中断。请求、错误、用户绑定、上下文代次改变或成功进展可开始新的观察。

参数拒绝反馈标记 `toolExecuted=false`、`retryPerformed=false`，提供实际参数格式或本轮格式查询入口；不擅自修改模型参数或自动重试。普通运行错误不套用“未执行”的结论，尤其不能据此重试写入。

授权失效、用户取消、来源冲突及预算仍由现有宿主规则处理。模型不能通过重新建动作、改名、重试或回查历史重置这些边界。自动暂停的启发式策略不作为当前默认，也未新增未经验证的策略开关。

## 验收

确定性检查覆盖连续失败去重、无公开输出与并行调用、参数恢复、消息队列、压缩事件、预算和来源写入保护。有限真实模型检查覆盖简单问题直接回答、跨来源综合、错误参数后的恢复；专门的错误恢复场景会明确要求一次无副作用的无效调用，不把该测试路线当作普通任务的必选流程。

0.16.394 已完成本次三批规划的剩余验收：66 个不重复的静态工具及条件出现的 `hub_mcp` 逐项核对；补齐质量上下文工具 `learningGoal` 必填契约。116 个不同回归用例通过，另有目录导出、保存轨迹复验和真实同线程压缩资格验收。十类约定场景分别有真实模型、桌面或正式动作层故障注入证据，包括重复读取、连续失败恢复、运行中追加要求、取消后保存补充与恢复、未知写入核对和来源冲突。

隔离桌面实际验证报告预览、外部修改阻止旧草稿、同步后重新读取与保存，文件/索引/回执一致；最终 0.16.394 完整便携包重开后历史和回执保留，原事项续问成功。完整清单和证据层级见 [本次收尾报告](../artifacts/agent-autonomy-closeout-20261105/report.md) 与 [验证索引](../artifacts/agent-autonomy-closeout-20261105/verification.json)。前批记录仍保留在 `artifacts/agent-autonomy-20261105/`。

通过有限场景不代表总体完成率或误判率已经得到统计验证，也不扩大为任意来源通用写回；第三方服务工具的契约审阅不等于实际执行了每种业务操作。
