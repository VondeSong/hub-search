# 本地素材自动接入阅读

默认保存位置选择 Obsidian 后，Hub 桌面端可检查该库 `X/`、`Telegram/` 下的 Markdown，包含历史平铺目录与子目录。阅读的“同步与连接 → 设置 → 保存位置与同步频率”提供独立的“本地素材检查间隔”：默认 0，仅手动；也可设置 5–1440 分钟。移动新资料后可点“立即检查本地素材”，不触发联网收件或附件补写。定时检查仅在 Hub 运行时执行；重启沿用设置与上次检查时间，到期才扫描。超过一批的内容连续排空，切换库或关闭定时检查会在批次边界生效。

Sources 加入 Hub 资料库用于主界面全文搜索；X、Telegram 接入阅读用于阅读进度及阅读筛选。两者引用同一份本地原件，可以同时启用，不再生成一套原件文件。搜索使用 documents/blocks 与索引，阅读使用 collection_x_items 与本地文件回执；Hub 内存在相应快照、附件内容缓存和阅读缓存，不能将其描述为数据库完全零复制。登记整个搜索资料库与接入部分阅读材料互不替代。

本地检查间隔与已连接平台的联网同步间隔各自保存。仅修改频率时不启动导出或补写附件；手动检查也会更新检查时间，避免紧接着再跑一遍定时检查。默认仅手动时，普通归档只需保存原件；接入阅读使用受支持的检查入口，不直接写数据库。

原始 Markdown 和引用的附件始终只读。来源 URL、真实来源 ID、作者、原始日期、转发上下文和本地附件用于生成阅读缓存。未知来源字段不补造；缺失附件标记为部分内容，附件到达后再次检查。仅接入实际引用的附件，不自动下载远程素材。

去重优先使用 X 推文 ID、Telegram 消息 URL；缺少消息身份时比较已接入本地素材的正文、转发来源和附件内容哈希。频道主页只是来源，不作为消息 ID。重复文件及附件改路径不新建阅读条目；同来源的不同版本在 Sources 原样保留。Hub 中已有完整正文、回复和阅读状态优先，不以历史素材覆盖。X 原生同步先到或后到、以及已有 Hub 导出文件的复制均复用已有阅读身份；无法证明来源或内容相同的记录保守保留。

阅读状态和标签只在首次新建时参考明确页面属性，之后由 Hub 的当前状态负责。重复扫描、正文更新、改名和重启保留已读时间、标签、创建日期、归档和删除状态。正文内作者自带的标签不作为用户标签。删除 Sources 文件不会自动删除 Hub 的阅读缓存；删除 Hub 条目不会由后台扫描重新生成。

本地素材具有独立的原件所有权，自动导出、标题整理和阅读状态保存不回写或改名原件，也不触发 X 取消收藏。旧版一次性导入记录根据已保存的原件回执原位接入，保留原 item key 和状态。普通归档无需操作 Hub 数据库。

收集与保存设置显示检查状态和最近结果；读取目录或解析失败保留原件与已有阅读缓存，可手动重试或等待设定间隔。切换保存位置后按设置检查新库，原库已接入的内容继续保留；原库改名使用“重新定位原库”，沿用稳定的库身份。
