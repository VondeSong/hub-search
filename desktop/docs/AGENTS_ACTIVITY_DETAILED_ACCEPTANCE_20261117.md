## 本轮整改

1. 最终成功不能掩盖先前工具失败：整轮折叠时仍显示最近失败/中断及多项数量，网页警告独立保留。
2. 短工具行无详情时仍有“进行中、等待执行、未完成、已中断”状态文字。
3. 独立聊天首次纯选库绑定不再重复显示初始问题。服务端验证无历史、无运行、无 anchor、revision=1、原问题一致且无其它材料变更；保存显式标记，不篡改旧记录，真正重复追问仍保留。
4. 来源复核会临时卸载对话，导致展开选择丢失。新增按当前聊天/运行/工具组保存的内存选择，最多 256 项；只存布尔选择，不缓存正文或授权。切换聊天重置，来源复核与旧回答隐藏逻辑继续生效。
