# Android 日志对齐手机原型 v29

本轮接续 #22，目标是对齐 [现有手机原型的日志页](https://hub-mobile-lab-von11.song02211368537057.chatgpt.site/#logs)，先在 `emulator-5564` 验证，再编译可独立运行的 ARM64 APK。没有向实体手机安装。

## 依据与实现

原型 v29 的源码为 `102ce00ea0652f2ea22f94cda6e92f2c3e2ca003`，发布回执为 `appgdep_6afb17805884819198c18d9c78fe5715`。本轮把这份实际发布源码导入 `sites/hub-mobile-lab/`，64 份文件快照校验通过。Android 使用真实记录、原有版本与同步命令，原型中的演示状态没有替代真实回执。

- 顶部使用居中“日志”、返回浏览、搜索与更多；范围独立进入选择面板，AI 洞察和每日回顾保持轻量入口。
- 正文收起限制为五行高度；多图收起时最多三张 88px 缩略图，展开后为两列 160px 预览。附件数量单独说明，打开照片可查看原图。
- 展开不替换正文节点；顶部、底部均可收起，并把滚动位置带回原卡片。消除展开时图片重新加载和收起后找不到原记录的问题。
- 标签在正文中直接操作，避免正文标签之外再次重复一排标签；菜单、范围和设置弹层沿用主题，回收站恢复操作不再使用浏览器默认按钮外观。
- 录音页分开显示“检查中、未连接云端、云端暂不可用、可转写、云端未配置此服务”，明确本地录音可先保留，连接恢复后主动补转写。增加重新检查、连接设置和密钥说明；设置直接复用真实云端连接表单，不自动打开待核对聊天。
- 手机复用云端地址与设备密钥；阿里和 OpenAI 服务密钥由个人云端管理，不在手机重复填写。实际转写状态与“仅录音”分别说明，识别文字仍需确认加入正文。
- 从语音页进入连接设置后，表单返回和连接成功回到语音页，不再进入不相关的聊天列表；系统返回仍保留当前录音草稿。
