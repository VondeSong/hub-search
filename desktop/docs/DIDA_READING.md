# 滴答稍后读

0.16.234 起，已连接的滴答资料库在同步时将标签精确为“稍后读”的任务或笔记导入阅读。阅读顶部提供独立的“滴答稍后读”来源和同步入口，使用现有资料库授权；X 同步不会阻止点击滴答同步，同一资料库仍遵循自己的暂停与排队规则。

## 导入与删除

1. 从已授权清单发现候选，读取单项正文、类型、标签、清单、检查项及原附件库存。
2. 保存阅读正文和原始回执，下载并保存全部可识别原附件。本地默认为 Obsidian 时，同时保存对应页面与附件。
3. 重新读回正文、原始回执、文件及默认页面，核验内容版本与文件哈希。
4. 再次读取滴答原项。正文、标签或附件版本改变时保留来源，下一次同步重新核验。
5. 未启用阅读云同步时，沿用原来已验证本地副本的删除流程；启用阅读云同步时，还需满足下面的来源清理保护条件。允许删除后再次读取滴答原项确认；删除失败或结果未确认时保留本地回执，后续重试不重复创建阅读条目。

只有标签完全等于“稍后读”才进入导入范围。其他标签不触发此机制。Hub 创建的阅读副本及已有受管任务绑定排除在候选之外。

0.16.235 起，“稍后读”只用作来源筛选规则，不加入阅读标签。阅读正文保留标题、正文、补充说明、检查项和附件，不插入滴答的清单 ID、任务状态、优先级、日期、时区或标签字段；原始回执仍完整保留，继续用于导入核验。已导入条目的规则标签和系统生成正文会在本地初始化时一次性清理；已编辑的正文保留，已删除来源不会重新进入删除队列。本地 Obsidian 标签按已有属性更新机制刷新，旧页面正文在后续保存时更新，手动改动仍受原有文件核验保护。

滴答导入条目的预览不显示“打开原文”按钮，正文中的真实资料链接仍可打开。阅读顶部来源圆点按品牌设置：X 书签为黑色，Telegram 为 #2198D4，滴答为 #4a71f3。

## 授权与重开恢复

资料库连接通过滴答官方 OAuth 建立直连 MCP 会话。授权保存在本设备的安全存储中，不随阅读内容上传；应用重开时读取保存授权，必要时刷新，再为同一资料库建立新会话。撤销授权或刷新失败时，需要重新连接，不能把历史连接成功当作当前可用。

附件下载使用独立的同账号网页登录会话；OAuth 连接恢复不代表附件网页登录仍有效。附件会话缺失或账号不匹配时，保留滴答来源并提示处理。

## 阅读云同步与来源清理

阅读正文、状态、标签和已登记附件可通过当前活动的阿里云 OSS 或 WebDAV 服务同步，复用“设置 → 云同步”的连接与本设备策略；不上传整个 SQLite 或滴答授权。原云目录和历史记录保留，服务迁移不删除旧数据，历史清理由独立维护入口明确执行。完整合同见 [Hub 云同步](CLOUD_SYNC.md)。

**阅读云同步模块启用时，滴答来源清理默认关闭。** 关闭自动同步或总开关只暂停相应传输，仍保留这项来源保护；没有当前完整云副本时不删除原项。桌面用户明确开启来源清理后，实际采集流程才会重新核验原始任务快照、当前正文、全部原附件、本机副本和当前认证来源，并取得仅用于本次在途操作的短时许可。手动执行“来源恢复凭证”检查本身不会删除滴答原项，历史成功记录也不能直接授权删除。

**关闭阅读云同步模块时，继续遵循原来已验证本地副本的流程。** 来源清理开关不替代原流程的正文、附件、默认保存位置、来源版本和账号核验；不能把这个开关理解为所有滴答导入操作的总删除开关。

手机用于阅读、修改状态和标签、归档及恢复云端阅读记录，并可查看或按需下载附件与副本记录。不提供资料库保存位置管理、来源清理、设备退休或云历史删除；来源级凭证需要原采集设备上的本机回执，不能由接收设备的阅读副本代替。

## 保留来源的情况

正文读取失败、附件库存未知或不完整、原附件未下载完整、本地页面或原件读回失败、存在未迁移子任务、授权与附件会话不能匹配、资料库暂停或移除，均不会删除滴答原项。`childIds`、`child_ids`、`children`、`childTasks`、`child_tasks` 中任何存在的子任务库存必须为明确的空数组；未知库存、多个任务或不一致身份均保留来源。附件读取使用已有的同账号网页登录会话，无需另建附件账号。需要处理的结果通过底部信息栏与阅读处理记录说明。

远端删除与本地提交由持久回执连接；应用重新启动后继续核验未完成记录。取消阅读条目的附加保存位置是另一项操作：只取消选择和未来复制，保留已同步的远端副本。

## 验证记录与边界

真实测试已限定在专用测试清单与独立本地、云目录内完成导入、原附件与云恢复核验及活动来源清理，详见 [R5 联调记录](READING_DIDA_R5_0.16.237.md)。R5 的来源调用经受限连接桥执行；该记录不能替代 Hub 直连 OAuth 验证，也不宣称服务端永久硬删除。

Hub 官方 OAuth 直连、已有前端启动流程恢复保存授权并重新建立会话，另在独立运行目录验证，详见 [同步收尾记录](CLOUD_SYNC_CLOSURE_0.16.237.md)。这项检查只读取偏好，不枚举或修改账号任务；未强制触发真实令牌过期刷新。正常运行仍逐次核验账号权限、附件网页登录与网络；缺失时保留来源并提供状态。
