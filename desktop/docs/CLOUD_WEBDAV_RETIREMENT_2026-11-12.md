# WebDAV 云同步退出记录（2026-11-12）

本轮按用户明确要求，删除坚果云及通用 WebDAV 同步。关联 [Issue #3](https://github.com/VondeSong/hub-search/issues/3)。当前活动云同步只支持阿里云 OSS；不发布版本或安装包。

## 实现与升级行为

- 删除桌面／Android 共用界面的 WebDAV 服务选择、地址账号密码表单、保存／测试操作和反向迁移入口。
- 删除对应 Tauri 命令、闪卡快照／附件 HTTP 传输、阅读 WebDAV 对象适配器及两种服务互迁代码。未知或旧服务不能回退为 WebDAV；旧配置无有效活动 OSS 时显示尚未连接。
- 升级不删除本机正文、原附件、待同步队列、旧元数据、安全存储中的旧凭据或旧云端文件。旧凭据不再作为可用服务参与账号迁移。用于格式回归的历史快照离线解码参考和历史检查点字段保留，不能建立旧服务连接。
- **仅存旧云端的内容，应先用旧版取回。** 新版不读取旧 WebDAV，不承诺自动取回尚未在本机的数据；启用 OSS 后按普通同步处理本机已有内容与目标目录。
- 首次启用 OSS 只保存活动连接，不执行完整迁移、不虚报内容同步成功，也不越过暂停或附件策略。更改已启用 OSS 的云位置继续复制、逐项读回、重查范围和本机版本，失败保留原配置；已绑定速记仍拒绝迁移。
- 三模块上传／下载类型与单文件上限继续独立；已移除的每轮／每日用户额度不恢复。连接草稿保留、局部失败继续其它模块与恢复状态刷新沿用既有实现。

## 原型与来源

后续已补齐连接摘要、按需凭据表单及分步连接／迁移，并接入先检查候选再保存的真实入口，见 [云连接原型对齐记录](CLOUD_CONNECTION_FLOW_2026-11-12.md)。以下记录保留 WebDAV 退出阶段的实际检查范围。

`sites/hub-workspace/` 同步删除 WebDAV 配置和互迁，并将旧浏览器配置转为停用状态，保留模块、附件偏好及待传记录。源码状态检查、TypeScript 与生产构建通过；本机浏览器实查旧连接提示和 OSS 表单，未显示旧服务编辑或反向迁移。

现有 Sites 项目可读取，但申请原项目写入凭证返回 `Sites project not found`。线上仍为 v80，此改动仅保存于 GitHub 源码，尚未发布到原站。`.source-snapshot.json` 保留真实 v80 来源，没有伪造新部署。恢复原项目的发布能力后应沿用同一 project_id 发布，不新建替代站点。
