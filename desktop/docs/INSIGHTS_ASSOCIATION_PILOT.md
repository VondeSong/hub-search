## 本批可体验流程

洞察 → 更多操作 → 寻找旧知识 → 选择原事项 → 输入关键词 → 查找 → 查看原文 → 在原事项核对。

- 使用原事项当前授权中明确选中的 1–32 份笔记，含固定清单的成员；不使用整库授权。其他类型资料继续从原事项处理。数量是本次小范围试点的边界，不替代助手的通用授权能力。
- 复用现有证据读取器，按标题／正文中的词面查询，最多展示 10 份候选；原文按当前授权与候选版本重新读取，每段最多 2000 字符，可向前或继续阅读。
- 检索结果只代表候选，不自动建立关联、保存发现或改变任务状态。零结果保留“换关键词／未必没有相关知识”的说明；同词但不适用的材料仍须人工或原事项助手判断。
- 回原事项时带入针对关键词的核对提问，要求读取原文、区分适用条件及反例，并根据明确证据区分计划、原型验证和实机完成。先由用户选择使用提问，再按现有发送入口运行；不自动调用模型、不覆盖当前输入、不扩大资料权限或执行预算。新成果仍通过首批选择器显式保存／更新。
- 补齐原事项接续的来源身份比较：除笔记外，普通无锚点对话、阅读、任务和附件也按对应身份核对；不放宽笔记编辑边界。
- 关联试点不等于已实现语义召回、自动完成状态判定、跨 Work 合并、后台扫描、阶段回顾或长期监测。

## 小样本观察与本批验收口径

先在四份授权合成笔记、两份未授权干扰笔记上观察现有检索，不调索引或增加嵌入模型。原生回执 `2b67775c-f9a7-46a3-93ad-633e6654496e`，7 次查询：

| 查询 | 返回 | 判断 |
| --- | --- | --- |
| 验证 | 方法前置与孔位方法，两份 | 两份均能回到原文 |
| 输入 | 方法前置，一份 | 精确词面命中 |
| 接口／孔位 | 孔位方法与旧椅子干扰，各两份 | 同词但不适用的干扰也会返回，不能按命中建立关联 |
| 阅读 | 阅读计划，一份 | 可定位原文，是否适用于当前问题仍需判断 |
| 降噪耳机 | 无 | 无材料时保持空结果 |
| 验收门槛 | 无 | 近义的“通过条件”没有被召回，属于明确限制 |

单次查找观察约 16–53ms，仅本机原生读取，不含界面渲染；不外推性能 SLA 或语义召回率。原始计时在忽略目录 `.local/insights-next-phase/keyword-baseline.json`。

据此冻结本批检查口径：词面样本的具体候选符合上表；返回内容不得超出当前明确授权，未选中同库文档与另一库干扰均为零泄露；原文须版本准确、可定位；撤权／版本变化后旧读请求不能继续显示；检索不写 Work、Run、发现、任务或来源；空结果与词面干扰不被提升为有效发现。若增加语义召回或自动状态判定，另准备有代表性的相关／不相关／无答案样本并评审，不用这组词面夹具证明语义质量。
