# Agents 新旧版本同题对照验收（2026-11-17）

对应 [#57](https://github.com/VondeSong/hub-search/issues/57)，方案见 [固定验收计划](AGENTS_COMPARATIVE_PLAN_20261117.md)。#14、#56 的限定 Windows 完成范围保持原结论；本轮没有发布安装包，没有修改生产能力或模型提示，没有使用 Ponytail 或子代理。

## 可以得出的结论

今天的版本扩大了可明确授权的工作范围，也补强了公开过程展示；这次同题实测没有证明基础问答全面更准确或更快。昨天的版本已经能够完成本批资料问答。两版均完成四项任务、六轮回答，保留十篇材料任务的三轮历史，未产生业务写回或写入草稿。

答案仍需要复核。新版长任务首轮将 project-steward 的“仅读取相关主路径和必要方法”写成“只读相关路径”，容易被理解为整个技能只读；第二轮明确纠正。旧版首轮也有将内容组织层级、预期产出表述得偏确定的地方，第二轮收窄。两版最终结论均区分用途说明、当时本机记录与实际验收，不能据此宣称任一系统已具备完整 Codex 能力。上述修正来自本次计划中的真实复核轮，不能把首轮追认为完全正确，也不能外推成默认单轮总会自行纠错。

## 正式检查与构建准备

正式节点为 `agent_work::runner::native::flow_acceptance::live_native_version_comparison`，入口 `node scripts/test-rust.mjs`，参数 `--ignored --exact --test-threads=1`。两候选分别先 collect-only，均实际收集一个唯一节点，再正式执行；各一个节点通过，节点内部各完成四项、六轮。没有运行整个 Rust 或前端套件。

旧版 collect 前首次构建因独立代码 worktree 缺少生成的 memory-runtime.zip 失败，尚未发送模型请求。核对同一资源生产脚本、descriptor 与锁定输入后复用已生成包，旧版正式 verify 完成逐文件完整性校验，再构建成功。失败回执保留，不计为模型质量失败；也不据此声称干净 CI 资源编排已验收。两版编译分别约 4 分 18 秒、4 分 23 秒，既有编译警告保留。

本轮测试驱动在真实执行后仅做 rustfmt 空白格式整理；`npm run format:check` 与 `git diff --check` 通过。未改生产代码，因此没有为形式重复整仓测试或再次消耗模型。

## 容量及仍未覆盖的范围

长任务实际是十篇材料、三轮、约四分钟的连续任务，不是小时级长稳。旧版累计保存 12 条 agentStream 记录、14,492 字节 text，新版 10 条、15,504 字节；含 contextUsage 等记录，不等同可见过程行数。都远未触及 1024 条或 512 KiB 文本限制，不能据本轮宣布真实阈值已验证。此前确定性容量测试继续独立保留。

同题对照只覆盖共同的资料问答路径，没有新测全部插件、浏览器、原生工作区或子代理。功能范围的扩大以 #14 的独立真实验收为据；图片、短计算、网页搜索、Hub 技能和共享记忆是此前已有能力，不列为本轮新增。

仍可独立扩展的项目包括通用电脑操作、带个人登录态的浏览器接管、更多写插件适配、图像生成与 artifact 等宿主能力、小时级或自然触达容量阈值的任务，以及 #32 跨端链路。它们不是更换图标即可补出的功能，也不因本轮对照通过而被标为完成。
