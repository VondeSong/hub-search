日期：2026-11-17 至 2026-11-18。对应 [#58](https://github.com/VondeSong/hub-search/issues/58)，接续 [总规划](HUB_CAPABILITY_PLAN_20261117.md)。Windows x64 日常真实资料库，产品版本 0.16.396；没有发布安装包。#14/#56 的既有限定完成不重新计作本轮成果。

## 实际增加的能力

用户可以从真实笔记中选原图或 PDF 页面，把缓存中的数据附件或本地 CSV/XLSX/JSON 加入对话。Codex 提供方能够在独立、固定依赖的 Python 环境中实际计算，生成文件，再沿用同一成果修订、打开、导出和继续讨论。外部公共文件也可以在已授权 HTTPS 域名内获取，随后按页或作为数据文件读取。

这一轮补的是输入、执行及成果管理，不是提高模型本体的智力。没有完成同条件 Codex 产品反复对照，不能说已全面达到 Codex，也不能宣称整体提速。移动端没有插入桌面主线；跨端 T17 仍由 #58/#32 的后续验收跟踪。

## 实现边界

| 能力 | 实际合同 |
| --- | --- |
| 图像与 PDF | 每聊天最多 8 个图片/页面授权；库内单图最多 4 MiB，本地粘贴仍为 256 KiB；页码、附件及父笔记版本参与授权。不静默缩坏工程图。原生输入上限 24 MiB，普通事件帧仍保持既有限制。 |
| 分析输入 | 最多 8 个 CSV/XLSX/JSON 文件，每个 10 MiB；来源附件保留对象、父版本及哈希。本地文件是显式选择的不可变副本，不能冒充已索引来源。 |
| 执行 | Windows x64、Codex 原生工具；固定 Python 3.13.17 及固定 pandas/numpy/openpyxl/matplotlib/reportlab 包，包哈希及执行前文件完整性检查；MXC 内离线运行，只读输入与旧成果副本。120 秒、2 GiB、8 进程，工作目录监测上限 192 MiB。 |
| 文件成果 | CSV/XLSX/JSON/PNG/SVG/Markdown/PDF，最多 16 文件、总计 50 MiB；校验实际格式和哈希。稳定成果身份与递增版本，旧版标记已被修订，空输出仅登记检查回执。 |
| 导出 | 用户选择本地目标；不覆盖已有不同内容；写后回读哈希，重复同一导出沿用回执。文件导出和知识库归档是不同结果。 |
| 外部资料 | 只允许已授权公共 HTTPS origin，限制跳转、类型、文件大小和实际内容；没有继承个人登录态。下载回执不等于模型已阅读。 |
| 续做 | 上下文带文件清单、覆盖账本、实际运行端能力和经过哈希复核的最新 Markdown 成果正文（总计最多 24,000 字符，单份最多 12,000，截断明示）。旧结果仅作材料，不作为新指令或本轮执行证明。 |
| 权限及计量 | 来源撤销/版本变化使相关成果不可继续使用；冻结材料额度尚不兼容完整文件分析，明确拒绝。不静默换提供方；DeepSeek 可以继续讨论已验证成果，目前不能运行这条原生 Python 路径。 |

容量是执行限制，不能理解为已经实测所有 10 MiB、5 万行或 10 工作表组合。XLSX 不执行宏，不承诺公式重算；公式与缓存值差异需要在具体分析中说明。首次环境准备依赖固定官方包可达，准备失败不会当作分析成功。

## 测试发现并整改

1. 公共 PDF 缓存使用混合斜杠，Rust 能读但 Windows 渲染接口报路径无效。验证文件后返回规范绝对路径，真实下载、渲染和模型首页读取均通过复测。
2. 新版成果没有进入非原生提供方的完整上下文。现在传递真实文件清单、能力事实、覆盖账本及已验哈希的当前 Markdown 报告，历史结果不能被当作新指令。改动有撤销、旧版、篡改保护回归，并完成真实 DeepSeek 复测。
3. 原型设计和分析文件前端的打开/导出/错误状态已接入正式组件。历史分页测试落后于已有“打开时刷新”行为，修正断言并完整复跑，未为通过测试取消刷新。
4. 新获取文件使用独立下载语义，避免把文件获取事件显示成真实浏览器交互。
5. 真实停止后续做发现只读能力状态查询被误算为业务操作，导致自然答复未通过交付校验；仅将该明确只读工具归为观察，分析及其他有副作用工具继续要求结构化交付。
6. 之前真实探针暴露的空输出被误算成果版本、静态 Matplotlib SVG 声明被拒、文件格式仅看扩展名等问题已整改；保留最初失败，最终成功不抹去失败记录。
