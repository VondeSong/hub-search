## 实际增加的能力

用户可以从真实笔记中选原图或 PDF 页面，把缓存中的数据附件或本地 CSV/XLSX/JSON 加入对话。Codex 提供方能够在独立、固定依赖的 Python 环境中实际计算，生成文件，再沿用同一成果修订、打开、导出和继续讨论。外部公共文件也可以在已授权 HTTPS 域名内获取，随后按页或作为数据文件读取。

这一轮增加了输入、执行及成果管理。后续补验已完成两组真实材料、每组每产品三次的 Hub/Codex CLI 对照，详见下文；没有验证 Codex 桌面宿主的全部交互，也没有证明模型本体更聪明或整体提速。移动端没有插入桌面主线；跨端 T17 仍由 #58/#32 的后续验收跟踪。

## 测试发现并整改

1. 公共 PDF 缓存使用混合斜杠，Rust 能读但 Windows 渲染接口报路径无效。验证文件后返回规范绝对路径，真实下载、渲染和模型首页读取均通过复测。
2. 新版成果没有进入非原生提供方的完整上下文。现在传递真实文件清单、能力事实、覆盖账本及已验哈希的当前 Markdown 报告，历史结果不能被当作新指令。改动有撤销、旧版、篡改保护回归，并完成真实 DeepSeek 复测。
3. 原型设计和分析文件前端的打开/导出/错误状态已接入正式组件。历史分页测试落后于已有“打开时刷新”行为，修正断言并完整复跑，未为通过测试取消刷新。
4. 新获取文件使用独立下载语义，避免把文件获取事件显示成真实浏览器交互。
5. 真实停止后续做发现只读能力状态查询被误算为业务操作，导致自然答复未通过交付校验；仅将该明确只读工具归为观察，分析及其他有副作用工具继续要求结构化交付。
6. 之前真实探针暴露的空输出被误算成果版本、静态 Matplotlib SVG 声明被拒、文件格式仅看扩展名等问题已整改；保留最初失败，最终成功不抹去失败记录。

### 又发现并修复的两个真实缺陷

1. **普通会话无法手动整理上下文。** 可选 Token 限额未设置时，预算视图没有 `canAdmitRun`，原判断把它当作额度不足。现在允许未配置限额的普通会话提出整理请求；已冻结且耗尽的额度继续拒绝，未知用量和预算根保留。新增普通/耗尽两条回归，与原有身份绑定、取消检查共 4 条通过。
2. **120 秒分析被 25 秒握手时限提前终止。** 真实 30 秒脚本复现 `Agent 会话握手超时`。仅对分析的执行响应等待设置 130 秒，保留命令自身 120 秒上限和外层取消/容量守卫；初始化仍用短握手。修复后 30 秒脚本成功，130 秒脚本被执行超时终止，后续正常计算仍成功。
