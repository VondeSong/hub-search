# 资料库管理

资料库更新在后台运行。每个资料库有自己的运行状态与排队入口，不同库可以同时推进；共用账号仍受服务端限流影响。模型、推理强度、速度与 Codex 请求并发继续由「设置 → Codex」统一管理。

## 添加与日常操作

添加资料库时先填写实际连接与读取范围，然后选择内容策略及「添加并开始」或「添加，稍后开始」。稍后开始会保存暂停状态，重启 Hub 后也不会自行启动。Obsidian 读取范围使用现有排除路径；Craft 读取范围由连接授予的权限决定。

资料库行提供暂停/继续、同步一次和更多操作。名称、裁剪后的图标、Obsidian 排除路径、内容策略与支持的备份功能放在更多操作中。飞书沿用已支持的读取能力，不提供写入或附件识别的无效控制。

暂停会先保存控制意图，再停止接收该库的新工作。同步、文件监控、附件处理和收藏复制在安全边界停止；已完成的正文、附件和远端对象标识保留。正在发送的远端请求可能先返回结果，保存对象标识后不再开始下一步。继续后使用原队列及已有副本补齐，不重新创建已确认的远端对象。取消当前处理也保持暂停，需明确继续。

同步一次不会绕过暂停。单库暂停不改变其他库状态。监控阶段与处理阶段显示在对应库行，操作结果和错误显示在底部信息栏。

## 内容策略

全局默认可由单库覆盖；单库选择「沿用全局」时，后续全局修改仍会生效。

| 设置 | 控制内容 |
| --- | --- |
| 下载图片原件 | 保存图片供预览，不要求同时开启 OCR |
| 图片文字识别 | 将已缓存到 Hub 的图片文字加入搜索 |
| 下载 PDF 原件 | 保存 PDF 文件供预览 |
| PDF 原生文字 | 提取已缓存到 Hub 的 PDF 原生文字 |
| PDF 扫描页识别 | 识别已缓存到 Hub 的 PDF 扫描页文字 |
| 视频与其他附件下载 | 在支持的远端来源下载原件，不分析视频 |
| 写入时携带附件 | 收藏复制到此库时是否携带附件，正文仍复制 |

读取资料库的普通正文始终保留。识别依赖原件；关闭下载后仍可处理此前已缓存到 Hub 的原件，不为识别隐式下载新文件。PDF 原生文字与扫描页识别分别控制。Obsidian 原件在本地，导入与读取不会删除 Vault 文件。

保存策略只影响后续处理，不会自动将历史资料加入队列。需要补处理时，使用该库的「按当前策略补处理已有内容」；暂停状态下不会绕过暂停执行。关闭附件复制也不删除以前已经上传的附件。

收藏与待读继续保留默认本地原件，并向额外资料库复制。Craft 附件大于 5,000,000 字节时跳过上传，正文与合规附件照常保存，本地原件不删除。视频仅随附件保存，不要求 Codex 解析画面或声音。滴答参考资料使用笔记类型，保留内容标题和原文，仅从已有标签中选择。

## 移除与保留

移除请求立即受理，相关工作停止后在后台清理本地搜索索引。Obsidian 原文件和远端内容不删除；可复用的缓存、来源映射与已有远端副本标识保留，防止重新添加后重复创建内容。已移除的库不出现在可用资料库和搜索结果中。

如果该 Obsidian 路径同时是收藏的默认保存位置，移除搜索连接不会自动修改收藏设置。需要停止往该目录保存新收藏，应在收藏保存设置中明确更改默认位置。

## 运行边界

控制意图使用数据目录中的独立持久文件，不等待正文写入锁。数据库提交分批进行，文件读取和 Blob 保存尽量在写锁外完成。暂停不会回滚已经成功的远端请求；结果不确定的写入仍保留待核对状态，不宣称上传完成。

本次没有增加时间窗、批量库控制、策略模板或预计空间等后续功能。
