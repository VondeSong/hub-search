# 手机闪卡与移动原型对齐（2026-11-15）

## 视觉依据与纠正

本轮以 [Hub 手机原型的复习页面](https://hub-mobile-lab-von11.song02211368537057.chatgpt.site/#review) 为视觉依据，实际打开第10版的今日、牌库、收件箱、问题和答案页面。来源快照 `5832222529b286a0db53f1ab03e2984cf080d4e4`，源码位于 `sites/hub-mobile-lab/`。工作台闪卡原型100提供的体验需求继续保留，但不能代替手机原型的布局。

此前 `d0a235d` 完成手机体验能力时，仍保留旧渐变大卡片、模块底部三导航和四色评分条。`f2a313e` 修复发布包启动以及评分区不可见，实机能打开不代表手机原型完整还原。用户再次指出差异后，本轮按移动原型重新实现相应页面，没有修改原型来迎合旧客户端。

## 对齐范围

| 页面 | 手机原型 | 本轮实现 |
| --- | --- | --- |
| 导航 | Hub顶栏、全局五导航；页内今日/牌库/收件箱 | 接回真实全局导航，页内切换保留已有会话，不重复出现模块底栏 |
| 今日 | 普通标题、简洁进度与蓝色按钮、灰底牌组组、管理组 | 使用真实今日计划和本轮进度，已有暂停轮优先继续，不以预览计划替换 |
| 牌库 | 灰底牌组行、卡片与待学习数量、点击打开牌组 | 使用真实牌组，原有文件夹、新建和整理功能收进管理牌组 |
| 收件箱 | 草稿卡片、问题/答案、来源与采用入口 | 采用前仍选择真实目标牌组；完整依据、媒体、反馈和批量功能保留在详情/整理入口 |
| 复习 | 专注顶栏、问题/答案单面灰底卡片、两列浅色评分、来源 | 保留真实题型、原生间隔、评分与来源；编辑、反馈、暂停等收进更多操作 |

实测原型参数：页面边距20px；标题30px/1.25；页内切换最小48px；组圆角20px，行最小76px；翻卡圆角24px、最小300px（短屏225px）、正文21px/1.7；评分为两列，间距8px、最小66px。颜色复用原生手机主题变量，纯白/纯黑/暖纸和强调色继续沿用现有设置。Windows页面保持原样。

## 真实数据与原生能力

- 原生计划、每日额度、临时额度、暂停/恢复、评分、计时、来源、备份和云同步协议不变。没有引入原型示例卡、示例间隔或演示备份。
- 今日卡片堆预览、真实计时估算、七天节奏、已学卡到期、复习偏好保留在“学习计划与统计”。原有未完成队列不会因切换页面重建。
- 牌组待复习数包含等待安排的新卡，与受每日新卡额度限制的今日计划分别说明，不制造加总相等的假数。
- 原型“暂不采用后恢复”是浏览器示例。真实收件箱沿用已有移除语义及确认，不承诺尚未实现的恢复能力。
- 独立包不依赖Vite；模拟器开发预览与最终独立包分别核验。真实资料截图只保留本机，不上传原型或仓库。
