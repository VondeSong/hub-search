# 手机日志第三段视频复刻与底部占位修复

日期：2026-11-16。事项：[#22 日志与速记](https://github.com/VondeSong/hub-search/issues/22)，父任务 #40，平台跨端。本轮只更新现有手机网页原型、Android 前端及模拟器验收，**未操作或安装实体手机**。

## 结果和原因

截图底部空白是已隐藏导航栏留下的 **84 CSS px 底部 padding**。日志页只覆盖了网格行和高度，没有覆盖通用 Android 主区域的 `padding-bottom:84px`。现在在日志布局中将它归零，滚动区内仍保留浮动按钮所需的末条记录间距和系统安全区。

原型原先仅给 body 设置很浅的灰底，内部 `.app` 的白色背景把它覆盖，白卡因而几乎不可见。现改为日志实际容器灰底／白卡，12 px 卡片间隔、18 px 圆角，深色页面和卡片使用各自主题层级。Android 使用同样结构。

视频文件名 `01ad80d412a18c70a0b217462831e36e.mp4`，SHA-256：`1a6129cf57d235a0e20e646802578402d0b13a0bef78a881b3217f692f68d725`。

- 576×1280、24 fps，视频轨 37.750 秒，共 **906 帧**；全部解码并逐帧计算变化量与时间戳。
- 检查七张连续联系表，放大排序菜单、多选卡片和三个筛选弹层；约 2.2 秒／4.3 秒是新建输入打开与关闭，后半段主要为搜索筛选。
- 原始视频、帧图、联系表和私人截图留在本机 `.local/flomo-mobile-prototype-20261116/latest-video/`，不上传至 GitHub 或 Site。
- [逐状态对应和时间线](../../sites/hub-mobile-lab/docs/journal-video-2026-11-16.md)。尺寸按约 390 CSS px 宽参考设备估算，沿用现有 Hub 主题和组件。

## 本轮对齐的行为

| 参考行为 | Android 和原型实现 |

保留 v16 已完成的新建富文本、同 ID 编辑、历史、改期、冲突和原页同步。Hub 按已有约定不显示具体时分秒，旧记录没有创建时间时不伪造，故排序使用“记录日期”；缺失编辑时间时明确回退到记录日期。“有语音”只筛选已有音频附件，不代表语音录制／转录专项完成。

批量修改复用 `update_quick_journal` 的真实 ID 和版本校验，保留原文、附件和历史；部分失败保留未成功的选择，重试不再次写入已经成功的记录。原型则使用已有浏览器事务和失败回滚，不冒充真实同步。
