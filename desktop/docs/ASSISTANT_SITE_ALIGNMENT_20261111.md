## 数据与兼容性

数据库升级至 schema 85，为既有 schema 84 数据库安装通用专题和回答保存回执表。升级保留 Work/Run、来源、已用/待核验预算及未知业务结果；表结构不兼容时回滚，不提升版本冒充成功。正式备份沿用完整数据库，不另建依赖某台电脑的专题文件。

来源范围切换在无活动执行、无待核验业务写入且版本一致时生效；保留同一 Work 和累计用量。原固定方法的 topicBinding/manifest 禁止经通用入口替换。
