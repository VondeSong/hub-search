# 移动端助手与多段录音整理（2026-11-17）

本轮对应 #32 的手机助手命名与连接入口，以及 #22 的语音草稿／补录体验。以用户提供的 Android 截图为问题依据，沿用现有样式和真实 IPC。

## 本轮改动

- 移动端入口、顶栏、无障碍名称与相关说明统一为“助手”，内部 agents 路由、API 与凭据不迁移。
- 连接状态移到助手顶部，可直接进入现有连接与设备设置；会话列表中间的大卡片移除。断网、登录和额度限制继续显示实际状态。
- 原录音在追加时默认折叠，本次新增独立列出，每段配对自己的转写。所选服务已完成的段不再重复展示补转写按钮，未确认的新文字保持可校对。
- 未保存内容明确标为恢复草稿；普通保存关闭，只有主动点“保存并新建”才开新记录。只浏览已保存录音而没有修改时不再留下一份待保存草稿；若只读访问后进程中断，下次也不把原记录当作新草稿。旧版本没有变更标记的草稿保守保留。
- 暂停／继续保持同一段，结束后再录生成新段，追加更新原日志 ID、保留原音和正文；不把补录、补转写与新建日志混为一谈。

[产品调研与取舍](../../sites/hub-mobile-lab/docs/assistant-voice-2026-11-17.md)比较了 flomo、Pixel Recorder 和 Obsidian 的官方文档。决定采用一条日志包含多段原音，不物理拼接旧音频；历史段只在明确操作后转写，沿用原有任务身份和重试保护。
