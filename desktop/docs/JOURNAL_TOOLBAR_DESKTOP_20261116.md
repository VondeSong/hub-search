# 桌面日志工具栏与筛选对齐 v102

本轮接续 [#22](https://github.com/VondeSong/hub-search/issues/22) 的桌面范围，依据工作台原型 v102：[原型提交 cff5eeb](https://github.com/VondeSong/hub-search/commit/cff5eeb0af12c7f03c6aea99c4429c2c5dfa9540)、Site 来源 `d9a362c57a10d5eafb1c19d55226546a51c91f05`。没有再次发布 Site，也没有把原型示例数据移入客户端。

## 桌面实现

- 紧凑视图栏、单一常驻日志搜索、可独立清除的日期/资料库/内容标签、真实匹配日志数量及每日记录中的任务数量。日志页原全局搜索收进该入口，布局切换、预览开关及窗口拖动能力保留。
- 详细条件使用原生 popover；资料库来自真实连接并与当前范围相交。`null` 表示全部，`[]` 表示明确空选；勾选第一项从不限范围切为所选范围，不创建原型中的假 Hub 来源。
- 新增视图用命名 dialog，保留重复名称和数量上限校验；已保存视图修改后可更新或恢复。沿用原有用户配置存储键，没有迁移或清空已有定义。
- 卡片布局复用顶部搜索与筛选，移除重复搜索/范围控件；保存位置及同步设置仍可访问。
- 每日记录有筛选时按命中日期展示，读取选定范围的完整分页快照，解决历史正文命中却不在当前写作周内的问题。结果日期分段展示；无筛选时保留连续日期与空白写作日，按月范围停在月末。
- 指定日期与月份归一，月份变更清除旧定位锚点。全日期月历保留全局匹配数量，提供各匹配月份跳转。
- 筛选、视图 popover 和命名 dialog 均隔离 Escape；修复 WebView 将 Escape 发送给 body 时，外层快捷键误隐藏 Hub 的风险。

业务仍使用真实 `journal_page`、记录索引、原生速记和共享任务数据。未改 Rust、OSS 协议、记录编辑协议、任务状态写回或 OS 日记格式；本轮没有执行真实记录新建/删除或同步写入，没有新增客户端示例内容。
