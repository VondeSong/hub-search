## 已实现的接入

- 读取已正式发布的固定 delivery，以 Work、Run、record ID、原始保存字节 SHA256 和 finding pointer 定位候选。主助手增加可选 findings 交付，普通正文仍可省略该字段；不从正文自动拆卡。
- 首次保存分配稳定 ID；内容修订、出处映射、用户事件分表持久化，同事务提交。相同操作按摘要回放已提交事实，相同出处返回原映射，不重置处理状态；错目标、改载荷和过时新命令拒绝。
- 每条发现分别核对自己的直接引用与显式共同背景。来源变化、来源不可访问、用户纠正、备份恢复和已采用补充变化分别留原因，部分核对不清空其余原因。冻结集合的已有成员分别检查，不扩大到新增材料。
- 状态支持待关注、稍后一天、已处理、到期、关注偏好与补偿撤销；新成果需明确关联原发现，拆分／合并保留新 ID 和人工替代关系。
- 反馈保留用户原话；显式继续时写入原 Work 的正式用户消息，再运行既有助手。更新时核对消息、Work 修订、实际 Run 绑定和用户确认的采用关系，用户补充单列，不能伪装为资料原文。
- 当前无法访问时隐藏正文、引文、背景和受限历史；前端在变化事件、重新聚焦和恢复可见时隐藏敏感缓存，并拒绝重新显示权限变化之前尚未返回的响应。重新聚焦时保留当前发现的身份和未保存反馈，核对通过后恢复详情；实机发现并修复了此前直接关闭详情的缺陷。未知写入保留原请求身份，先核对提交结果，再选择重试或放弃未提交请求。
- 整库备份包含四张业务表。每次恢复都建立新的访问确认边界，不能沿用旧确认；重新确认仅核对本机已同步资料，不声称已经核对远端最新内容，不自动恢复后台运行。
- 桌面已有全局导航增加洞察，复用现有原事项面板、引用预览和主题颜色。浏览、筛选、保存、状态、反馈保存、来源核对和恢复均不调用模型；只有显式继续核对运行助手。
