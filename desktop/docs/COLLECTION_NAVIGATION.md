# 阅读导航

自 0.16.233 起，阅读使用自己的导航和视图配置。搜索界面的智能集合仍属于搜索，不会出现在阅读导航中，也不会被阅读的筛选或视图管理修改。0.16.234 将界面名称统一为“阅读”，中栏标题使用其他页面相同的字号和字重。

## 阅读原型与桌面

工作台的「阅读」入口提供四种布局和十四个可切换的验收场景。桌面热开发版使用当前配置的阅读库、同步记录与 Agents 入口。

精简阅读流在窗口宽度足够时左边浏览、右边读文。表格、看板、画廊和「需要处理」全宽显示，点选条目进入阅读，收起时返回原列表位置。在窄窗口打开阅读后，标题栏提供「返回列表」。切换布局保留正在使用的搜索、筛选和排序。

列表和表格选择两篇或以上后，可批量标为已读、进行中或归档。某条失败时保留失败项的选择。使用 / 搜索，J/K 切换文章，1/2/3 修改阅读状态，E 归档。键盘入口可从阅读导航底部查看。本文管理与核验汇集离线、附件、副本、云端恢复和来源检查。

新版阅读流的选中条目以白色卡片突出，正文标题上方显示来源和估算阅读时长。桌面按每条正文的段落和附件原顺序排列，段落放不下的附件接在正文后。下载沿用阅读云副本的权限和策略，失败时可进入本文检查器。文末可切换已读状态及归档或恢复，操作沿用已有状态规则。

## 中栏

- 全部内容、待读、进行中、已读：查看正常收藏；归档、放弃和删除中的内容不计入全部内容。
- 我的视图：将当前来源、状态、标签、附件类型、收集时间、关键词、保存副本位置、排序和布局保存为命名视图。支持重命名、排序、隐藏、删除和更新。删除视图只删除配置，不删除收藏或副本。视图图标对应保存的列表、表格、看板或画廊布局；更改布局后点击更新，图标随之更新。
- 已保存副本：默认折叠，按具体资料库筛选已经验证成功的副本。提供商和库名一起显示，避免混淆同名的 Craft 和 Obsidian 库。两者名称相同时只显示一次，例如“滴答清单”；自定义名称仍保留。同一条收藏保存到多个库时，可计入多个库。
- 归档、放弃、需要处理：整理结束的内容与真正需要检查的处理记录。正常排队、主动暂停、已取消和 Craft 超过 5 MB 而跳过上传的附件不作为错误。
- 收集与保存设置：打开现有默认本地保存位置、原附件和自动同步设置。

导航数量基于当前来源的完整本地数据，不受关键词、当前页和其他筛选条件限制。正文列表按组合筛选后再排序、分页；顶部结果数量表示实际匹配数量。已保存副本需要成功回执，尚在排队或只创建了部分远端内容的记录不计入。

## 顶部与视图

顶部保留全部、X 书签、X 喜欢、Telegram、滴答稍后读来源入口。列表、表格、看板和画廊只负责切换布局，归档、放弃和命名视图放在中栏。切换布局保留当前筛选和排序，各布局保留自己的列宽、显示字段、密度和卡片设置。

0.16.236 统一来源圆点与各布局的来源标签颜色和字形：X 书签使用黑色，X 喜欢使用粉色，Telegram 使用 #2198D4，滴答使用 #4a71f3。画廊视频缩略图只显示视频图标，保留加载与失败提示。同步入口使用紧凑按钮，菜单打开和同步执行时分别显示选中和转动状态。

看板支持将卡片拖到待读、进行中、已读或放弃列，并保存阅读状态；标签保持原样。拖动手柄也支持左右方向键和 Home/End。保存失败时卡片保留原状态，错误显示在底部信息栏。全部状态的看板包括放弃列中的内容；其他筛选继续生效，正常全部内容计数仍排除放弃内容。将 X 来源改为放弃仍沿用下次同步取消原收藏的规则。

列表与预览之间的分界支持拖动；方向键调整宽度，Shift 加大步长，Home/End 调整到最窄/最宽，Enter 或双击恢复默认。宽度保存在本地，下次打开沿用。实际可用区域过窄时使用单栏预览，提供返回列表入口。多个资料库徽章换行，不挤压正文和处理按钮。

桌面筛选菜单提供收集时间、内容类型和标签，点选后即时应用并关闭。多选标签必须同时匹配。条件条支持逐项移除，点「清除」会清空条件与关键词，保留当前来源、导航范围、布局和排序。快捷排序提供收集时间、发布时间、标题和附件数量。换字段从降序开始，重复点击同一字段切换方向。需要多条规则时，可打开「配置视图 → 高级排序」。命名视图保存完整配置，修改后点「更新视图」才覆盖原设置。最多保存 30 个视图。

「来源同步与连接」按 X 书签、X 喜欢、Telegram、滴答和 Obsidian 展示实际状态及上次同步。滴答可直接检查附件会话，会话失效时使用「重连会话」。核验失败后保留原因和重试入口。会话失效或账号不一致时，关闭再打开仍提示重连。账号匹配后退出弹窗。再次打开可查看「附件会话已核验」和核验时间，原来的来源同步时间仍单独显示。「同步详情」提供后台进度、记录和连接设置。

「云同步」显示阅读模块与本机网络策略。失败或有内容待传输时，弹窗保留反馈和「重试同步」。检测到断网后，网络恢复时仍可从同一弹窗重试。完成后关闭弹窗，重新打开可查看新回执时间。打开两个弹窗只读取状态。站点使用演示数据，可在断网提示内恢复演示网络再重试。

旧收藏视图自动迁移到独立配置，保留自定义名称、筛选、排序、列宽和卡片设置。原有配置保留供回溯。切换到其他工作区再返回时，在本次运行内保留收藏的分页、滚动位置、选中内容和预览开关。

## 需要处理与副本规则

需要处理中的每条记录按具体目标库打开。暂停的待处理副本只能先恢复该库处理；批准、取消、重新生成、关联和重试均核验界面所指向的目标库。如果后台已经切换到其他库，旧按钮请求被拒绝，避免误操作另一个副本。

查看导航、筛选和预览均使用本地缓存，不为了展示正文请求 Craft 或滴答。操作进度及错误继续显示在共享底部信息栏。

本次不改变既有保存规则：本地默认 Obsidian 原件保留，远端库只增加副本；Craft 超过 5,000,000 字节的附件跳过上传；视频作为原附件保存，不交给 Codex 分析；滴答无行动内容保存为笔记，只使用已有标签。

选中的附加保存位置可以再次点击取消。取消只停止该目标后续复制并取消勾选；已经同步的远端正文、附件和成功回执保留。再次选中成功目标沿用回执，避免重新创建副本。正在执行的写入先收敛，存在不确定结果时保留核验记录。默认本地保存位置不能取消。

资料库图标的文件选择器在设置菜单关闭后仍保留，选择图片后进入设置窗口内的裁剪界面。裁剪并保存后，各处使用同一裁剪结果。

滴答“稍后读”导入与其删除回执规则见 [DIDA_READING.md](DIDA_READING.md)。
