## 子牌组

- 新建牌组可选择父牌组；操作菜单支持新建子牌组、修改父牌组和移回根目录。服务端验证目标存在，阻止自身和后代成为父牌组，变更在事务中完成。
- 保留原有全局名称唯一约束和文件夹功能。移动分支时更新文件夹；删除父牌组只删除直属卡片，把子牌组提升到上一级，保留后代的 ID、卡片和复习历史。
- 每个视图可开启“包含子牌组”。分页、筛选、全选 ID、看板计数和复习计划使用同一递归范围；旧调用默认只处理当前牌组。关系变更同时更新分页版本，旧分页被拒绝。
- 桌面与手机标题按同一层级范围统计卡片、到期、新卡和暂停数量，只汇总已有牌组摘要，不追加正文查询。树形列表保留展开状态、搜索路径和层级缩进。
- 树、文件夹和搜索投影共享一次索引。同步父记录尚未到达时保留稳定 ID，孤立节点仍能显示；处理已观察到的环、同名映射和乱序删除，不丢弃卡片。
- **含层级的快照使用版本 5，平级数据保持版本 4。** 旧客户端拒绝版本 5，避免忽略父关系后写回丢失层级。备份、云历史、迁移基线和内容校验都识别该标记；参与子牌组同步的设备需升级。

## 正式所有者

`database.rs` 拥有连接、写入锁、初始化缓存和升级。`flashcard_decks.rs` 拥有层级、文件夹和事务规则，`flashcard_deck_commands.rs` 负责 IPC 与数据库准入。

闪卡其余职责迁入 `flashcard_models`、`flashcard_store`、`flashcard_validation`、`flashcard_authoring`、`flashcard_study_settings`、`flashcard_study`、`flashcard_transport`，并与既有 `flashcard_query` 协作。纯校验、行投影和额度读取位于查询与命令之下。生产消费者直接引用正式所有者；主文件退出这些业务实现，保留原 IPC 名字与签名，新参数使用兼容默认值。

`useMobileOverlayHistory` 拥有手机历史与返回行为；`useFlashcardStudyPlan` 拥有计划数量、启动和旧回复取消；`FlashcardDeckHierarchy` 与 `FlashcardDeckTree` 拥有树投影与展开。复习内容仍由既有唯一会话所有者管理。

`lib.rs` 从 48,420 行降到 43,337 行，`App.tsx` 从 1,495 行降到 1,391 行。迁移所有者的公开函数在根文件中没有重复实现，生产命令直接注册模块入口。行数仅描述改动规模；本次核验迁入的职责，不宣称整个仓库已不存在大文件或依赖环。

## 资源改动

- 当前任务计数在原事务中维护，状态栏读取小计数表，避免反复扫描已完成历史；失败详情与历史继续保留。
- 50,004 条合成任务记录保留完整，当前计数只有 3 行。相同计数结果下，旧单项统计执行 **850,082** 个 SQLite 步骤，新七项统计执行 **220** 个步骤。这是查询工作量证据，**不是整个 Hub 的 CPU 或内存降幅**。
- “全部复习”的后台计划只返回数量，点击开始后才取得完整 ID 和内容。范围、额度、张数变化及退出会取消旧启动；普通数量刷新不会取消正在启动的复习。
- 删除大牌组在 SQL 中记录全部卡片删除状态，避免先加载全部 ID。真实范围与批量操作不增加 500 张截断。
- 普通快照直接解析为类型数据；网络接收逐块检查原 32 MiB 上限。备份比较将借用数据送入摘要流，迁移比较只处理当前记录，减少完整快照、中间 JSON 和序列化缓冲区的同时存在。
- React、DOM 渲染器及公共依赖共用纯运行时分块。实际构建的主入口从 **630,008 字节降到 435,756 字节**，最大 JS 分块也是 435,756 字节，全部低于原 500 kB 警告线。运行时没有应用成员或反向导入。分块边界改善不等同启动总加载字节或 CPU 降幅。
- 全量备份、完整历史扫描、离线校验和压缩仍处理完整数据。“全部复习”保留整轮内容快照，本批减少的是日常数量查询分配。
