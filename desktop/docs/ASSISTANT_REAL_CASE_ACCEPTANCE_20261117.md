1. 我明天要核对数模和原理图，先把这篇笔记整理成待查清单：已经记下什么、还不知道什么、接着看什么资料、查到什么才算有结果。
2. 今天只能先查三件事，应该先查哪三件？每件拆成能照着做的步骤，不编联系人、图号和参数。
3. 把两轮内容整理为独立成果，先放优先三项，再放其余事项；事实和核对建议分开，保留出处和未知状态。
4. 点一处关键引用核对原文，返回聊天；编辑标题与来源说明，预览、返回编辑再确认保存。
5. 从搜索结果重开，在实际 Obsidian 中阅读；再次尝试同名新建，确认不会覆盖已保存成果。
