## 实施与异常记录

- 分析回执按当前授权和输入哈希核验。单元格明细按同一输入版本归集，逐条检查地址、来源行和跨批重复。批次区间相交时暂停汇总并保留各区间。记录数超过回读上限时标明有历史记录省略。
