## 实现与原型对应

复用现有 `PreviewRenderer`，不替换 Markdown 管线、不引入编辑器。默认仍为“当前”；桌面 Markdown 预览增加“当前／Craft 风格”选择，与浅深色外观独立。Craft 样式只作用于阅读区域，PDF（包括尚未加载完成时）、OCR、任务详情和 Android 继续沿用原呈现。#11 的页码、缩放、命中页及异步响应保护已整合，未覆盖。

依据现有站点 `app/preview-theme.css` 和 `PreviewTheme.tsx`：本轮核对原 Site 最新为 v98，GitHub 镜像由 #11 的 `77090c9` 同步，主题 CSS 字节一致；已有原型满足本次方向，没有重新设计或发布 Site。原型示例与实际资料仍分开。

切换只改变外层样式，不重新解析或替换正文节点，保留目录、折叠、媒体组件和命中状态；切换前记录当前阅读块，布局后校正块位置。偏好键 `hub.preview.theme.v1` 使用现有 `UserProfileStorage`：原生通过个人资料存储持久化，Vite 浏览器仅用其既有浏览器适配器。未选择不写入；缺失／未知值显示当前，不覆写未知旧值；尚未加载时禁用选择，写入失败显示未保存，沿用全局重试与待存语义。

合集沿用既有表格／画廊及记录分页，不宣称复刻原生合集交互。白板、复杂分栏和装饰背景仍只能使用已有可读转换；主题不能恢复来源未提供的布局。Craft 风格选择后显示“复杂布局以原文为准”，保留原文入口；没有新增编辑或写回。
