## 实现

- 完整备份仍使用严格校验；失败采集不发布恢复点、不更新正常阅读库。错误提示只陈述已有文件未被修改，实际副本存在与核验状态分开。
- 恢复面板显示正常阅读库的实际位置、存在状态、可追溯的生成时间，以及已结束的未完成采集。不存在正常阅读库时禁止打开，不能把旧路径副本冒充当前版本。
- 有缺项阅读副本只能生成到独立、可辨认的子目录。同一路径必须具有本空间、同采集的阅读副本标识；普通目录和其它副本均不接管。原始备份、Hub 数据目录和正常阅读库保持独立。
- 正文和结构逐一核对原始哈希，附件复用现有严格格式、原件和导出校验。缺项在正文附近提示离线不可用；报告按资源 ID 列出不可用附件与受影响页面，原始分类记录保留供追溯。
- 本地附件转换只采用可核对的名称或稳定身份，消除原先按扩展名及顺序接错附件的可能。Markdown 与 Wiki 相对链接及块定位由解析器检查；不猜同名页，不制造空笔记。代码示例不当作真实链接检查。
- 导出清单版本为 7，保留稳定文档身份、原始文档 ID、实际路径、哈希和生成时间。阅读属性只显示来源、空间、可读日期，不额外重复标题和 UUID。已有 Obsidian 配置内容保留，新建库关闭重复内联标题。
- 同一副本重复生成保留本地修改，冲突另存“Craft 更新”。丢失的受管附件可从有效原件重新补齐。集合为静态正文与原始数据；白板文件需要 Excalidraw，不能据此声称完整还原了 Craft 布局或交互。
