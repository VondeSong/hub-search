- 复用统一任务仓库与精确任务身份；顶部“安排今天、梳理项目、推进任务”、项目旁分析按钮、任务行与详情入口使用同一批原任务，不另建聚合库。

- 确认范围后重新读取本地任务；可请求既有后台来源核对。现有刷新命令只排队，因此界面明确本次分析基于本地快照，不把排队成功当作远端已刷新。
- 调用现有真实 agent_investigation 创建独立分析记录，沿用助手选择的模型/默认模型及 Codex 账号身份。仅授权选中任务，关闭外部 MCP、网络搜索及自动成果写入。任务编号由助手正文内的 hub-task-plan JSON 显式返回；兼容旧结构化 nextSteps，无法对应原任务的建议不可采纳。引文沿用宿主核验的本轮依据，不从模型 JSON 接受伪造来源。
- 原任务变化、完成、删除或身份替换后拒绝旧建议。关闭/切换忽略旧响应并请求停止后台分析；助手历史保留可追溯记录。
- 采纳前展示明确目标与影响，可取消；今日计划仅保存原任务引用，其他建议保存 Hub 笔记。个人数据沿用 UserProfileStorage，并等待持久化确认；不复制任务、不更改来源正文、日期、清单、同步开关或完成状态。
- 今日标记及筛选、任务详情的 Hub 建议笔记和完整助手分析入口均接通；只读来源同样可保存 Hub 笔记。

## 与演示原型的实际差异
