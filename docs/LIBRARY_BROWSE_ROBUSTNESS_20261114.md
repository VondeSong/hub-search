# 资料库定位、异常层级与大目录检查

日期：2026-11-14。接续资料库模块 #35 下的 #25；本轮为桌面结构浏览的一个增量，#25 保持打开、处理中。

## 修正内容

- 飞书同一正文在多个 Wiki 节点出现时，聚合列表的“定位”保留该条结果自身的有效目录，不再总是跳到第一个位置。范围搜索仍优先保留当前目录范围；结果携带过时位置时回退到实际缓存归属。
- 缺失上级、自身循环和多个目录成环时，在浏览投影中将必要节点挂到库根目录，保留其正常下级，并显示说明。原始目录对象及来源关系保持不变。层级校验与面包屑计算使用迭代，避免递归校验及反复前插。
- 目录树、列表、分栏的同级目录首次显示 100 项，按 100 项继续加载，三个位置共用该目录的加载数量。当前位置超出已加载批次时仍保留相应路径，并将侧栏中的当前目录滚入视野。

未增加来源写回、同步动作或依赖；不修改原型及 Rust 后端。

## 合成规模测量

本轮预先限定的检查目标是：千个同级目录首批最多显示 100 项，下一批可达；跨批定位保持可见；一万层结构计算不溢出、不丢失归属。耗时用于观察变化，没有将临时测量值设为产品承诺或不稳定的测试阈值。

对照基线 `d864a2e39973d932847994dfd25c16db325238e9`，使用同一份 1,000 个同级目录、10,000 篇文档的合成缓存，在 Vitest/jsdom 中交替挂载原组件和本轮组件各 7 次，去掉前两次，取剩余 5 次的中位数。组件读取模拟缓存；不包含原生 IPC、磁盘、网络、WebView 排版绘制及真实账号同步。

| 指标 | 基线 | 本轮 |
| --- | ---: | ---: |
| 当前目录首屏的目录行数 | 1,000 | 100 |
| 挂载与异步缓存渲染中位耗时 | 353.47 ms | 44.02 ms |

同一最终测量轮中，目录与文档分组在 3 次预热后测量 20 次，中位耗时 1.88 ms；一万层目录的分组及完整路径计算单次约 20.40 ms。另一次较早测量为 852.80/58.31 ms，说明本机负载影响明显；稳定的结论是减少首屏挂载节点，不能由这些值推出真实客户端的绝对速度或内存改善。

本轮临时测量脚本和日志保留在忽略目录 `desktop/.local/library-browse-scale/`，没有作为产品测试或运行代码提交。规模正确性由已提交回归用例覆盖。
