# 标签写回来源

在标签管理的已批准补标建议或已批准治理建议中展开详情，点击 **写回来源 → 预览变更 → 确认写入**。可以逐项选择要修改的笔记；每次确认只写入当前预览的一项。

## 支持范围

- **补标**：把已批准的 Hub 内容标签添加到对应来源。
- **规范化**：将已批准的合并、别名、停用替代关系中的原标签替换为目标标签。
- **Obsidian**：修改 YAML 标签属性，以及正文中的准确标签引用。其他属性与正文保留，使用同目录临时文件替换，写入后重新读取并刷新索引。
- **Craft**：通过当前资料库的 `craft_write` 连接修改准确页面的标签文本；新增标签使用页面末尾的独立标签块。修改后从 Craft 重新读取并核对。来源标签索引在下次 Craft 同步时刷新。

Craft 写回按目标页面 ID 直接读取并验证响应根页面，避免父文档返回内容未包含子页面时误报“请先同步来源”。写回清单显示子页面标题。页面响应有继续分页标记、目标 ID 不符或目标不再是页面时，停止预览；其他子页面仍排除在标签修改范围之外。

父子关系、待拆分等不能直接表示为标签替换的关系仍保留在 Hub 内。规范目标存在歧义或连续映射时，先整理关系再写回。代码、链接、图片和其他 Craft 子页面不会作为普通标签文本替换；遇到无法安全处理的写法会提示手动修改。

## 确认与记录

预览使用来源当前内容，确认绑定预览记录与内容摘要，30 分钟后失效。写入前再次核对建议状态、来源定位和内容；来源变化时必须重新预览。已完成记录重复提交返回已有结果。写入失败、部分完成或响应不明时，不会自动重放旧操作。

**写回记录与备份**显示最近 30 次操作，并可查看写回前的原文快照。撤销 Hub 内部建议不会撤销已完成的来源修改，历史与备份仍可查看。需要手动恢复时，先将备份与当前来源核对，保留写回之后的新编辑。

Craft 连接必须提供写入权限。当前每页最多显示 20 项，每个治理建议最多 1000 项；单篇来源快照上限 2 MB，返回分页内容的 Craft 文档暂不写回。

## 数据与验证

数据库版本升级为 63，新增 `tag_source_writebacks` 保存预览、原文快照和执行结果。旧版仅支持版本 62 的程序无法打开升级后的数据库，应继续使用新版程序。

已验证：

- 后端完整回归：387 项通过，7 项跳过。
- 前端相关回归：42 项通过。
- Obsidian 临时笔记实际文件写入、冲突拦截、YAML 与 Markdown 保留行为。
- 真实 Craft 连接的只读协议、页面定位、已有标签识别，以及官方连接返回的文本块更新格式。
- 两种来源的界面预览与确认流程。

没有使用用户真实笔记执行写入测试。Craft 的生产写入路径由连接权限和写后读回结果判定，不将请求发送成功当作已验证成功。

Craft 块接口参考：[官方 API](https://connect.craft.do/api-docs/space)。
