# 桌面资料库原型对齐检查

日期：2026-11-14。对应 #25（资料库结构浏览），父模块 #35。

## 参考和实现

视觉依据为已发布的[工作台资料库原型](https://hub-workspace-von11.song02211368537057.chatgpt.site/?view=libraries)，版本 94，来源提交 `dd296f0e33648ac7fddf73609fc0abd40ee60405`。本轮只修改桌面客户端，没有修改或重新发布原型。

主线已有独立的图标栏、结构导航、内容列表和阅读区，以及目录树／分栏切换。本轮继续补齐：

- “全部库”直接展示已缓存的实际文档，显示来源和原路径；首次展示 100 项，可以继续加载。
- 聚合列表复用现有收藏存储和结构定位，单个资料库读取失败时保留其他库的可用内容。
- 阅读区可以收起；保持正文组件及阅读状态，打开一篇文档时自动恢复阅读区。
- 库结构导航复用现有宽度调整、键盘操作和用户配置保存；保留收起／展开入口。
- 搜索框支持 Ctrl/Cmd K 聚焦，Escape 清除当前搜索。

使用原生 `library_contents`、`local_search` 和现有正文预览，不加载示例正文替代实际业务数据。Craft 子页面返回文档首页的独立修复 `aee9cd4` 已保留，本轮没有重新计为新增修复。

- 相关前端回归：9 个文件、69 项通过。其中包括跨库内容、单库失败降级、收藏身份、阅读区保持挂载、Craft 子页面返回、目录定位、侧栏键盘与拖动调整及正文预览回归。
- `npm run build` 通过，包含类型检查与生产构建。存在项目既有的大分块提示。
- Windows Tauri WebView 实测：独立测试资料库的两篇 Markdown，全部库打开正文、阅读区收起并重新打开、两层目录的逐级分栏、导航宽度拖动通过。
- 实际确认主工作区的 1437 开发服务返回新页面，独立 Tauri 窗口加载该服务。原日常窗口当时连接另一任务工作树的 1420 服务，因此保留原进程和其他任务环境，未将它误报为已经热更新。
- 未修改 Rust，本轮不重复运行此前资料库后端的测试，也不将此前测试数量累加进本轮。

## 保留的边界

本轮完成桌面布局与核心浏览交互的对齐。原型中的示例“线束项目”专题、Craft 合集专属表格／画廊、复杂来源的完整原生视图，仍是后续能力；没有增加无实际功能的入口。

本轮实际窗口验收使用独立本地测试库，没有重新对真实 Craft、飞书执行全量同步，也没有完成大规模资料库的性能验收。#25 保持打开，后续验收按原事项接续。
