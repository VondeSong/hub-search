## Craft：真实账号与安卓原生检查

使用已有真实账号，通过模拟器浏览器完成新授权；连接密码由用户直接输入。本轮选择一个空间，未修改或删除远端原文。

- 已下载 15 篇正文并完成文字索引。
- 17 条附件引用中，15 条已有本机内容，对应 14 份去重后的原件；逐份读取模拟器文件，验证大小及 SHA-256 与 Blob 元数据一致。另两条视频引用为受限状态，不计为下载成功。
- 实际关闭模拟器 Wi-Fi 和移动数据后，检索并打开已下载正文；断网冷启动后仍能搜索、阅读 Craft 子页面和查看已缓存图片、放大图片。
- 以 Craft 自带的介绍文档核验界面，不用示例数组替代搜索结果。外站图片链接与已下载的 Craft 附件分别处理；外站图片未缓存时仍需要网络，不能用正文成功代表所有媒体已离线可用。
- 安卓数据保存在应用私有目录：`craft-search.sqlite3` 保存正文、目录及状态，`blobs-v1/` 保存原件，`tantivy-generations-v1/` 保存搜索索引。没有将电脑的活动 SQLite 复制给手机。
- 最终开发版重新完成断网冷启动、离线正文打开、联网后手动同步：无需再次输入密码，保存的授权自动恢复，连续失败计数归零。另制造三次断网失败，再联网同步，已打开的设置页自动清除旧失败提示。
- 重复同步后仍为 15 篇正文，身份与正文保留；两篇正文中的媒体访问 URL 随来源刷新，因此不把整篇字节哈希不变作为成功条件。14 份原件再次逐份校验大小及 SHA-256 通过，原有 5 条速记的 ID 与内容哈希保持不变。

本轮运行 Android 15 / API 35 的 `emulator-5564`，使用当前源码编译的 x86_64 开发版及主工作区 1422 前端服务。开发模式仍需电脑界面服务；本轮“离线”验证的是来源互联网断开后读取本机资料，不表示开发壳已脱离电脑独立交付。
