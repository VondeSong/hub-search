# Hub 桌面工作区调整（2026-09-10）

## 已实现

- 侧栏增加“全部内容”，当前标签/日历导航前置；复核规则收起，侧栏中部使用统一滚动区。资料库名称附带来源应用。
- 标签详情分为“内容 / 内容补标 / 标签关系”，默认浏览内容。切换这三个入口保留已挂载的定义草稿。全局健康检查集中在对应导航入口。
- 补标页共用模型、推理强度及 Fast 设置；提供“查找可能漏标 / 逐篇检查”。逐篇检查要求先保存定义，运行期间锁定冲突操作。
- 管理页展开工作区，查看建议证据时在右侧预览原文；预览仍可用全局开关关闭。
- 列表显示标题与路径两行，提供记忆选择的紧凑/舒适模式。日志使用正文摘要，避免重复显示日期标题。
- 页面显示当前资料库范围，提供查看全部资料库操作。收藏空状态明确限定当前范围，无结果时不保留空预览栏（固定预览仍尊重用户选择）。
- 预览工具栏独立占行，Obsidian 文档属性默认折叠；搜索时展开属性以保留命中定位。无预览时提供打开来源操作。
- 闪卡允许选择并记忆本次复习张数（10/20/50/100/全部），不改变卡片调度。图表根据可用宽度换行，热力图自适应；0 次记录不再画出正数高度柱。
- 统计“记忆保持率”改称“答题记得比例”，明确按评分计算；累计次数和卡片库总量分开描述。
- 无效时间输入安全回退，避免日期格式化异常影响列表。来源中已经写入的异常标题不自动重命名。

## 验证

- TypeScript 检查与生产构建。
- 相关组件与展示函数回归；包括未保存定义的页内切换保留、无效日期、统一模型设置传入逐篇检查、现有闪卡同步与拖拽。
- 使用真实组件和隔离的示例数据进行浏览器视觉检查：普通及较窄工作区、完整侧栏、内容/管理切换、空收藏、正文属性和闪卡图表。
- 浏览器窗口检查不等同于 Windows 系统 DPI 全面验收，安装后仍应留意用户实际缩放配置。

## 范围说明

本次以桌面导航、布局和现有工作流为主，保留来源数据、已保存定义、预算及人工审核规则。没有重写全局审计的数据失效机制，也没有自动执行标签批准。跨页面关闭或应用退出的通用草稿恢复不在此次改动中；已验证的是标签页内切换的草稿保留。
