# Hub 使用说明

> 标签分析交给 Codex 后的使用流程、历史分页、安全边界及验收进度，见 [标签治理验收清单](标签治理验收清单.md)。该清单描述的是标签治理能力，不代表 Hub 其他同步功能均只读。

## 1. Hub 是什么

Hub 是一个 Windows 本地搜索工具，把以下资料源放进同一个搜索界面：

- Craft 空间
- Obsidian Vault
- 滴答清单

搜索、筛选、排序和预览主要在本机完成。资料库索引读取 Craft、Obsidian 和滴答清单的内容，不会因为搜索或预览而修改来源。任务同步、标签回写、保存阅读内容和 Obsidian 归档是独立的写入能力：启用相应同步或发起相应操作后，Hub 可以在获授权的来源中创建、修改、完成或删除对应内容。使用前应确认操作的目标资料库和同步设置。

Hub 的本地缓存用于加快搜索和提供预览，不等于完整备份。尤其是 Craft 和滴答清单，仍应使用官方导出功能另行备份重要数据。

## 2. 首次使用

### 2.1 运行免安装版

双击 `Hub_x.x.x_x64_portable.exe` 即可运行。程序关闭主窗口后默认驻留系统托盘；再次运行同一个 EXE 会唤醒已有窗口，不会启动第二个实例。

Hub 使用两套独立的全局快捷键：`Ctrl+Shift+K` 显示或隐藏完整 Hub 主窗口；`Ctrl+Alt+Space` 弹出快速搜索框并自动聚焦输入。快速搜索框首次启动时居中显示，之后会恢复用户上次调整的尺寸和屏幕位置；可拖动顶部区域移动窗口，也可从窗口边缘调整宽高。快速搜索框失去焦点后会自动消失，不会改变主窗口的显示状态。两套快捷键都可在“设置 → 行为”中分别修改。

### 2.2 添加 Craft

1. 打开右下角设置。
2. 找到“添加或重新授权 Craft 空间”。
3. 填写或确认 Craft MCP 地址。
4. 点击浏览器授权。
5. 授权完成后等待第一次同步和本地索引建立。

Craft 凭证保存在 Windows 凭据管理器，不写入 SQLite、Tantivy 索引或免安装 EXE。

### 2.3 添加 Obsidian

1. 打开设置。
2. 找到“添加 Obsidian Vault”。
3. 选择 Vault 根目录。
4. 点击“添加并建立索引”。

资料库扫描只读取 Vault，不修改原文件。用户发起的标签回写或阅读归档可以写入所选 Vault，不属于索引扫描。扫描默认忽略：

- `.obsidian`
- `.trash`
- `.git`
- `.basic-memory`
- `node_modules`
- 符号链接

可为每个 Vault 单独设置排除目录、路径前缀或通配规则。

### 2.4 添加滴答清单

1. 打开设置。
2. 找到“添加或重新授权滴答清单”。
3. 点击浏览器登录。
4. 授权完成后等待项目和未完成任务同步。

资料库同步读取项目和未完成任务，因此搜索覆盖当前未完成任务、任务描述、检查项、标签及项目信息，不把已完成任务当作长期历史库。任务工作区与 Craft / 滴答任务同步使用独立的受控写入能力；开启任务同步后，关联任务的创建、修改、完成和删除可能同步到来源。

## 3. 三类资料库多久同步一次

### 3.1 自动同步周期

设置中的“自动同步”控制所有已启用资料库的定时校准，默认是每 15 分钟，可选：

- 关闭
- 每 5 分钟
- 每 15 分钟
- 每 30 分钟
- 每小时
- 每 3 小时
- 每 6 小时

后台每约 30 秒检查一次同步是否到期，所以实际开始时间可能比设置值晚几十秒。如果此时已有同步、下载、OCR 或索引工作，最终可见时间还会略晚。

Hub 必须仍在运行。隐藏到托盘不影响自动同步；完全退出程序后不会同步。

### 3.2 Craft

- 日常自动同步：按设置周期执行增量同步。
- 完整核对：自动同步中每 24 小时至少执行一次文件夹归属和删除核对。
- 手动更新：点击“更新当前资料库”“更新所选资料库”或“更新全部资料库”时强制完整核对。
- 远程限流：遇到 Craft 429 限流时会按 `Retry-After` 或退避时间重试，因此大型空间可能需要更久。

### 3.3 滴答清单

- 按“自动同步”的设置周期执行。
- 每次读取项目列表，再读取各项目的未完成任务。
- 当前不是服务端实时推送，刚在滴答清单中修改的任务不会立即出现在 Hub。
- 一条本地任务连续 3 次完整读取都没有出现后，才从本地索引移除，避免一次接口缺失造成误删。

需要立即看到变化时，使用顶部的更新按钮手动同步。

### 3.4 Obsidian

Obsidian 除了参加定时同步，还启用了本地文件监听：

- Markdown 创建、保存、重命名或删除后先等待约 750 ms，合并连续写入事件。
- 后台空闲时约每 3 秒处理一次变化。
- 正常情况下，保存后约 1～4 秒即可进入本地索引。
- 临时失败会重新排队；设置中可查看每个 Vault 的监听状态。
- 定时同步继续承担遗漏校准，手动更新会完整扫描一次 Vault。

因此 Obsidian 通常比 Craft 和滴答清单更新得更接近实时。

如果在本地把 Vault 文件夹改名或移动，进入“设置 → 资料库”，在原资料库上点击“重新定位文件夹”，选择移动后的同一个库。也可从“更多资料库设置 → 更换文件夹”操作。Hub 保留原库 ID、已有索引与收藏副本关联，并重建文件监听；重新添加同一路径也会复用原资料库。正在处理时先暂停并等待处理停止。

“修改名称”只设置 Hub 的显示名。Obsidian 跳转使用实际库文件夹名称；Craft 仍按空间 ID 连接，同步或重新连接时更新来源名称，用户设置的显示名保留。

## 4. 首页和资料库选择

搜索框为空时显示最近内容，可按今天、昨天、本周等日期分组。

在设置中可以控制：

- 修改时间为“不限”时是否仍按日期分组
- 日期显示完整日期，还是“今天”“昨天”“3 天前”等语义化日期
- 首页页面名称字号和是否加粗

左上角资料库菜单支持多选：

- 点击单个资料库可选择或取消。
- 选择多个资料库时只搜索这些库。
- “全部资料库”用于恢复全选。
- 资料库菜单底部可进入管理设置。

## 5. 搜索与筛选

### 5.1 内容类型

- 页面：Craft 页面、Obsidian Markdown 和滴答任务。
- PDF：PDF 原生文字及开启 PDF OCR 后的扫描页文字。
- 媒体：图片和视频相关结果；图片文字依赖 OCR。
- 附件：附件名称及当前已支持提取的附件内容。

### 5.2 搜索范围

- 全部字段：标题、章节、正文、路径、标签和附件等字段共同召回。
- 页面标题：只匹配页面或任务的页面名称。
- 标题与章节：匹配页面名称及文内章节标题。

只命中页面标题时，结果不会额外显示无关正文摘要；正文存在真实命中时才显示摘要。

### 5.3 其他筛选

- 文件夹：限制到一个资料库路径或滴答项目。
- 修改时间：不限、最近 7 天、30 天、90 天等。
- 清除筛选：恢复默认筛选状态。

顶部筛选会保存在本机，下次启动继续使用。

### 5.4 搜索语法

- 多个普通词默认要求同时命中，即 AND。
- 使用 `OR` 可搜索任意一个词。
- 使用英文双引号可搜索短语。
- 中文标题支持全拼和拼音首字母召回。
- 英文和数字词支持有限的错别字容错。

## 6. 搜索结果怎么看

每条结果可能包含：

- 左侧资料库图标和资料库名称
- 页面名称或任务名称
- 内容类型
- 所在路径、项目或文件夹
- 修改日期
- 标题、章节、正文、路径等命中类型图标
- 包含命中词的正文摘要

命中词使用黄色高亮。右侧命中类型图标说明该结果是因哪些字段被召回，不是操作按钮。

同一页面中的多个正文命中会聚合成一条结果，避免同一页面重复占满列表。右侧预览中的命中计数和上下箭头可逐个导航页面内命中。

## 7. 键盘和鼠标操作

### 7.1 列表导航

- `↑` / `↓`：上一条或下一条
- `PageUp` / `PageDown`：一次移动 8 条
- `Home` / `End`：第一条或最后一条
- 单击：选择结果
- 双击：按该资料源的配置打开
- `Enter`：搜索框未聚焦时打开当前结果

### 7.2 搜索和界面

- `Ctrl+F`：聚焦搜索框
- `Ctrl+Shift+F`：展开或收起筛选
- `Ctrl+P`：打开或关闭预览
- `F12`：打开预览或跳到下一个命中
- `Shift+F12`：跳到上一个命中
- `Esc`：搜索框有文字时先清空；再次按下隐藏窗口
- 可配置全局快捷键：从任意应用唤起 Hub 搜索

### 7.3 调整左右宽度

拖动搜索结果和预览之间的分隔条，可调整两侧比例。开启“记住窗口状态”后，窗口大小、屏幕位置和左右比例会在重启后恢复。

## 8. 预览和打开原内容

### 8.1 Craft

Craft 可分别设置“搜索结果打开方式”和“预览按钮打开方式”：

- 网页精准定位：使用完整网页块链接，定位能力更好，可能先打开浏览器再唤醒客户端。
- 直接唤醒客户端：打开更直接，但 Windows Craft 客户端可能只打开页面，不能可靠滚动或选中目标块。

### 8.2 Obsidian

通过 `obsidian://` 深层链接打开对应 Vault 和文件。预览在本机渲染 Markdown，支持 Frontmatter、双链、Callout、表格、任务列表和 KaTeX 等常用格式。

### 8.3 滴答清单

双击任务、按 Enter 或点击预览右上角的打开按钮时，Hub 使用精确的 HTTPS 任务链接打开对应任务。

## 9. 图片、PDF、附件和视频

### 9.1 图片 OCR

开启后，Hub 下载被页面引用的图片并使用 Windows OCR 识别文字。识别效果取决于图片清晰度和 Windows 已安装的语言包。

### 9.2 PDF

- “PDF 内容”控制下载 PDF 和提取原生文字。
- “PDF OCR”只处理没有可用文字层的扫描页。
- PDF 在结果中按命中页预览，可前后翻页。

### 9.3 附件和视频

Office、Markdown、PDF 等附件可显示为文件卡片。视频默认只显示封面或占位，不在页面打开时自动下载完整视频；用户主动播放时才加载媒体。

## 10. 数据存储和迁移

### 10.1 将 Craft 空间导出为 Obsidian Vault

在“设置 → 资料库”中找到 Craft 空间，点击“导出 Vault”：

1. 输入 Vault 名称并选择保存位置。Hub 会在该位置创建独立的 Vault 文件夹，不会把页面散落到所选父文件夹。
2. 默认导出图片、视频、其他附件，并把日期页面整理到 `日记/年/月/日期.md`。
3. Hub 会先获取最新 Craft 内容，再生成 Markdown、`attachments/` 和 `.obsidian/`；Craft 页面链接会转换为 Obsidian 双链。
4. 完成后可直接点击“在 Obsidian 中打开”，也可先在文件管理器中检查结果。

再次导出到同名 Vault 时只更新变化内容。若导出的文件已在 Obsidian 中被修改，Hub 会保留本地版本，并另存一份带“Craft 更新”的文件。导出记录和校验信息保存在隐藏的 `.hub-export/` 中。

### 10.2 Hub 本地数据

默认数据目录：

`%APPDATA%\com.craftsearch.desktop`

主要内容：

- `craft-search.sqlite3`：资料库、文档、任务、内容块、设置和后台任务状态
- `tantivy-generations-v1`：全文搜索索引
- `blobs-v1`：按 SHA-256 保存的原文、图片、PDF、附件和提取结果

设置中的“数据存储位置”可以选择：

- Windows 默认位置
- 免安装程序旁
- 自定义空文件夹

迁移时应使用设置内的“更改并迁移”，不要在程序运行时手工搬动数据库。

### 10.3 在另一台电脑使用

1. 复制免安装 EXE。
2. 如果只复制 EXE，新电脑会建立新的本地缓存。
3. Craft 和滴答清单需要在新电脑重新登录，因为凭证保存在原电脑的 Windows 凭据管理器。
4. Obsidian 需要重新选择新电脑上的 Vault 路径。
5. 若要迁移缓存，先在旧电脑退出 Hub，再复制完整数据目录；新电脑仍需要重新授权远程账号。

不要让两台电脑同时通过同步盘读写同一个 SQLite/索引目录。

## 11. 本地索引状态和失败任务

点击右下角“本地索引”可查看：

- 文档数量
- 正在处理的任务
- 下载任务
- OCR 页数
- 待发现内容
- 失败数量
- Obsidian 文件监听错误

失败项的建议处理方式：

1. 先展开详情查看失败类型和最后错误。
2. 网络、临时限流、文件占用等问题可点“重新尝试”。
3. 已删除资源、永久 404、损坏文件或明确不需要的内容可点“忽略”。
4. “忽略”只清理失败任务，不删除来源文档；来源再次变化或重新同步时，可能重新生成任务。

## 12. 常见问题

### 搜索不到刚修改的 Craft 或滴答任务

等待下一次自动同步，或点击顶部更新按钮。确认 Hub 没有完全退出，并检查授权是否仍有效。

### Obsidian 保存后没有更新

在设置中查看 Vault 是否显示“监听中”。如果监听失败，先重建监听；仍无效时手动更新该 Vault。

### 滴答清单显示“需要重新授权”

重新进行浏览器登录。若每次重启都失效，检查 Windows 凭据管理器是否允许 Hub 保存凭证，以及数据目录是否被清理工具删除。

### 图片或 PDF 不显示

展开右下角索引状态，查看是下载失败、PDF 解析失败还是 OCR 失败。临时网络问题选择重试；永久 404 可忽略。

### 切换到阅读时出现“正在读取本地阅读内容”

阅读列表每页读取 60 条。首次进入或更换筛选、排序和分页时，需要等待本地查询；正文就绪后会先显示，连接和副本状态随后更新。在同一次运行中返回相同阅读页，会先显示最近一页并恢复滚动位置，再后台检查更新。已读、归档、删除、手动刷新以及云同步或恢复引起的内容变更，会使保留的旧页失效。

### 免安装版是否包含全部资料

不包含。EXE 是程序，本地数据库、索引和附件缓存在数据目录中，远程登录凭证在 Windows 凭据管理器中。

## 13. 当前边界

- Hub 是搜索缓存，不是完整的 Craft 或滴答清单灾备系统。
- 滴答清单当前主要读取未完成任务，不保证保留已完成任务历史。
- Craft Windows 客户端不保证通过直接协议准确选中并滚动到块。
- Obsidian 只索引 Markdown 引用的常见图片和 PDF；未引用附件不会自动全部复制。
- Word、Excel、PPT 等格式目前主要显示附件元数据，不一定提取正文。

## 14. 闪卡复习（实验）

牌组支持子牌组。在“新建牌组”中选择父牌组，或打开牌组旁的操作菜单选择“新建子牌组”。操作菜单中的“父牌组”也可以把现有牌组移到另一个父牌组或根目录；牌组名称沿用全局唯一规则。

进入父牌组后，在“卡片配置”中开启“包含子牌组”，当前视图的列表、筛选、全选、看板和复习会包含所有下级牌组。设置按视图保存，默认只查看当前牌组。删除父牌组会删除其直属卡片，下级牌组和卡片保留并移到上一级。

选择“全部复习”时，界面先读取待复习数量，点击开始后才取得整轮内容。子牌组层级会保存到备份并参与同步；有层级的数据使用新版同步协议，参与同步的其它设备需升级到支持子牌组的版本。

Hub 可以接收由已连接 Hub MCP 的外部 Codex 等 AI 根据资料生成的闪卡草稿：

- Windows 侧边栏使用“闪卡复习”；未开启侧边栏或在 Android 上时，使用搜索栏右侧的闪卡按钮。
- 先在设置中的“Hub MCP / Codex 集成”按说明连接外部客户端；生成所用模型和登录态由该客户端控制。
- 在外部 Codex 中指定资料和学习目标，使用 `hub-generate-flashcards` 技能读取来源、生成卡片并提交到 Hub 收件箱。核对后移入牌组，才进入学习和同步。
- 卡片保留来源文档、路径、内容哈希，并引用已下载的原图或视频；不会写回 Craft 或 Obsidian。
- 牌组列表中可以直接编辑问题、答案和解释；来源笔记内容变化后，旧卡片会显示“来源已更新”提示，便于人工核对。
- 复习时可选择“重来、困难、记得、轻松”，Hub 会据此安排下一次复习。

### Windows 与 Android 同步

闪卡页右上角可以配置 HTTPS WebDAV：

1. 在 WebDAV 服务中预先创建一个专用于 Hub 的空目录。
2. 在 Windows Hub 中填写目录地址、用户名和密码。建议同时设置一个至少 10 个字符的端到端加密口令，然后保存、测试连接并执行一次同步。
3. 在 Android Hub 中填写同一个目录、WebDAV 凭据和完全相同的加密口令，再执行同步。加密口令错误时无法读取远端内容，Hub 不提供找回功能。
4. 此后可在任一设备点击“同步”，合并牌组、卡片、删除状态、复习事件和卡片引用的图片/视频；也可以开启“自动同步”，由 Hub 在内容变化后于后台同步。

同步使用 ETag 条件写入；远端在同步期间发生变化时会重新下载、合并并重试。复习事件按唯一 ID 合并，合并后重新计算卡片计划。WebDAV 密码与加密口令保存在系统安全凭据存储中。

设置加密口令后，卡片快照和媒体会在本机使用 XChaCha20-Poly1305 加密后再上传，WebDAV 服务端不会看到明文；旧的未加密快照仍可读取，以便平滑迁移。即使启用了内容加密，也必须使用 HTTPS，且不要通过同步盘直接共享正在运行的 SQLite 数据库。
