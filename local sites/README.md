# Hub 本地桌面交互原型（统一整理版）

本目录将原本分散的 4 份本地 HTML 原型整合成一个可直接运行的桌面工作台原型。

打开 [主站](index.html)，点击右下角「助手」或按 Ctrl/⌘ + J，右侧会打开高保真 Agents 面板。工作区顶部可切换引用与摘录、流式复核和中断与规则。点击案例中的原文引用，可在工作区查看对应段落，点「返回当前资料」回到原位置。窗口形态菜单支持右侧分屏停靠、悬浮浮窗和专注展开，收起后重新唤起可继续当前对话。

从文档点「问助手」或在双纸视图点「让助手对比这两张纸」，面板会切换到「当前资料」并带入现有文档。这里的回复、日志和任务操作均使用本地原型数据。

## 1. 原始原型梳理

| 原始文件（已归档至 `originals/`） | 原型定位 | 整合后的归属 |
| --- | --- | --- |
| `hub_v3_quick_look.html` | **Hub 工作台 v3 桌面外壳**：包含 macOS 顶部标题栏、左侧统一导航、资料库空间（层级目录/空间卡片/双白纸并排对照/Quick Look）、全局搜索、任务、每日日志、闪卡复习、命令面板 (`⌘K`)、右侧快捷助手与设置弹窗 | 作为统一主入口 **`index.html`** 的桌面外壳与基础模块 |
| `hub_agents (6).html` | **Hub 助手高保真原型（React 18）**：多形态停靠（右侧分屏/悬浮/专注展开）、思维链与工作过程回执、引用联动高亮、模型与技能配置、3 个可切换交互案例 | 整合为 **`modules/agents.html`**，默认接管侧栏「Agent 工作台 (`⌘2`)」 |
| `hub_read (1).html` | **Hub 阅读工作区 v2**：顶部来源分段切换、5 种视图（流式/表格/看板/画廊/分拣）、分屏精读、检查器、阅读助手、批量操作与归档/同步弹窗 | 整合为 **`modules/reading.html`**，默认接管侧栏「阅读与收藏 (`⌘3`)」 |
| `hub_v4 洞察.html` | **Hub 洞察工作区 v4**：状态分段切换、发现核对台、阶段回顾与统计、长效关注主题、修订谱系与冲突模拟、全量处理记录 | 整合为 **`modules/insights.html`**，默认接管侧栏「洞察与标签 (`⌘7`)」 |

## 2. 目录结构

```text
local sites/
├── index.html          # 统一入口（双击或通过本地服务打开）
├── modules/
│   ├── agents.html     # Hub 助手高保真工作区（支持 ?embed=1 嵌入）
│   ├── reading.html    # 阅读工作区 v2（支持 ?embed=1 嵌入）
│   └── insights.html   # 洞察工作区 v4（支持 ?embed=1 嵌入）
├── originals/          # 本机原始 HTML 备份
├── start-local.ps1     # 可选：一键启动本地 HTTP 预览服务
└── README.md           # 本说明文档
```

## 3. 使用方式

### 方式一：直接双击打开（零依赖）
直接用浏览器打开 [`index.html`](index.html) 即可体验全部模块。

### 方式二：本地 HTTP 服务预览（推荐）
在 PowerShell 中运行：

```powershell
.\start-local.ps1
```

默认会在 `http://127.0.0.1:4173/` 启动并自动打开浏览器（支持 `-Port` 自定义端口）。

> 说明：原型的 Tailwind CSS、Lucide 图标、React/Babel、Chart.js 及字体沿用原文件 CDN 引用，首次加载需联网。

## 4. 整合特性

- **状态保活切换**：Agent、阅读、洞察三大高保真工作区采用懒加载 + 保活挂载，在资料库、搜索、任务、日志、闪卡之间自由切换时不会丢失当前对话、筛选条件或滚动状态。
- **高保真 / v3 轻量版即时对照**：位于 Agent、阅读、洞察三个模块时，顶部标题栏右侧提供 `高保真 / v3 轻量` 切换按钮以及 `↗` 独立标签页打开入口，方便横向比较交互方案。
- **全局快捷键贯通**：即使焦点在高保真子工作区内，`Ctrl/⌘ + 1~7`（切换主模块）、`Ctrl/⌘ + K`（Spotlight 命令面板）、`Ctrl/⌘ + \`（折叠侧边栏）、`Ctrl/⌘ + J`（快捷助手）依然有效。
- **URL Hash 直达**：支持通过 `#space`、`#search`、`#agents`、`#reading`、`#tasks`、`#journals`、`#flashcards`、`#insights` 直接定位对应工作区。
