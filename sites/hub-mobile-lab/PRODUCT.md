# Hub 手机端原型

<!-- impeccable:product-schema 1 -->

## Platform
web（手机浏览器优先，独立 Sites 预览）

## Stack
静态 HTML、CSS、JavaScript；示例数据在浏览器本地。

## Users
假设以 Hub 的个人使用者为首要体验对象，面向通勤、临时查找和回顾等短会话。

## Product Purpose
2026-11-13 基线：检验搜索、资料浏览、阅读、任务、Agents 和闪卡怎样在手机上形成可追溯的闭环。保留 Issue #2 洞察的依据、处理和回顾，以及 Issue #32 的 VPS Agents 交互；与桌面站点及实际 Android 客户端独立。

## Navigation and Workflows

底部主标签固定为搜索、浏览、Agents、任务、复习。洞察通过浏览入口与搜索首页“值得留意”卡片进入，不占底部标签。全局加号保持 flomo 风格速记，日志在浏览首位。

统一搜索按类型检索资料、本地笔记、任务、阅读、Agents 会话、洞察和闪卡；资料库 / 空间 / 分组支持多范围选择，并明确搜索范围不等于给 Agents 上传整库的授权。资料和阅读可写独立草稿的关联笔记、交给 Agents 或创建带来源任务；回答可保存笔记或转任务。任务本地新建 / 编辑、来源链接、完成 / 恢复 / 撤销形成闭环，不声称写回远端来源。

连接总览分开内容同步（OSS）和 Agents 会话（VPS）。各自的偏好、异常与恢复独立演示，不把电脑离线解释为所有模块不可用。

## 小组件预览（2026-11-15，Issue #53）

沿用本 Site 的 `#widgets`，从「设置 → 小组件预览」或「复习 → 管理 → 小组件预览」进入。默认展示「小米负一屏 / 回顾一条 / 4×2 / 浅色」，并提供「今日复习 + 记一条」与「回顾一条 + 记一条」的比较；保留原有五个底部标签。

回顾支持查看同一条原文、原地换一条及选择本站示例/本机速记范围；今日复习沿用现有原型牌库、剩余数与会话；记一条打开现有速记和草稿。展示、换一条和外观操作不写入评分或完成状态。预览配置只保存在当前浏览器。

提供负一屏/桌面示意、浅深色、适用的 2×2 / 4×2 / 4×4 尺寸，以及离线缓存、空内容/复习完成、首次使用的状态预演。状态预演不切断真实网络，不修改现有笔记或复习进度。网页不能把小组件添加到手机系统，也不证明小米宿主兼容；未发布 Android 测试包及真实负一屏验证另行推进。

## Agents Scope

遵循 Issue #32 的 VPS 主方案：手机通过 Hub 服务连接个人 Linux VPS，由执行端运行官方 Codex app-server。主仓已有 Android/VPS 基础接入实现；本 Site 仅以本地状态预演其手机交互。Windows 关机不阻塞新云端会话的设计，不能等同于能够访问关机电脑上的资料与工具。

Agents 是底部主入口，也可从资料 / 阅读 / 任务等上下文操作进入。全屏对话保留对话、材料、成果三种视图，包含多轮输入、图片预览、流式示例回复、停止、断线恢复、结果保存 / 复制 / 转任务、会话重命名 / 归档 / 恢复、可搜索多选材料和首次连接演示。已有桌面聊天迁移与桌面私有资料访问不在本轮范围内。

当前服务源码媒体约束为图片 / 关键帧最多 6 张、单张 4 MiB、合计 12 MiB、短视频 ≤30 秒的关键帧处理；此网页本机预览为最多 3 张 × 2 MiB，视频仅合成关键帧示例。模型入口说明固定示例回复与真实模型的区别，不提供虚构的实时模型选择。

## Boundaries
此 Site 使用示例数据与浏览器本地状态，不连接真实资料库、OSS、VPS 或 Codex，不调用模型、不写回 Craft / 滴答 / OS，不更改真实同步任务。实际选择的图片只在浏览器预览和保存，不声称已经识别；连接向导不接收真实密钥、令牌或密码。

Site 的演示能力与主仓 Android/VPS 已有基础连接是两个交付层。新增界面和闭环是否已经迁入实际客户端，需逐项核对对应源码与实机记录；不把“此站未连接”写成“Android 尚未接入”，也不把 Site 的按钮可用写成真实链路已验收。
