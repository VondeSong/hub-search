# 语音附件与保存行为修复

本轮只修改手机网页原型，不涉及 Android 安装包或真实转写服务配置。

- 语音附件使用独立的整行样式，避免被照片缩略图的固定宽度、按钮定位挤压；删除按钮独立置于右侧。
- 移除速记编辑器额外的“保存并继续录入”按钮。普通保存回到日志列表，不自动打开空白录音。
- 向原记录追加录音后，保存成功关闭弹层；保存失败保留在原记录草稿。只有主动点击“继续追加录音”才进入下一段。

核验：语音、日志编辑及移动端现有检查通过，两个修改的脚本语法检查通过。新增回归覆盖追加保存成功不新建录音、失败保留原草稿。浏览器实际完成演示录音→加入草稿→保存记录→再次查看与保存校对，确认没有自动弹出录音页；360px 窄屏检查语音卡片及删除按钮均位于编辑器内部。网页录音演示不代表 Android 实录或付费转写验收。
