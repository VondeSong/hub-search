# 移动端原型功能对照

本轮以现有安卓功能核对结果为范围；仅更新独立手机 Sites 原型，不修改 APK、桌面、个人 OS 或真实云连接。

## 页面与操作

| 入口 | 本轮交付 |
| --- | --- |
| 搜索 | 保留多来源筛选；新增记录按归属日期检索，附件名与多个正文标签可检索。 |
| 浏览 | 日志、阅读、收藏、最近浏览、标签；资料库和同步状态另列。 |
| 速记 | 全局加号，正文、标签、照片、更多和记下；更多提供日期、普通文件、加粗与列表。 |
| 日志 | 保存后回到卡片；合并原本地记录入口，按归属日排序，正文/附件名搜索与标签筛选，长文展开。 |
| 同步 | 持久保存设备偏好与模块范围；显式预演本机保存、上传、等待电脑、写入回执、离线和重试。 |
| 任务 | 保留来源、查看、完成、恢复和撤销；收起没有正式保存目标的新建入口，旧本地任务保留。 |
| 复习 | 今日、牌库、收件箱；查看来源、采用/暂不采用/恢复草稿，采用后可复习。 |
| 闪卡管理 | 原型专用 JSON 导出与合并恢复；拒绝未知格式、重复身份和无效评分，失败保留原状态。 |
| 阅读 | 保留来源、状态与列表位置；本文管理区分离线标记、PDF 摘录及没有原件的情形。 |
| 后续功能 | 设置内保留洞察、桌面协作、工作专题的历史演示；移动 Agents 的远程执行与会话另行规划。 |

## 数据与演示边界

- 继续使用 `hub-mobile-v1` 保存元数据，兼容既有文字、照片、链接、任务、草稿和评分。不因导航收起而清除旧数据。
- 新附件原件使用浏览器 IndexedDB；每条最多 9 个，单个 20 MB。提交之前完成原件保存，失败保留输入；保存后可以逐个下载。移除草稿附件后清理无引用缓存。
- 旧照片 data URL 仍能显示，不强制迁移。浏览器实际配额不足时明确报错；不会为显示保存成功而丢弃附件。
- 日期默认本机今天，可补记。归属日独立保存，不从上传时间重新推算；卡片不展示时分秒。
- 云阶段统一带“示例”标识。自动同步开关仅保存偏好，不自动推进演示；按钮每次推进一阶段。电脑离线时保持等待，失败后可恢复并重试，不产生新记录 ID。
- 此站不进行真实后台上传、OSS 请求或 OS 写入。锁屏、Android 输入法、系统返回、进程回收和真实设备网络仍需在安卓中验收。
- 本机速记卡片不提供已归档内容编辑或云删除，不假定 OS 编辑会反向回到手机。
- 闪卡备份仅适用于本原型，与安卓备份格式不同；不包含速记附件。清理站点数据或更换浏览器会失去本机内容，附件可在卡片逐个保存。
- 阅读离线是示例标记，不保证断网重载。PDF 仅有示例文字摘录，不伪装成可下载原件。

## 检查

- `node --check dist/app.js`、`dist/workflows.js`、`dist/mobile.js`、`dist/mobile-features.js`。
- `node checks/mobile-checks.cjs`：日期、旧草稿、保存失败回滚、数字/异常标签路由、分步同步与重试、收件箱去重及恢复、备份校验与幂等合并。
- 浏览器：补记、文字和文件/大图草稿关闭重开、保存后回到日志、刷新后文件恢复、下载内容校验、状态推进与失败恢复、闪卡采用和复习、原型备份下载/恢复。
- 已检查 360×740、390×844 和 390×430 视口，无横向溢出；短视口带附件及展开更多时保存按钮可见。纯白/纯黑主题、全局标签进入新速记、任务完成/撤销和阅读附件/离线标记已通过浏览器检查，未发现控制台错误。设计检测仅提示既有阅读引用的 3 px 边框，本轮未改该规则。
