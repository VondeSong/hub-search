当前基线：2026-11-13，参考主仓源码补齐跨模块流程，仅更新独立手机 Sites 原型，不修改 APK、桌面、个人 OS 或真实 VPS 服务。

主仓已经有 Android/VPS 基础接入实现。本目录中的“仅演示 / 未连接”只限定 Site：不能据此判断 Android 尚未接入，也不能把此站新增的 UI 视为真实客户端和服务端已同步实现、实机已验证。

底部五项主导航为搜索、浏览、Agents、任务、复习。洞察保留浏览入口和搜索首页“值得留意”卡片，不占底部标签；全局加号仍直接速记。

## 数据与演示边界

- 继续使用 `hub-mobile-v1` 保存元数据，兼容既有文字、照片、链接、任务、草稿和评分。不因导航收起而清除旧数据。
- 新附件原件使用浏览器 IndexedDB；每条最多 9 个，单个 20 MB。提交之前完成原件保存，失败保留输入；保存后可以逐个下载。移除草稿附件后清理无引用缓存。
- 旧照片 data URL 仍能显示，不强制迁移。浏览器实际配额不足时明确报错；不会为显示保存成功而丢弃附件。
- 日期默认本机今天，可补记。归属日独立保存，不从上传时间重新推算；卡片不展示时分秒。
- 云阶段统一带“示例”标识。自动同步开关仅保存偏好，不自动推进演示；按钮每次推进一阶段。电脑离线时保持等待，失败后可恢复并重试，不产生新记录 ID。
- 此站不进行真实后台上传、OSS 请求或 OS 写入。锁屏、Android 输入法、系统返回、进程回收和真实设备网络仍需在安卓中验收。
- 本机速记卡片不提供已归档内容编辑或云删除，不假定 OS 编辑会反向回到手机。
- 闪卡备份仅适用于本原型，与安卓备份格式不同；不包含速记附件。清理站点数据或更换浏览器会失去本机内容，附件可在卡片逐个保存。
- 阅读离线是示例标记，不保证断网重载。PDF 仅有示例文字摘录，不伪装成可下载原件。
- 阅读想法草稿与速记、任务编辑草稿各自独立。来源链接区分 `doc/<id>`、`note/<id>`、`article/<id>`、`task/<id>` 等类型，避免不同来源同 ID 错开内容。
- Agents 归档是可恢复的会话收起，不删除消息、材料或运行。进行中 / 待发送请求先完成、停止或撤回；重命名、归档、恢复和多选材料保存失败均回滚。
- Agents 搜索范围与材料授权分离。只加入用户明确选中的条目；跨模块带入只形成草稿，不自动发送或暗中访问整个资料库。
- 主仓服务源码约束是图片 / 关键帧合计最多 6 张、单张 ≤4 MiB、合计 ≤12 MiB、短视频 ≤30 秒的关键帧处理。此 Site 的本机图片预览限制为 3 张 × 2 MiB，视频仅合成关键帧示例，不上传视频、不处理声音。
- Site 连接向导只保存演示地址与设备昵称，不接收真实密码、密钥或令牌；“模拟成功”不代表真实 TLS、服务身份、登录或设备配对验证通过。

## 当前自动检查命令

```sh
node checks/mobile-checks.cjs
node checks/workspace-checks.cjs
node checks/task-tools-checks.cjs
node checks/agents-enhancements-checks.cjs
node checks/search-interactions-checks.cjs
```

| 检查 | 重点 |
| --- | --- |
| `mobile-checks.cjs` | 日期、旧草稿、保存失败回滚、标签路由、分步同步 / 重试、收件箱去重、备份校验 / 合并。 |
| `workspace-checks.cjs` | 跨模块检索、资料范围与重置、同 ID 类型隔离、阅读草稿及来源保留、跨模块入口。 |
| `task-tools-checks.cjs` | 新建 / 编辑与草稿、日期、来源快照和幂等关联、筛选、完成 / 撤销、保存失败回滚。 |
| `agents-enhancements-checks.cjs` | 重命名 / 归档 / 恢复、历史搜索、请求恢复不重复、多选材料、身份隔离、演示配对、复制降级、安全渲染和回滚。 |
| `search-interactions-checks.cjs` | 唯一筛选入口、7 类直切、资料聚合 / 精确类型、独立条件删除、草稿重置 / 取消 / 应用、失败回滚与旧状态恢复。 |

对全部 `dist` JavaScript 的语法检查及 `git diff --check` 均通过。本轮实际浏览器操作、窄屏结果和未测边界见 [2026-11-13 验收记录](qa-2026-11-13.md)。隔离检查和网页容器不代替系统文件选择、真实触控 / 输入法或 VPS 端到端验证；以下为历史版本事实。
