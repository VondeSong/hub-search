# 手机速记录音原型（2026-11-16）

接续 #22 的已确认实时双供应商方案。本轮只更新原有手机 Sites，不修改 Android、VPS、OSS 或 OS。

## 体验入口

日志 → ＋ → 工具栏麦克风（更多 → 语音记录也保留）。选择阿里或 OpenAI，记住选择；录制过程中不可切换。

- 「体验实时转录」无需麦克风：预设示例逐段出现，区分已确认文字和临时句，支持暂停／继续、完成、断网／额度不足演示和补转。
- 「使用麦克风录音」使用浏览器 MediaRecorder：本机录制、暂停／继续、停止后等待最终音频数据，再保存 IndexedDB、回听或下载。不会将示例文字填充为真实录音的转录结果。
- 完成后可校对，确认加入原速记草稿，保留此前文字和附件。通过原有保存动作产生一条日志记录；语音元数据随同一个附件身份保存。
- 保存后点语音附件回读识别原文与校对稿。补转只更新演示原文，不覆盖手动校对稿；后续附件校对不自动改写日志正文。日志正文继续通过原有编辑入口修改。
- 保存失败保留草稿；关闭录音或页面进入后台会结束采集并尝试保留原音。未授权／无设备时可重试或选择演示。

## 边界

阿里 `paraformer-realtime-v2` 和 OpenAI `gpt-live-transcribe` 是方案中的两个选项，均未接入真实服务；不收集密钥、不调用识别 API、不产生识别费用。流程演示无原音文件，界面明确标注；真实录音没有自动转录。

网页录音在结束后持久化。录制中强制刷新、崩溃或杀进程可能丢失未完成音频，不能当作原生分片恢复、后台录音或完整断网补传实现。页面隐藏会主动结束录音，锁屏／来电／蓝牙和实体 Android 验收不在本轮范围。AI 整理、逐词定位、服务端账单和真实补转尚未实现。

录音文件仅保存在当前浏览器。清除网站数据会移除本机原音；重要录音可下载。现有云同步及 OS 写入继续只是本站演示。

## 本轮检查

- `node checks/voice-checks.cjs`：计时、暂停／继续身份、异常保留、补转保护校对、合并原草稿、存储失败回滚、同记录更新与无原音保护；MediaRecorder 生命周期 mock 覆盖尾部数据、停止麦克风及真实录音不填入示例文字。
- 原有 mobile、journal-studio、journal-feed-tools 检查；JavaScript 语法检查及差异空白检查。
- 浏览器：390×844 录制／暂停／继续／断网／结束／校对／补转／保存、刷新后附件回读；320×700 窄屏查看，无横向溢出，未观察到控制台错误。
- 本轮没有实际开启用户麦克风，未将模拟采音测试当作真实硬件回听验收；真实麦克风及手机浏览器权限兼容仍需用户体验验证。
