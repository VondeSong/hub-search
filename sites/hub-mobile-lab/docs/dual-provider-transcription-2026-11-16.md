# 双服务接入的原型边界（2026-11-16）

原型继续使用 v23 的录音、暂停、回听、校对及草稿流程。本次仅补充与 Android 实现的区别，不改变原型的公开范围，也不在公开网站配置个人服务密钥。

- 网页上的实时文字仍是明确标注的交互演示。本机麦克风录音只存此浏览器，不会上传或产生识别费用。
- Android Hub 通过已连接的个人 VPS 转接阿里与 OpenAI；每段录音选择一家，保留本机原音。选择另一家补转写需要用户主动操作。
- 实时文字与原有补充文字分别保留。完成后校对，点击加入文字才合并到原草稿；迟到结果不能覆盖校对稿或写进下一条记录。
- 网络、额度或服务出错时保留原音；先核对同一任务的结果，再决定补转。重试沿用已有任务编号，避免把网络超时变成重复识别。

本站的演示与浏览器录音检查不代表 Android 麦克风、真实识别服务、实体手机锁屏或后台持续录音已验收。实际服务结果见仓库 Android 接入报告。
