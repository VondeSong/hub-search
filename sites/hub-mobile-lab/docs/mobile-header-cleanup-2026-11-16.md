# 手机页头精简与日志标题对齐

日期：2026-11-16。接续 GitHub #55（父任务 #45）。

## 本轮要求与改动

- 搜索、浏览、Agents、任务、复习的共用页头移除蓝色 Hub 品牌图块；标题与左侧内容边距对齐。
- 原品牌按钮同时承担空间菜单入口。保留原 `mobile-space` 行为，将入口移到右侧「空间与设置」齿轮，点击区域为 44 × 44 px；原页面主操作保留。
- 共用备用页头中的 Hub 图片一并移除。应用 favicon 与桌面小组件卡片的品牌标记保留；搜索、添加、筛选、内容类型等功能图标保留。
- 设置图形由原来近似太阳的放射线改为齿轮轮廓，避免空间设置入口与亮度操作混淆。
- 日志页返回按钮只显示箭头，保留「返回浏览」可访问名称与跳转行为。
- 日志标题改为 18 px，与其他二级页面一致。左右等宽布局使标题对齐整个手机内容区的中心；不受左侧一个、右侧两个按钮的数量差异影响。
- 日志搜索与更多菜单保持原入口及行为。修改资源更新缓存标记。
