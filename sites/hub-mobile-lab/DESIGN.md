# Hub 手机端设计

## 内容与操作分层

2026-11-13 基线：内容保持稳定实体表面，文字、留白与来源承担主要层级。顶部轻工具、悬浮五项底栏和阅读工具条使用少量玻璃材质；不在列表每一行叠加模糊。参考 Apple Liquid Glass 的操作层表达与 Craft 的文档秩序，Web 原型采用 CSS 材质与可降级效果。

全局导航固定为搜索、浏览、Agents、任务、复习。快速记录使用统一加号；日志是浏览中的第一项。Agents 另有资料 / 阅读 / 任务上下文入口；聊天与复习答题使用全屏会话并提供明确返回。洞察从浏览入口与搜索首页“值得留意”卡片进入，不占主标签；历史桌面协作和工作专题仍在设置的后续功能中保留。

## 主题与尺寸

- 纯白、纯黑、暖纸三套语义主题；湖蓝、鼠尾草、鸢尾紫独立强调色。
- 阅读正文 17px / 1.75，可切换为 19px。系统字体，中文长标题允许自然换行。
- 内容最大宽度 480px，手机左右约 18–20px。主要点击区域至少 48px，底栏标签 12px。
- 主题覆盖输入、弹层、toast、来源标签、正文和选中态，避免零散覆盖。
- 减少动态、减少透明和强制颜色模式有对应处理；不支持 backdrop-filter 时用实体表面。

## 交互准则

返回保留搜索、筛选与列表滚动位置；弹层统一遮罩关闭、Escape/浏览器返回、焦点恢复和背景滚动锁。速记直接进入一个无标题输入框，采用用户提供的 flomo 截图中的“正文＋底部工具栏”结构；去掉记录/任务/链接分类、重复标签与大按钮。底部保留标签、照片、更多和“记下”；更多中提供按天补记、普通文件、加粗及项目符号，保留关闭与简短的本机保存状态。使用 Hub 现有主题与强调色，不照搬参考的绿色与输入法。

速记文字、日期及附件草稿在当前浏览器保留，文件以 IndexedDB 保存原件，元数据沿用原有状态；旧文字、照片、链接及任务草稿兼容。空内容禁用提交，纯附件可保存，失败保留输入。每条最多 9 个附件、单个 20 MB；实际配额不足明确报错，不截断文件。保存后回到日志卡片流，不跳到资料详情；正文、附件名、日期与标签可回看、搜索和筛选。日期归属与建立时间分开，不在卡片显示时分秒。

日志中的本机记录与日记示例共用卡片形式；不再增加“本地记录”一级入口，旧 saved 地址保留为别名。卡片预演本机保存、待上传、等待电脑、OS 已写入和失败重试，云端阶段明确标“示例”。同步页面统一呈现设备开关、模块范围和队列；异常与电脑离线控制默认折叠，不自动推进状态，也不宣称真实锁屏上传。首版不加手机编辑已归档记录或双向修改。

统一搜索以类型化身份区分示例资料、本地笔记、任务、阅读、Agents 会话、洞察和闪卡；相同 ID 的不同类型不能相互覆盖。资料库 → 空间 / 分组支持多选，父级表达全选或部分选中，提交后保留范围；零选中显示空结果，不擅自回退整库。内容类型、日期与排序可叠加。任务按截止日、会话按更新日、资料按记录日筛选，无日期内容不编造日期。搜索范围选择不授权向 Agents 上传资料。

任务提供明确标注浏览器本地的新建、编辑和独立草稿，覆盖标题、日期、优先级、说明、来源链接、搜索、状态 / 日期 / 来源筛选与排序。来源任务保留原始快照，本地调整不伪装远端写回；完成、恢复、撤销失败时保持原状态。由资料、阅读、洞察或回答建立任务时保存类型化来源和摘要，重复来源可定位已有任务。

阅读 / 资料的“记下想法”使用与全局速记分开的草稿，保留可选摘录和原文关联；同处可创建带来源任务或明确带入 Agents，不自动发送。阅读管理继续分开说明正文离线标记、PDF 摘录和实际文件是否存在，不为未提供的原件放下载按钮。闪卡保留今日、牌库和收件箱入口；示例草稿可查看来源、采用或暂不采用并恢复，采用不产生重复；原型 JSON 备份与安卓格式不同，采用幂等合并恢复。

洞察依据可以打开具体文档；建立任务保存稳定关联 ID，重复操作不重复创建。任务完成与发现处理状态分开。所有示例状态均保留其演示边界。

连接总览分开内容同步（OSS）和 Agents 会话（VPS）。两个入口分别描述本机保存 / 上传 / 电脑写入和对话执行的状态，不共用“已连接”推断。当前 Site 不探测真实服务；主仓 Android/VPS 已有的基础连接实现与此处演示层分别核验。

## Agents 对话

回答和引用占据主要阅读区。用户消息使用轻底色，回答保持正文排版；运行过程默认折叠。对话、材料、成果在同一会话内切换，输入栏固定在可视视口底部，上方内容按实际输入栏高度留白。附件、模型与会话操作使用底部弹层，沿用背景锁定和系统返回处理。

连接状态只显示必要信息。Windows 离线不影响云端聊天；手机离线、服务不可达、执行端登录失效、订阅额度不足和设备撤销分别表达。额度未知时不显示虚构余额。停止待送达、停止待确认和已停止各有明确文案；断线不等于取消。

发送前生成稳定请求 ID。仅存本机的消息等待明确发送，已被云端接收的运行在恢复连接后查询同一个请求。示例附件先预览，可移除，实际图片不产生虚构识别结果。保存成果保持幂等，并进入现有本地记录与搜索。

会话列表分当前、已归档、全部，标题与历史消息可搜索。重命名只改标题；归档只收起会话，不删除消息、材料、运行记录和草稿。活跃或待发送请求需先完成、停止或撤回；已归档会话保持只读，恢复后接着提问。重命名、归档、恢复保存失败均回滚，不显示虚假完成。

材料选择器搜索标题、正文和来源，分资料、本地记录、阅读与已选，跨筛选保留明确勾选和已选数量。只把确认的条目加入草稿，已附上材料去重；本地笔记与同 ID 的示例资料采用不同身份。任务 / 阅读带入入口只建立带材料的草稿，不自动发送。

完整回答提供复制、保存笔记和转任务；已停止回复可复制已收到部分，不伪装完整成果。剪贴板失败时回退可手动复制的文本，保留示例标记和来源信息。

首次连接向导只有地址、设备昵称与模拟成功 / 失败选项。校验格式和展示模拟结果之后才可保存演示配置，修改输入会使上次校验失效；拒绝携带凭据的 URL，不设置真实密钥输入框。模型入口只作说明：固定示例回复未调用模型，不提供无法生效的模型选择器。

媒体说明区分源码服务的图片 / 帧合计 6 张、单张 4 MiB、合计 12 MiB、短视频 ≤30 秒关键帧，与当前网页的本机图片预览 3 张 × 2 MiB。视频入口仍是合成关键帧，不是实际视频上传、完整视频理解或音频转写。

## 代码职责

- `dist/app.js`：示例资料、主导航与路由、页面分发、阅读 / 复习和历史桌面更新演示。
- `dist/mobile.js`：外观、可视 viewport、弹层生命周期与阅读操作。
- `dist/workflows.js`：快速记录、洞察依据及旧任务关联的兼容流程。
- `dist/workspace-tools.js`：跨模块类型化搜索、资料范围、连接总览、独立阅读想法及来源桥接。
- `dist/task-tools.js`：本地任务编辑 / 草稿、来源快照、筛选排序、完成撤销及 Agents 上下文。
- `dist/agents-runtime.js`：本地会话 / 归档、请求状态、材料适配、恢复与成果保存；不发起网络调用。
- `dist/agents-ui.js`：会话管理、全屏对话、多选材料、连接向导演示、复制及局部流式更新。
- `dist/mobile-features.js`：日志卡片、浏览器附件存储、同步演示、标签与闪卡管理。
- `dist/style.css`：全局语义主题与通用组件。
- `dist/agents.css`：复用主题变量的 Agents 布局与组件。
- `dist/workspace-tools.css`、`dist/task-tools.css`：复用主题变量的搜索范围、跨模块与任务组件。

新增交互的本地浏览器、窄屏 / 短屏与主题检查见 [2026-11-13 验收记录](docs/qa-2026-11-13.md)。不沿用历史截图或隔离脚本结果代替实机触控、输入法和实际服务验证。
