## 2026-11-15 紧凑移动交互

本轮按已确认的交互审查方案更新现有站点，跟进 [Issue #55](https://github.com/VondeSong/hub-search/issues/55)。当前实现包括：

- 搜索、浏览、Agents、任务、复习使用“空间入口 + 当前页名 + 页面主操作”的统一顶栏，去掉正文重复的大标题和用途说明，保留五项底部导航。真实笔记、阅读和任务详情标题继续显示。
- 各主页面的空间菜单提供稳定的“快速速记”和外观 / 设置入口。搜索与浏览保留速记快捷加号，任务顶栏新建任务，Agents 顶栏新建对话；加号不再在所有主页面都表示速记。
- 搜索未激活时优先显示本浏览器最近打开的内容，没有访问历史时使用明确标注的示例推荐；聚焦但未输入时显示近期搜索。类型与资料范围改为同一行的独立菜单入口，类型单选即应用，范围面板继续使用草稿、取消、重置和应用规则。
- 浏览改为紧凑目录。洞察从浏览进入，仍可通过全局搜索检索，不再占搜索起始页的常驻推荐卡片。
- Agents 列表压缩连接说明、搜索和范围切换，使用轻量会话行并显示草稿 / 运行 / 待重试 / 归档状态。保留紧凑会话详情、材料与成果、运行过程、附件及原请求恢复能力。
- 任务页去掉重复的新建入口，保留本地任务操作与来源说明；复习保留开始按钮、专注模式及退出恢复。既有小组件预览与入口继续有效。

设计规则与目标见 [交互实施规格](docs/interaction-review-2026-11-15.md)。本轮发布版本、浏览器实测、检查结果及剩余限制以 [交付与验收记录](docs/interaction-qa-2026-11-15.md) 为准；设计目标不等同于实测结果，浏览器检查不代表真实 Android 输入法、系统返回、相机 / 相册或小米设备已经验收。

## 2026-11-15 小组件预览

沿用原手机站点，在 [小组件预览](https://hub-mobile-lab-von11.song02211368537057.chatgpt.site/#widgets) 比较「回顾一条 + 记一条」与「今日复习 + 记一条」。也可从「设置 → 小组件预览」或「复习 → 管理」进入，不增加底部主标签。

支持负一屏/桌面布局示意、适用尺寸、浅深色、回顾范围及离线/空内容/首次使用状态。回顾正文打开同一条资料，复习复用现有会话，记一条恢复已有草稿。网页交互不写真实系统小组件，不证明 Android 或小米真机兼容。

检查命令：`node checks/widget-checks.cjs`、`node checks/mobile-checks.cjs`、`node checks/workspace-checks.cjs`。本轮的浏览器路径、响应式检查、存储失败修复及真实验证边界见 [验收记录](docs/widgets-qa-2026-11-15.md)。后续原生自测与开发计划继续在 [Issue #53](https://github.com/VondeSong/hub-search/issues/53) 跟进。

## 历史基线：2026-11-13 入口与闭环

以下记录当时的入口与交互。搜索七按钮、搜索首页洞察卡片及各页统一速记加号已由上方 2026-11-15 方案调整，不能作为当前界面的实现要求；其余数据闭环与本机能力边界继续沿用。

当时主导航为 **搜索、浏览、Agents、任务、复习**。洞察不是底部标签：保留在浏览入口，并通过搜索首页“值得留意”卡片进入。当时的加号直接打开 flomo 风格速记，不把速记重新拆为任务、链接等分类。

- 统一搜索覆盖资料、本地笔记、任务、阅读、Agents 会话、洞察和闪卡，以内容类型分组显示并进入对应详情。不同类型即使具有同一 ID 也不混淆。可多选“资料库 → 空间 / 分组”，叠加内容类型、日期和相关 / 最近排序；此选择只影响本地搜索，不代表整库授权给 Agents。
- 任务支持本地新建、编辑标题 / 日期 / 优先级 / 说明、搜索筛选、完成 / 恢复 / 撤销。资料、阅读、洞察、Agents 回答可形成带来源链接和快照的本地任务；来源示例任务的编辑显示为本地调整，不声称已回写 Craft 或滴答。
- 阅读和资料详情可“记下想法”、带资料交给 Agents、转为任务。阅读想法使用独立草稿，保留摘录与原文关联，不覆盖全局加号的速记草稿。
- 连接总览分开内容同步（OSS）和 Agents 会话（VPS），两条通道独立显示演示状态；恢复一个通道不会自动恢复另一个。

这些界面闭环用于评估手机交互，不表示本轮已完成对应的 Android 迁移、真实资料连接、云端写回或跨设备同步。

### 历史搜索交互修正（2026-11-13）

下列“七个类型按钮直接切换”和“仅右侧按钮打开筛选”属于旧版布局。当前使用资料范围 / 内容类型菜单，类型选择后直接生效；范围草稿、独立条件及存储失败回滚规则保留。

- “全部 / 资料 / 任务 / 阅读 / 对话 / 洞察 / 闪卡”是直接切换的内容类型，不打开弹层。“资料”包括笔记、日志、PDF 和链接；精确类型仍可在筛选中选择。
- 搜索页只有右侧筛选按钮打开完整筛选面板。“复盘、项目、线束固定点”作为独立的“试试搜索”建议，不混入类型切换。
- 已应用的资料范围、日期、旧来源 / 标签和精确子类型可单项取消；点击“全部”只取消内容类型限制，不清空关键词或其他条件。
- 资料范围和各资料库默认折叠，显示选中摘要。面板默认随内容收缩，展开范围时才扩大；标题和底部“重置 / 应用筛选”不随中间列表滚动。
- 面板里的修改、重置都只是草稿，关闭不应用。应用成功后在本浏览器记住条件，后续搜索无需重新确认；存储失败保留原条件和当前草稿，兼容旧版范围与页面状态。

## 体验桌面更新闭环

1. 在洞察打开支出发现，查看依据，追加一条或多条反馈。
2. 请求桌面更新。请求先保存到手机。在“同步与离线”同步一次，桌面默认离线，请求进入等待上线。
3. 模拟桌面上线和补录账目；推进“模拟桌面开始”和“模拟桌面完成”。手机仍显示旧结论。
4. 再同步一次。在请求记录查看新结果并确认采用。回到发现，可核对两个版本、原处理状态和历史反馈。
5. 手机离线、同步暂停、同步失败和桌面离线是不同状态；分别可从“同步与离线”体验。未开始的请求可以撤销。

## Issue #32：手机 Agents 原型

依据 [Issue #32](https://github.com/VondeSong/hub-search/issues/32) 更新后的主方案，手机连接个人 VPS 上的 Hub 服务和 Codex app-server。正式路径采用 ChatGPT 订阅登录，Windows 可以关机。本项目只演示交互，不连接 VPS，也不保存任何真实账号或设备凭证。

从底部 Agents 主标签，或资料 / 阅读 / 任务的上下文操作进入。聊天采用全屏布局，保留对话、材料、成果三个会话视图。新会话仅包含当前对话和明确选择的材料，已有桌面聊天、桌面文件和工具不会自动进入。

2026-11-13 基线已补齐会话重命名、归档、恢复及归档历史搜索，本轮继续保留；归档不删除消息、运行记录或材料，进行中 / 待发送的请求需先完成、停止或撤回。材料选择器支持全部示例资料、本地记录和阅读的全文 / 来源搜索、多选、已选计数及去重。完整或已停止的回复可复制，剪贴板不可用时提供手动复制；完成的回答还可转为带来源的本地任务。

连接向导提供服务地址、设备昵称、模拟成功 / 失败、校验后确认等流程。它不联系服务、不验证真实身份，只有演示配置会留在浏览器；不得输入真实密钥、令牌或密码。模型入口是说明，不是假模型选择器，也不声称固定示例回复来自真实模型。

推荐验收路径：

1. Agents → 新对话 → 输入问题 → 发送，查看接收回执、流式示例回复、折叠运行过程，再继续追问。
2. 打开阅读笔记 → 带着资料提问 → 查看已选材料 → 发送 → 打开回复引用。在“成果”保存一次，再打开日志；重复保存不重复创建。
3. 输入栏加号 → 从相册选择图片 → 预览/移除 → 发送。图片只保存在当前浏览器，回复明确说明未调用模型识别。拍照入口调用支持设备的系统相机选择。
4. 连接与设备 → 演示手机离线 → 发送问题，显示“仅存本机”；恢复网络后明确发送同一条。已接收的运行断线后，恢复查询原请求，不重复建立一轮。
5. 回复中停止；断线时停止显示待送达，收到演示回执后才显示已停止。若结果先完成，则保留已完成结果。
6. 分别体验登录失效、额度不足、设备撤销和服务不可达。恢复登录或配对仅为演示；不会自动切换账号或按量 API。Windows 默认离线仍可聊天。
7. 会话选项 → 重命名 / 归档 → 在“已归档”或“全部”搜索历史 → 恢复。核对材料与消息未被删除，保存失败时保持原状态。
8. 添加材料 → 选择资料 → 搜索正文 / 来源 → 跨分类多选 → 确认已选数量 → 加入草稿。未选中的资料不会加入，不自动发送。
9. 连接与设备 → 连接向导 → 体验格式错误、模拟失败、修改后重测、成功后确认。无需、也不应填写真实凭据。
10. 附件面板 → 关键帧示例，预览 0/1/2 秒的三张合成帧。只表达选定关键帧，未实现完整视频识别或音频转写。

| 范围 | 媒体限制与含义 |
| --- | --- |
| 当前服务源码约束 | 图片与关键帧合计最多 6 张，单张 ≤4 MiB、合计 ≤12 MiB；短视频 ≤30 秒，按关键帧处理。 |
| 此网页原型 | 每轮本机图片预览最多 3 张、单张 ≤2 MiB；JPEG、PNG、WebP、GIF。视频仅合成关键帧示例，不上传视频或处理声音。 |

浏览器实际配额不足会保留此前状态并提示；本机预览上限不是服务端限额，也不是订阅额度。

实现与验收范围见 [Agents 交互说明](docs/agents-32.md)。

## 既有速记与复习能力

各主页面的空间菜单可打开速记，搜索与浏览另有快捷加号；任务和 Agents 顶栏分别新建任务、对话。日志在浏览首位，记录保存后回到按天卡片流；更多中可补记日期、添加普通文件及插入格式。速记附件最多 9 个、单个 20 MB，原件保存在浏览器 IndexedDB，旧照片与草稿保留。洞察从浏览进入，也能被统一搜索检索；历史桌面协作和工作专题仍在设置 → 后续功能中查看，不与 VPS Agents 混为一条执行通道。

同步页显式演示本机保存→上传→电脑写入及失败重试，统一模块范围；不连接实际 OSS/OS。闪卡包含今日、牌库、收件箱、草稿采用/恢复与原型备份；阅读管理说明离线标记、附件和出处。完整范围与边界见 [移动端原型功能对照](docs/mobile-scope.md)。

推荐验收路径：

1. 搜索“阅读” → 打开笔记 → 返回，查询与列表位置保留。
2. 日志 → 加号 → 补记日期和附件 → 记下 → 卡片回看；同步页模拟离线、上传失败、电脑上线及重试，不重复创建记录。
3. 空间菜单 → 快速速记 → 输入记录 → 关闭 → 重新打开，恢复文字、日期和文件草稿；保存后刷新，正文、附件和标签仍可查看和搜索。
4. 设置 → 外观与阅读，切换纯白/纯黑/暖纸、强调色、较大正文和减少透明效果。
5. 复习 → 收件箱 → 核对来源并采用 → 牌库 → 翻卡评分 → 退出；原型备份可导出及合并恢复，原进度保留。
