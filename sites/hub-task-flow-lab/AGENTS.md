# Hub 任务流程实验室维护约束

本文件适用于本目录及其子目录。同步到 `VondeSong/hub-search/sites/hub-task-flow-lab/` 后，继续遵守仓库根目录及所有适用上层的 `AGENTS.md`；本文件不覆盖更高层指令。

## 定位与授权边界

- 这是独立交互原型，不是正式桌面程序、移动客户端或真实任务连接器。
- 所有任务、资料、AI 输出、来源保存与同步回执均为本机示例或模拟。不能把模拟成功写成真实远端已保存、已完成或已撤销。
- 不接入账号、凭据、外部模型或任务 API，不上传用户资料；真正接入需要另行明确需求、授权与验收方案。
- 不因修改本原型而改动 `desktop/`、旧 Hub 工作台、旧手机端原型或它们的 Site 映射。
- 不擅自新增发布目标、提交、推送、创建 Release / 标签或发布安装包。外部写入与发布必须在当前任务授权范围内，并在完成后核验。

## 不可破坏的交互契约

1. **同一行动保留同一身份。** 候选确认、关联资料、加入行动池、等待恢复、完成重试、重开与日志均引用原任务 ID。加入行动池不复制任务、不移动原清单。
2. **资料、候选与任务分开。** 资料来源筛选应包含真实关联材料；只留资料、暂放和忽略不创建任务、不删除材料。候选已处理后重复提交必须幂等。
3. **日期不凭空补全。** 新建任务的计划日、截止日均可空；保留两者差异。硬性截止与今日计划不能被行动池 5 项限制隐藏。该上限是本原型展示的个人偏好规则，不声明为正式桌面程序的既有功能。
4. **等待与完成意图分开。** 等待需要对象和条件；恢复不等于完成。pending / failed 完成操作应先核对、重试或明确取消，不能在旧意图仍有效时静默修改任务。
5. **模拟回执与日志一致。** 未确认成功不标记完成、不写入完成日志；重试使用同一操作 ID；旧回执不得完成新操作。重开保留原历史。
6. **草稿与异步工作属于具体任务。** 候选草稿按候选和处理模式隔离，助手草稿按任务隔离。被拒绝的提交不清空输入；重置后旧 AI 回调和旧完成回调不得写回新状态。
7. **重置仅影响本原型。** 存储键使用 `hub-task-flow-lab-` 命名空间，不调用 `localStorage.clear()`，不读取或清理旧站点存储。改变存储结构须更新校验与兼容方案。
8. **失败可见且不假保存。** 浏览器存储失败、模型校验失败和模拟同步失败应分别说明；对话框内错误应在对话框内可见。
9. **引导不是固定任务替身。** 引导应跟随候选实际关联或新建的任务，并能按当前状态恢复；不能在分支后悄悄跳回另一个示例任务。
10. **界面与文档保持一致。** 修改流程分支时同时核对 `dist/flow.mjs`、`dist/task-flow.svg` 与 `docs/task-flow.md`，不让示意图承诺代码没有的能力。

## 修改与验证流程

- 先读取相关实现与现有测试，保留其他任务已经修改的内容。使用 `apply_patch` 编辑，不进行破坏性清理。
- 修改交互后运行 `npm run check`。模型测试与 UI 静态契约都必须通过；不能只报告语法检查成功。
- 静态契约不等于浏览器验收。涉及弹层、键盘焦点、异步回执、草稿、重置、窄屏或主题时，应补充对应浏览器步骤，并明确实测的尺寸与环境。
- 当前基线记录为 38 项检查（24 模型 + 14 UI 静态契约）；后续变更须重新运行并更新真实数量，不沿用历史“通过”作为当前证据。
- 不将自动测试数量或局部颜色对比计算描述为全页面 WCAG 合规，不把桌面浏览器窄视口模拟描述为真实移动设备实测。
- 保存本轮验证范围、失败情况和未测项到 `docs/verification.md`。引用图片或日志时只记录真实观察，不补造账号数据或远端结果。
