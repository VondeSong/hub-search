# 任务状态：只看进展与上下文

2026-11-08。用户明确选择从对话面板完全移除 Token 预算，仅保留任务进展与上下文。此决定覆盖之前“默认展开”与“保留在高级设置”的两版方案。

- “查看任务状态”打开仅含两行的紧凑面板：任务进展与上下文占用。进展直接来自当前请求状态，区分尚未开始、正在处理、已暂停及回答已生成；上下文无数据时显示尚未报告。
- 对话面板与普通详情均不再包含 Token 输入框、高级预算入口、累计用量说明、上限示例或长篇解释。不填写预算也能直接提问，旧设置和历史记录仍保留。
- 保留原型现有字体、配色与定位，收窄独立状态面板并删除对应无用的表单状态和样式。
- 已将决定补入 [GitHub #28](https://github.com/VondeSong/hub-search/issues/28)。真实自动安排、执行上限与续行授权仍待开发；隐藏界面不等于解除后端约束。本地 Hub 源码未改。

## 实际验证

TypeScript、生产构建与 4 项针对本轮的 DOM 交互检查通过。覆盖状态面板仅两项且无表单、普通详情无预算、保留旧设置、未填预算直接提问，以及正在处理和停止后已暂停的准确呈现。界面静态检查未报告问题。
