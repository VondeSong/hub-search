# 洞察保存前依据确认

2026-11-12，关联 hub-search #2 首批桌面接入。

在既有「选择已有成果」流程中，勾选候选之后显示依据确认。用户须核对每条候选的引用及适用背景，之后才能保存。切换范围、成果或候选会清除确认；重复保存仍遵循原有出处幂等规则，不改变既有状态。共同背景须在成果中明确列出；不会把同一 Work 曾经读取的全部资料自动转成单条发现依赖。

沿用原页面样式，确认区放在内容滚动区域，底部取消／保存操作保持可见。已在本地浏览器核验未确认禁用与确认后启用，TypeScript、生产构建和既有 18 项 ledger 检查通过。

这是浏览器示例流程；正式数据库、真实模型、整库恢复与权限验证仍由 desktop 的独立验收负责。当前 Sites 编辑连接未取得发布权限，本次源码修改尚未部署至原站；来源快照继续保留线上 v80，未伪造新的发布编号或哈希。
