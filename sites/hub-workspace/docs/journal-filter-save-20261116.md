# 筛选面板直接保存

本轮补齐 v103 中缺少的保存流程。参考 Notion 的“选择属性、设置条件、明确保存到视图”组织，但 Hub 是个人视图，不使用“为所有人保存”的协作文案。

- 筛选弹层的属性层和条件编辑层均保留保存区，明确区分临时调整和已保存状态。
- 已保存视图可直接保存到当前视图，或恢复原有条件；保存不包含临时搜索词。保存后面板保持打开，状态切换为已保存，保存按钮禁用。
- 默认视图和现有视图均可另存为新视图，复用命名、重名校验和30个视图上限。打开命名弹窗时先关闭筛选弹层；取消不新增或覆盖视图，焦点回到筛选入口或条件标签。
- 本月、今天、全部资料库选择后保持编辑器打开，便于继续设置和保存。编辑器内移除条件返回属性层；标签叉号仍独立移除。
- 查询仍即时预览；关闭弹层保留临时条件，不伪称已保存。视图菜单原有更新/恢复入口继续保留。
- 原“完成”改为中性的“收起”，明确只关闭面板；保存使用独立按钮和状态反馈，避免混淆。

不新增高级 AND/OR 构建器、协作权限或同步能力；原型仍使用浏览器样例，桌面迁移继续使用真实来源及原有配置存储。
