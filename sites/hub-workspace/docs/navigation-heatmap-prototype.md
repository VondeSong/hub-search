# 热力日历与左侧栏调宽原型

入口：`/?view=journal&layout=calendar`。本轮仅更新 Sites 原型。

## 热力日历

- 左侧小日历和主区域月历都按原型记录集中的日志、速记条数着色；任务不计入。每个日期按稳定记录 ID 去重，资料库数量单独去重，修正原来同日多个记录被覆盖成一个来源值的问题。
- 固定档位为 0、1、2、3–4、5 条及以上，绿色逐级加深，跨月保持同一含义；提示包含实际数量，附有图例。
- 保留日期选择、今天标识、月份切换和方向键/Enter 定位。新增或修改记录日期时重新统计。
- 手机月历显示完整七列，以日期和数量为主；点击日期沿用当天记录展开。小日历继续放在原日志导航中。

## 左侧栏

- 内容/阅读等通用模块，以及日志、任务、库结构、闪卡接入同一个拖动分隔线。此前日志、任务和库结构使用固定宽度；闪卡独立处理拖动，未保存宽度。
- 鼠标可在侧栏右边缘拖动；宽度范围为 200–420px。支持方向键微调、Shift 加大步长、Home/End 到边界及双击恢复该模块默认值。
- 每个模块独立保存宽度，刷新、模块切换及收起再展开后恢复；布局设置中的恢复默认会清除这些宽度偏好。
- 保留手机抽屉导航，隐藏拖柄；桌面保存的宽度不会挤压手机正文。

## 实际检查

- TypeScript、新增 `navigation-heat-check.mjs`、原任务/日志行为与闪卡额度回归，以及生产构建通过；新目标设计检测无发现。
- 实际鼠标验证日志 224→324、任务 224→284、内容 224→294、库结构 248→328 以及合并后的新版闪卡 232→312；刷新及切换后恢复各自值。库结构双击恢复 248，闪卡双击恢复最新默认 232，Home/End 验证 200/420，侧栏收起再展开保持宽度。
- 同日新增记录后数量 4→5，热力档位 3→4；验证日期点击、Arrow/Enter、跨月、月历当天展开及收起。
- 1280×720、1856×1000、390×844检查；手机月历网格完整七列，无页面或网格横向溢出，手机拖柄隐藏。
- 独立复核实际查看用户参考图、七张交付截图和代码，结论 ship，无必须修正项。沿用现有视觉体系，不改全局设计系统。
