# 助手菜单字号与自动执行额度原型

日期：2026-11-08。仅修改浏览器原型，本地 Hub 源码未改。

## 本轮交互

- 模型、思考强度和任务菜单的主文字统一为 12px，说明与分组为 11px。模型／思考菜单从 360px 收至 300px，任务菜单从 320px 收至 300px；提供方图标改为 18px，缩减行间留白。尺寸按现有原型的 CSS 像素设置，不推定截图的系统缩放比例。
- 任务用途保留六种选择。执行额度移除标准／扩展手动选项，改为只读“自动安排”，并提供“查看用量与上限”入口。
- 该入口直接打开对话详情中的“用量与任务”：说明按问题、资料量及进展安排、由系统限制上限，达到上限仍未完成时先交代进展和继续所需额度，再由用户决定是否续行。
- 新请求偏好为自动；旧会话的手动偏好迁移至自动，已经暂停或排队的请求保留原快照，不恢复为自动运行、不隐式改变其模式。

## 真实实现边界

这里只演示自动执行规则，未接入真实模型、预算调度、累计计量、到达上限暂停或续行授权。已有模型用量上限表单仍为原型选择，不能冒充执行端保护。

本地源码当前由 `AgentTaskMode.tsx` 选择 quick／deep，后端 `agent_work.rs` 与 `agent_work/assistant.rs` 再确定不同的预算。真实自动调度需要前后端配合，已经登记为 [GitHub #28](https://github.com/VondeSong/hub-search/issues/28)，模块 Agents、状态待处理。用户明确本轮不修改本地源码，不以原型发布宣布该任务完成。
