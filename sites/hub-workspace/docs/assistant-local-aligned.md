# 助手原型与本地源码对齐

核对日期：2026-11-08。本地参照为 `VondeSong/hub-search` 提交 `1c580cfed200a35fe7922ec27628801ffd3bdc90`，桌面版本配置为 0.16.396。此次只修改浏览器原型，没有修改桌面业务代码。

## 对齐范围

| 本地依据 | 原型实现 |
| --- | --- |
| `AgentInvestigation.tsx`、`AgentAssistantRefinement.css` | 顶部历史、新对话、居中任务模式、详情、关闭；欢迎文案与材料建议；建议先填入问题，等待用户发送 |
| `AgentTaskMode.tsx` | 标准／扩展选择与说明，从标题入口打开 |
| `AgentAssistantOptions.tsx`、`AgentModelMenu.tsx`、`AgentModelMenu.css` | ＋添加菜单、保存权限、资料范围；输入框右侧推理强度、Fast 和模型提供方菜单 |
| `AgentConversationHistory.tsx` | 对话搜索、切换、置顶、归档与恢复，保存本浏览器会话内的历史状态 |
| `AgentInvestigation.css`、`useAgentPanelResize.ts` | 默认 440px 宽、半屏高且至少 320px 的浮窗；左右留 12px；可拖动、键盘调整、双击恢复；详情内切换侧边栏 |
| `StandaloneAgentLauncher.css` | 右下角 44px 高的“助手”入口及彩色圆环 |
| `AgentInvestigation.tsx` 发送处理 | Enter 换行，Ctrl/Command+Enter 发送；运行中默认立即追加，可切换排队；加 Shift 临时切换本次发送方式 |

主题继续使用本站的 `--surface`、`--text`、`--muted`、`--line` 和 `--accent`，对应本地主题表面、正文、次要正文、分隔线和强调色。未引入另一套视觉方向。

## 保留与兼容

- 继续读取 `hub-proto-assistant-v2` 快照，并兼容 v1。新增历史元信息保存在同一快照中；新对话使用独立身份，不覆盖原工作。
- 保留原工作引用、未发送输入、附件名称、排队和暂停记录。刷新或切换工作后，运行保持暂停，需手动继续。
- 保留来源不可用时的内容隐藏、发送阻止与草稿保存检查；保存笔记、任务仍需用户预览确认。
- 任务、日志、洞察、资料库及已有示例的业务处理保持原有实现。

## 原型与真实能力边界

这次对齐界面结构与可演示交互，不代表连接了本地后端。模型提供方、推理强度、Fast、联网与工具连接仅控制演示设置；不读取真实可用模型、账号、共享记忆或 MCP。技能使用明确标注的示例处理方法，文件仍只记录名称。公共链接、资料库图片和闪卡自动导入没有真实后端，入口说明相应范围；未伪造调用成功。

历史保留在当前浏览器会话存储中，不是桌面数据库或跨设备同步。浮窗尺寸保留在本浏览器本地存储中。
