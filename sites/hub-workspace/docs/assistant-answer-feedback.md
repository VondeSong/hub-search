# 助手回答交互与提供方设置修正

日期：2026-11-08。仅修改浏览器原型，本地项目未改，未控制电脑界面。

## 本轮修改

- DeepSeek 不再因提供方判断而丢失推理入口，提供关闭和低／高／最大三档，默认开启。中、超高等原有状态按官方映射显示为高，不伪造五档独立能力；切到 OpenAI 仍保留五档。设置随下一条演示请求保存，未发起真实 API 调用。[DeepSeek 官方思考模式说明](https://api-docs.deepseek.com/guides/thinking_mode/)
- 模型使用提供方官方站点图标，保持原资产比例，不给不同 GPT 型号发明独立品牌标识。OpenAI 图标来自 `https://cdn.oaistatic.com/assets/favicon-eex17e9e.ico`；DeepSeek 图标来自 `https://www.deepseek.com/favicon.ico`。资产属于各品牌，仅用于模型提供方识别，不表示合作或背书。[OpenAI 品牌规范](https://openai.com/brand/)、[DeepSeek 官网](https://www.deepseek.com/)
- 任务菜单标题改为 13px、说明 11px，行高从至少 68px 收至 54px，菜单宽度从 360px 收至 320px；其他菜单的文字层级保持不变。
- “复制回答”改成双页轮廓图标按钮，保留辅助名称、悬浮提示和失败提示，成功后短暂显示勾选反馈。
- 将“准备笔记”改为“新建笔记”：把回答保存为独立笔记；将“准备任务”改为“创建任务”：把内容整理为可编辑待办。两者仍先预览再确认。它们是用户对已生成文字的保存操作，对 DeepSeek 回答也可使用，不代表 DeepSeek 执行了真实工具调用。
- 新增“插入页面”：可选当前页面，也可按标题／资料库搜索可写目标；确认前展示目标、现有内容与可编辑的待追加正文。只追加到末尾，不覆盖原文。

## 插入保护与边界

固定只读样本和任务不列为可写页面；来源或目标失效时不能确认。确认时核对页面版本，变化或失败时保留草稿；同一操作身份重复提交不会重复追加。原文段落和已有清单保持原样，新插入段落单独记录来源依赖；来源被撤回时只隐藏相关插入段落，保留目标页原文。

插入只更新当前浏览器里的 Hub 示例数据，不写入真实 Craft、Obsidian 等外部页面，也不变更本地客户端。

## 验证

16 项助手状态检查、7 项页面插入检查、8 项反馈组件交互检查通过。交互覆盖 DeepSeek 推理、模型图标、图标复制、保存动作、当前页插入、搜索目标、取消无写入、只读排除和失败保留草稿。TypeScript 检查与生产构建通过；没有进行截图、实机或真实后端验收。
