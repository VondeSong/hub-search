# 日志工具栏与筛选交互优化

日期：2026-11-16。关联：VondeSong/hub-search #22（日志与速记）。

## 目的与范围

针对网页原型日志区的视图栏和四列表单式筛选，减少视觉占用、明确筛选状态，并修复搜索和日期范围与实际显示内容不一致的问题。

## 界面与交互

- 顶部改为紧凑视图栏和搜索条件栏。正常桌面宽度下约 109px 高。
- 搜索保持可见，日期、资料库和内容类型以可编辑、可单独清除的条件标签展示。
- 详细筛选使用原生 popover，支持 Escape、焦点返回、视口内定位和资料库多选。
- 清除筛选保留搜索词和当前布局；搜索词可独立清除。
- 新建视图使用命名弹窗，支持重复名称提示；修改已保存视图后提供更新和恢复。
- 卡片布局复用统一搜索入口，保留记录操作、输入区及保存位置设置。
- 使用现有主题变量，修正深色主题确认按钮文字颜色；窄内容区自动换行。

## 行为修复

- 每日记录搜索、全日期及资料库/内容筛选按真实匹配日期展示，历史命中不再受当前七天窗口遮挡。
- 按月展示不混入下月日期；指定日期与月份、导航锚点保持一致。
- 从历史月份切换指定日期时，采用同月锚点或该月第一天。
- 月历数量跟随筛选；全日期结果跨月时显示可直接跳转的匹配月份。
- 保留已保存视图的多资料库和空资料库选择，兼容已有 v1 存储与 table → list 布局迁移。
- 隐藏或删除当前保存视图后回到默认配置；切换范围关闭旧预览与当天面板。

- 现有 `task-journal-check.mjs`、`memo-check.mjs`、`navigation-heat-check.mjs` 通过。
- 浏览器检查：历史搜索、组合筛选、空资料库、清除条件保留搜索、保存与恢复视图、单一搜索入口、原生日期键盘跨月、月历匹配月份跳转、Escape 与焦点返回。
- 浅色/深色主题和约 599px 宽的内容区实测，页面无横向溢出；筛选弹层位于可见视口内。
