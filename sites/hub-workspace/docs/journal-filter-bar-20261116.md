# 筛选按钮与条件栏对齐参考截图

接续v105保存流程。用户提供的Notion截图显示：顶部图标切换第二行条件栏，条件栏中已设置项为强调色标签，未设置日期仍有入口，栏内“＋筛选”打开属性选择，再进入条件编辑。此前直接从顶部按钮弹出属性列表，属于交互偏差。

- 顶部改为单独筛选图标，显示真实展开/按下状态；只切换条件栏，不改任何筛选值，也不直接打开弹层。
- 条件栏展开时，即使没有条件也保留“日期”和“＋筛选”，不会因零条件而自动消失；隐藏条件栏不会取消条件。
- 标签使用当前Hub主题的强调色圆角样式，并明确属性与值；点标签直接进入二级条件编辑。资料库、内容类型继续使用Hub自身真实业务语义，不添加Notion任务状态字段。
- “＋筛选”负责属性列表，日期入口只进入编辑器，未选择日期时不应用条件。删除最后一个条件后仍可继续添加。
- “清除全部”移到属性弹层，条件栏不堆积工具按钮；保存、另存、恢复和“收起”沿用v105。

使用既有Hub字号、间距和主题变量，按参考截图的控件相对关系调整，不改变页面其余布局。测试与实际发布状态随根仓库交付记录更新。
