# 日志导航、布局与保存视图原型

## 2026-11-09：精简工具栏与视图菜单

- 全局左栏已有二级导航开关，日志内容区不再重复放置。移除内容区重复标题、年月、前后月及今天按钮，日期跳转集中到左侧。每日记录／卡片已有编辑器；列表和月历保留唯一的「写日志」入口。
- 点当前视图标签的下拉箭头集中设置。自定义视图可直接编辑名称并保存或按 Enter，布局变更仍沿用「更新视图／另存为」的原有规则。支持复制与删除自定义视图；默认视图可复制和恢复，名称固定、不可删除。排序和显隐保留在折叠的「管理所有视图」。
- 标签侧栏本轮不新增。原型记录含正文 `#标签` 与来源结构化标签；桌面已有按库标签统计和分页日志查询，但全库标签统计包含非日志内容，不能直接用作日志计数。如后续确有按标签回找需求，首版可折叠展示当前资料库、日期范围内最常用的 5–8 个，按标准化标签与记录身份去重，点击进入现有筛选；按范围和数据版本缓存，展开时查询，避免逐页扫正文或渲染全量标签。需用实际日志规模验证延时，不能将小样本原型当作桌面性能结果。
- 类型检查、构建、日志脚本、视图交互与原有主题／筛选回归均通过；静态界面检查未报告问题。未做本轮浏览器截图对比。本地桌面源码未改。

## 设计范围与职责

本轮属于现有界面的局部修正：年月选择器不再挤动日历，布局命名反映内容用途，顶部与侧栏各自承担清楚的导航职责。沿用已有字体、主题、语义色、圆角与组件样式，无需调整全局设计变量，也未创建或改写 `PRODUCT.md`、`DESIGN.md` 或 `.impeccable/design.json`。

- 顶部负责切换、保存和管理视图，以及调整显示方式与筛选条件。
- 左侧保留日期导航与常用内容筛选，不再重复列出保存的视图。
- 内容区提供按天记录、跨日期回看、月历定位和列表浏览。

## 年月选择器

点击侧栏年月打开悬浮选择器。选择器使用原生自动弹层，覆盖于页面上方，不占用日历布局空间；点击外部或按 Esc 可关闭。保留年份输入、上一年／下一年、月份选择及查看整月操作，原有年份边界与日期处理继续适用。

桌面 1440 × 1000 实测中，日历日期网格展开前后顶部位置均为 `494.4583435058594px`，没有下移。390px 手机视口中弹层可完整显示；深色主题下也已检查。

## 布局与内容筛选

日志布局统一为四种：

| 名称 | 用途 |
| --- | --- |
| 每日记录 | 原“日历流”；按日期连续显示日志、当天安排、新建与完成记录，并提供当天输入 |
| 卡片 | 原“速记卡片”；来源日志与速记统一按记录浏览，可跨日期回看 |
| 月历 | 按月定位日期，展开当天记录并进入写入 |
| 列表 | 按日期分组浏览记录摘要与来源 |

日志表格入口已移除。浏览器中已有的 `table` 布局配置读取时自动迁移为 `list`，保留可用配置。

侧栏“常用筛选”提供“置顶记录”“带附件”“未加标签”，点击后进入全部日期的卡片浏览，并显示当前内容筛选及清除入口。筛选作用于速记与来源日志的统一记录集合；来源日志保留只读行为，浏览器速记保留原有编辑与置顶操作。

“未加标签”同时检查来源记录的结构化标签与正文中的 `#标签`，避免将有来源标签的日志误判为无标签。“带附件”按记录的附件名称清单判断。当前验收浏览器的计数为置顶 **1**、带附件 **0**、未加标签 **0**；这是该浏览器示例状态的结果，不是固定业务总数。

## 保存视图

顶部以“默认视图”和已保存视图作为切换入口，使用 ＋ 保存当前组合。保存内容包括显示方式、日期范围、来源资料库、关键词及内容筛选；内容筛选已纳入持久化视图配置，切换或刷新后可恢复。

顶部管理菜单集中提供视图排序、隐藏和恢复显示。布局设置中保留复制、重命名、隐藏、删除配置等操作；已保存视图发生修改时可更新或另存为。手机管理菜单同样使用页面顶层弹层，避免被顶部容器裁切。
