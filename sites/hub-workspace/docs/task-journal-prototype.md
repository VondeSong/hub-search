# 任务五视图与日志对齐原型

本轮沿用既有站点的字体、语义色、导航和阅读样式；任务入口扩展五种视图，日志以当前 desktop/src/JournalWorkspace.tsx、JournalDailyStream.tsx、QuickJournal.tsx 为对照。桌面业务交互未修改。后续先更新站点原型，经用户明确指令再修改本地交互。

## 任务

列表、状态看板、示例周时间线、任务拆解图、资料关联图共用稳定任务 ID。滴答示例沿用库结构的 d-* 对象，既有 Hub 任务也可在全部任务中浏览；笔记清单不作为可完成任务。滴答示例任务的状态、计划日、独立完成日、正文检查项存入同一浏览器状态，任务页、来源结构和日志任务事件共用。父任务完成不自动改变子任务或检查项。

- 列表提供项目、状态、日期与独立完成框；新任务使用既有原型创建入口。
- 看板按待办、进行中、等待条件、已完成分组，选择卡片状态移动任务。
- 时间线为 2026-11-09 至 15 的单日计划示例；无日期列入未安排；完整日期超出该周显示“本周范围外”，不按日号猜测。
- 拆解图表达真实父任务/子任务，支持展开折叠；筛选后不重新加入不匹配子项。
- 资料关联图以当前任务为中心，使用手动定义的设计依据/评审记录/方法参考等关系。点资料显示正文，可定位回来源结构。连线不代表任务依赖。
- 看板、时间线和图形切换时默认收起详情；点击节点可阅读。手机收起详情后回到内容，避免空白。

## 日志与本地对照

直接复用本地 JournalViews、JournalNavigator、JournalNavigation 和四份日志 CSS；JournalViews 的存储适配为独立 prototype 浏览器命名空间。JournalSite 使用虚构/既有示例资料呈现相同布局，不复制本机真实日记。

| 本地现有体验 | 原型对齐 |
| --- | --- |
| 默认日历流，日常记录标签 | 相同默认布局、日期导航、连续日期与空白日 |
| 日志缩略卡、当天安排/当天新建、完成记录 | 共享示例任务；完成日独立于计划日；完成记录弹窗可查看 |
| 速记卡片 | 输入、日期、标签、卡片、附件名称选择、浏览器草稿与记录持久化 |
| 月历、列表、表格 | 布局菜单切换；月历日期展开当天内容，可写这一天 |
| 筛选与保存视图 | 关键词、日期、资料库范围、显示属性、密度、顺序；保存/复制/重命名/隐藏/删除及导航管理复用本地视图配置 |
| 日期侧栏与我的视图 | 复用本地导航组件和配置行为 |

实际后端边界：原型仅保存当前浏览器示例数据；没有 OS 日记写入、OSS 上传或真实滴答同步。附件只保存名称，不保存或上传文件内容；同步按钮禁用并说明原因。不把原型状态显示为已写入 OS 或已云同步。截图中的记录为手工验收示例。

## 核验

- 类型检查、原有12组库结构/搜索/分栏检查通过。
- task-journal-check 验证状态覆盖、日期覆盖/清空、真实子任务归属、跨库关联身份、跨月日期及保存视图的资料库范围。
- 实际桌面操作验证五视图切换、状态更新、跨年日期范围外、资料正文/来源定位、任务状态回读及日志完成记录。
- 速记保存及视图保存已实际操作，刷新后正文、所选OS范围、视图名称与状态恢复。
- 390×844 手机验证任务关联资料阅读/返回、详情收起不空白、日志日历流及布局切换。
- 真实账号写回、大规模数据和本地安装验收不属于本次原型交付。

## 任务页以本地布局为准的修正

用户反馈上一版任务页布局与本地不一致。本轮以用户截图及 desktop/src/TaskWorkspace.tsx、WorkspaceRefresh.css 为直接依据：侧栏仅保留项目与清单，逐条显示名称、所属库和数量；顶部先显示全部/滴答/Craft/Obsidian来源统计，再显示列表、看板、表格与新建视图；筛选条件独立展示，可逐项删除或一键清除。搜索、排序/筛选、统计与预览入口集中在视图栏右侧。默认全部项目、待完成筛选、预览关闭。

原时间线、拆解图和关联图保留在“新建视图”菜单，避免取代本地默认入口。新增4条明确的虚构Craft/Obsidian任务用于检查跨源筛选；统计由示例数据计算，不复制截图中的真实534条账号数据或私有任务正文。项目同名时按来源分别保留。

本轮只修站点原型；本地任务业务代码未改动。

对照检查：已实际复现“选中 Car 主项目 + Obsidian 来源 → 空结果 → 清除筛选恢复”的流程，表格切换可用。默认待完成与本地一致。新视图配置保存在浏览器，按视图恢复来源/状态/排序；更多菜单只展示未接入的同步能力及示例操作；刷新重读浏览器状态，不冒充远端同步。
