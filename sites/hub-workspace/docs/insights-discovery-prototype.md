# 洞察新流程原型

关联任务：Hub #52；模块父任务 #41。此轮按用户纠正先做原型，尚未修改桌面业务代码。

入口：洞察 → 发现 → 开始发现。旧的成果选择保留在更多菜单的“从已有分析导入”。

新流程沿用原工作台的布局、主题、对话框、按钮及颜色变量。两个例子分别使用明确标识的固定工作资料和生活记录，不连接私人资料、模型或后台任务，也不填充个人判断库。

可体验：选择资料、查看原文、直接看发现、适用条件与未知、保留、加入后续记录、核对新旧依据、维持／采用修订、查看历史、纠正关联及撤销。缺少两侧必要依据时不产生发现；相同关键词的仓库材料不构成 DXF 应用关系。

每个例子的状态独立保存在当前浏览器。关闭后可从首页“新流程体验”入口接续；切换例子不清除另一例的记录。“重新体验此例”只重置当前例子。原有发现账本、公开资料案例、阶段回顾、主题与决定记录不迁移、不合并。

维持原判断与采用修订均保留新观察、理由和原版内容；同一后续记录不会因重复点击新增修订。原文是固定示例，可回看但不可编辑。任何结论都只是演示，不代表真实检索、自动采集、模型分析或真实工具验证。

验证：独立状态检查脚本覆盖未分析不能保存、无资料、同词干扰、不能自动改判、维持、修订、重复确认、纠正和状态恢复。浏览器检查覆盖工作修订、生活维持、引用、刷新接续、切换场景、无结果与纠正；标准桌面、640及390像素宽度检查。

这是本轮首个可比较的交互原型。个人资料中的真实效果、与助手＋Skill的公平对照、源权限和版本变化、后台范围、通知、桌面接入继续按 #52 验收，不由原型测试替代。
