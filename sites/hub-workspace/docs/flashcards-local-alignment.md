# 闪卡今日首页与本地对齐

本轮仅更新站点原型，本地桌面软件与真实闪卡数据不变。

## 对齐依据

读取 hub-search 的 desktop/src/FlashcardsWorkspace.tsx、FlashcardsWorkspace.css、FlashcardTodayProgress.tsx、FlashcardToday.css、StudyProgress.tsx。首页直接沿用本地的布局、字号、圆角、间距、配色和窄屏规则。

- 左侧搜索、今日、牌库、收件箱、统计、质量与制卡偏好和牌组导航。
- 今日待复习数量、日期、本次张数、每天新卡和开始复习入口。
- 今日完成、新卡额度、连续学习与最近七天的学习节奏。
- 未完成一轮时显示继续复习入口，练习中提供显示答案、四档评分、稍后再看、暂停与撤销。
- 支持直接访问 `/?view=flashcards`，其他页面保持各自的交互。

## 原型数据边界

沿用原来的四张示例问答卡，分为学习笔记、工程知识两个示例牌组。首页的历史学习数值为示例。复习设置及示例进度仅保存在浏览器中，按上海日期开启新的示例日。

当前未接入本地数据库、云同步、备份、编辑或制卡服务；管理入口保留位置并显示说明。统计入口演示今日进展和七天节奏，不代表已移植完整桌面统计模块。评分间隔为演示值，不运行正式调度算法。

## 验证

- TypeScript 检查通过，站点生产构建通过。
- `node scripts/flashcard-check.mjs`：8 项检查通过，覆盖每日新卡额度、已学新卡、单轮上限、不限额、牌组范围及空队列。
- 浏览器验证：首页、设置、显示答案、评分、重来保留卡片、撤销、暂停继续、完成状态、刷新后的设置保留和直达链接。
- 1280 × 720 与 390 × 844 宽度检查；窄屏页面无横向溢出。
