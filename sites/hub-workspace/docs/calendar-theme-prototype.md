# 日历年月与日志主题原型

## 2026-11-09：主题与常用筛选联动

- 背景主题默认决定强调色，例如浅蔷薇配玫瑰、雾蓝配湖蓝。日历五档热力、图例、选中态、年月弹窗和日志视图菜单随之更新，热力统计规则不变。外观设置仍可明确指定强调色，或选「跟随主题」；旧版独立颜色配置升级为随主题，新选择会保存。
- 右侧筛选增加「内容类型」。左侧选择会展开右侧筛选并同步显示，右侧修改或清除会同步高亮；再次点击已选快捷项也可清除。复用同一筛选值，保留日期、资料库、搜索、布局，快捷项计数按当前范围计算。
- 本轮通过主题与筛选交互检查、TypeScript、日志筛选与日期检查、热力检查和生产构建；静态界面检查无报告。未进行本轮截图对比。只改站点原型，本地桌面源码未改。

## 2026-11-08：原始年月与主题核验

核验日期：2026-11-08。本轮在现有 Hub Operate 站点原型中扩展日志导航，沿用现有字体、主题、强调色与布局系统。

## 已实现行为

- 侧栏日历标题完整显示“年份＋月份”，日历图标、年月文字与展开图标居中对齐。
- 点击年月打开内联选择器，自动聚焦并选中年份。支持输入 100–9999 的整数年份、上一年／下一年及十二个月快捷选择；无效年份禁用月份与“查看整月”。
- 选择月份立即跳转；Enter 按当前显示月份查看整月。Esc 或“收起”关闭选择器并将焦点还给年月按钮。保留上个月、下个月和回到今天入口。
- 日期键统一补齐为四位年份，例如 `0100-01-01`。侧栏越界补位日期不可选，键盘导航不越出范围，主日历流过滤越界日期。
- 日志输入、按钮、标签、卡片与热力图使用宿主的表面、文字、边框及强调色语义变量。热力仍按记录条数分为 **0／1／2／3–4／5+** 五档，不含任务；主题与强调色切换不改变分档含义。
