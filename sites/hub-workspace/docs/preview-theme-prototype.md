# Craft 风格预览主题

2026-11-11，关联 Hub #27。本轮只更新现有站点原型，桌面端、编辑和批注不在本轮范围。

## 体验入口

- 在资料阅读面板上方切换“当前 / Craft 风格”。两种样式使用同一个文档节点与同一份正文。
- “对比样本”打开固定示例《给知识留一处，安静的阅读空间》，包含中文长文、标题、列表、引用、提示、复选框，以及用于排版观察的表格、代码、图片和相关文档入口。
- 太阳/月亮按钮复用现有浅色/深色外观。主题选择保存在当前浏览器；普通入口初始使用当前样式，`?preview=craft#item=preview-theme-sample` 可直接打开 Craft 样本。
- 切换预览主题保留当前阅读块的位置，避免长文比较时跳到另一段。

## 展示约定

沿用 Hub 的界面和系统字体，仅调整预览正文区域。Craft 风格使用更清楚的标题层级、16px 正文、较宽松的段落间距、克制的引用缩进和柔和提示底色。窄面板正文为 15px；最大文档宽度 840px，含自适应页边距。

表格和代码在各自区域内横向滚动，图片随正文宽度缩放，相关文档保留实际跳转。本轮为 Craft 风格主题，不承诺像素级复刻或恢复来源未提供的特殊布局。没有增加依赖，没有变更主数据格式。

样本中的表格、代码、截图和页面卡片是原型专用展示块，不代表当前通用 Markdown 渲染器或真实来源同步已经具备这些新增能力；截图复用站点原有素材。清单沿用原型现有的浏览器本地演示行为。
