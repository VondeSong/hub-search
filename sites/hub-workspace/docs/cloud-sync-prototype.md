# 云同步中心原型

关联：[云同步规划 #3](https://github.com/VondeSong/hub-search/issues/3)。本站独立于桌面仓库，本轮仅修改站点。

## 当前入口

- 直接访问 ?view=cloud；全局云图标、设置与闪卡顶栏进入同一个同步中心。
- 主页展示总状态、闪卡/阅读/速记结果、立即同步、暂停/恢复及最近记录。连接与诊断从同步设置进入。
- 数据与存储、速记保存位置、来源与采集、备份与恢复仍使用独立设置页面。云同步只保留跳转，不维护重复表单。

## 按上传与下载组织设置（2026-11-11）

- 同步内容使用一行三个模块开关。上传到云端、下载到本机分为两张紧凑表格，共同分类只在表头出现一次，删除三组独立折叠、重复说明及过多留白。
- 上传表对齐正文与记录、附件；闪卡/速记沿用随内容上传，阅读保留原有附件上传开关。下载表以模块为行，图片/视频/PDF/其他和单个上限为列，全部直接可见。模块关闭时对应行禁用，设置保留。
- 新配置默认图片/PDF开启，视频/其他关闭，单文件20 MB；三个模块互不影响。其他包含音频与已支持的其他格式。
- 设置只控制本机自动下载，不影响上传、正文同步和已下载文件。未勾选或超限可在附件详情显式手动下载，操作显示大小；打开正文或附件详情不绕过策略。
- 删除每轮/每日额度、今日额度统计、更新时间、额度耗尽场景及阻断逻辑。旧保存值不再参与调度。
- 阅读上传选项位于上传表，完全独立于下载表。阅读网络、分类说明和速记差异收进更多设置与同步说明；缓存仍在数据与存储。
- 附件详情为每模块四个示例文件，按类型和大小演示自动/手动下载，显示本机状态。云端完成不代表所有附件已下载，按策略不下载不视为失败。
- 速记继续区分上传、等待电脑写入、正文已写入；本轮演示正文先写和附件后补，重复同步不重复写日记。这是目标交互，现有桌面仍需专门开发。

## 旧浏览器设置

沿用 hub-cloud-center-demo-v1；已存在新结构时验证三模块类型和大小范围。旧闪卡自动全部映射为全部类型，旧阅读自动映射为图片/PDF，原来手动的保留为手动；阅读统一上限取旧图片/PDF上限的较小值，避免扩大下载范围。旧速记全附件规则保留。旧本机下载标记迁到对应示例文件，不清理文件或队列。已有上传、网络、缓存、模块开关和保存目录保留；旧额度错误被清除。

旧日志目录一次迁入同一保存位置配置，已有自定义目录优先保留。刷新中断轮次清除运行标记，待处理改动保留。

## 其他能力与限制

- 同步仅处理启用模块；暂停、离线、凭据失败保留改动，停用模块错误不阻塞其他模块，也不伪装已经修复。
- OSS连接表单在管理连接中，凭据更新和更换位置分开；旧WebDAV继续保留迁移演示。速记仅支持OSS，已绑定速记时阻止不完整迁移，统一恢复仍不覆盖速记。
- 诊断包含设备、恢复、历史维护及暂停/失败续跑；来源采集和删除、文件备份各自管理，不混入同步完成状态。
- 保留字体、主题变量、颜色、图标与列表布局，不引入新视觉风格。

所有文件、网络、设备、同步和恢复均为浏览器示例，不连接真实OSS/WebDAV，不读取密钥、不传输实际附件、不操作真实来源或备份。本轮不修改桌面端。下载上限与真实支持上限分开：原型字段最多闪卡250 MB、阅读100 MB、速记20 MB。

## 检查入口

scripts/cloud-check.mjs 验证调度、类型与大小边界、独立设置、旧配置迁移、取消额度、已下载保留和速记正文先写及幂等。另执行TypeScript检查、生产构建、差异检查与浏览器桌面/窄屏核验；实际结果以本轮交付记录为准，真实云传输和双端同步未验证。

本轮实际检查：TypeScript、cloud-check、生产构建及差异检查通过，机械界面检查无发现。浏览器核验三个模块独立设置、开关保留及刷新保存、超限和未勾选类型手动下载、速记正文写入（8→11条）、手机390×844无横向溢出，浏览器错误日志为空。

第二轮表达调整检查：原有状态逻辑未改，TypeScript、cloud-check、生产构建、差异及机械界面检查通过。浏览器确认上传开关不改任何下载字段、独立下载与大小设置、关闭模块禁用对应行且重开保留、刷新保存；1280×900和390×844实看，两表无横向溢出。桌面端仍未修改。


## 苹果风格重设计（2026-11-11）

本轮替换云同步旧表格外观，云中心使用冷灰背景、白色分组、紧凑行和统一图标。玻璃近似效果只用于顶部工具栏和粘性分段导航；保留文字对比、焦点和不支持模糊／减少透明度时的实色回退。独立数据设置与其他模块不受影响。

参考 Apple HIG Materials（https://developer.apple.com/design/human-interface-guidelines/materials）的导航／内容分层；已查看官方材质页面和 Craft 参考库 Updater 原图，后者仅借鉴分组密度与分类图标，不复制窗口交通灯。此为 Web 材质近似，不声称原生 Liquid Glass 光学效果。

- 上传与下载各一个分区；正文规则集中说明一次，删除重复表头。下载类型用带图标、文字与勾选态的选择按钮，每模块保留大小上限。
- 闪卡、阅读、速记附件上传均可独立切换。新增 uploadFlash / uploadQuick，阅读沿用 media；旧数据默认保留原先上传行为。
- 关闭附件上传仍处理正文、保留未上传附件状态；重新开启后补传。已有云副本仍按下载策略下载。速记附件云副本状态独立于正文写入，不因重试重复写入。
- 所有控件均为浏览器原型状态；新增上传开关、正文先写等尚未实现于桌面。本轮不修改桌面端，不进行真实云传输。


## 文档风格与双向附件策略（2026-11-11）

本轮用户反馈苹果材质过重，改为借鉴 Craft 文档界面：中性页面、标题层级、细分隔与小幅圆角，移除玻璃导航、渐变背景、彩色图标底和大块卡片。仅采用其文档式信息层级，不移植官网宣传视觉。参考 https://www.craft.do/ 的产品界面展示，以及本项目现有 Craft 阅读预览。

上传与下载统一使用模块行，分别选择图片、视频、PDF、其他和单个附件上限。两组设置独立保存；正文和记录继续按模块同步。上传未选或超限的原件留在本机，放宽规则后可补传，既有云副本不删除。附件详情逐项显示云副本是否存在，不能因正文成功就宣称所有文件已上传。

上传策略 uploads、逐类型上传结果 uploaded 与下载策略 attachments 分开；沿用旧上传开关语义迁入，旧关闭保持全类型未选，旧开启保持类型及原模块硬上限（闪卡250/阅读100/速记20 MB），不重置旧下载偏好。新旧状态均做类型和大小校验。真实桌面端未实现此新上传策略，本轮仅浏览器示例，无真实云传输。
