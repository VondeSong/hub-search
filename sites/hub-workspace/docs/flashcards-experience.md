# 闪卡今日与复习体验：原型阶段

对应 hub-search #46。沿用原工作台站点、闪卡布局、主题与快捷键，仅更新浏览器原型；没有连接真实闪卡、评分、FSRS、同步或制卡服务。

## 已可体验

- 今日卡片堆预览默认隐藏答案；主动显示后才揭晓。切换预览卡片再次遮住答案。牌库浏览继续直接显示参考答案。
- 今日待学习是当天尚未完成、且额度允许的卡片；本轮是单轮上限内的张数。正在进行的一轮保留原队列，偏好的单轮上限只影响下一轮。
- 所有相关入口统一称“复习偏好”。牌组旁直接开始复习；已有一轮时明确“继续当前一轮”，不会悄悄丢弃原队列。
- 收件箱有两份明确标为示例的草稿，可编辑、移入牌组、丢弃。移入后才进入这个浏览器的卡片列表与后续计划。
- 选择题、填空题可先作答再揭晓。揭晓后的建议重来／记得只提示，必须主动选择评分；回答随练习保存，刷新和撤销可恢复。
- 四档评分显示固定示例间隔，明确不运行正式 FSRS。完成页显示已安排的下一次示例到期。
- 复习中可编辑示例参考文本、保留本地反馈和暂停单卡；牌库预览可恢复学习。点击卡片可揭晓，触屏评分留在底部，提示消息避开评分按钮。

## 自主选择的保守语义

这些选择用于原型验证，不表示用户已经逐项认可，也不自动成为真实排程合同。

| 条目 | 本轮原型选择 | 桌面边界 |
| --- | --- | --- |
| A3 额外新卡 | 每次最多补 5 张且不超过等待数量；只增加本示例日额度，次日归零；学习仍计入今日新卡，每日偏好不改 | 真实临时额度尚未实现 |
| B1 用时 | 至少 5 次带用时的示例评分才估算；不足显示“用时样本不足”，估算明确标为示例 | 不新增真实用时汇总或后端 |
| B3 节奏图 | 柱高对数缩放，真实示例次数完整保留；点击日期查看次数／新卡，零记录明确显示 | 未更改真实统计组件 |
| B4 未来到期 | 按已学卡片已有示例 dueAt 汇总 7 天，不预测未学新卡，后续评分可改变 | 未新增真实查询或预测服务 |
| C3 暂停 | “暂停学习”持续保留到主动恢复；S 只是移到本轮最后 | 不引入“今天不再出现”新语义 |
| C5 下一批 | 复用已安排的下一次示例到期和可用额外新卡入口 | 不承诺退出后调度或实际提醒 |

## 示例日期与状态

原型有 12 张初始示例卡、2 份待确认草稿。按上海日期生成历史样本，当日从零开始。已保存的原四卡练习可迁移，新增示例不会被误标为已学习。存储键保留，增加版本校验；未知版本或损坏字段安全回退。

“示例场景”包含正常、12 张今日／10 张本轮、额度用尽、断档与极值、空牌库、用时样本不足、未来到期。前一天／下一天只移动示例时钟；模拟日期在刷新和聚焦时保留，重置为今日才回到当前日期。额度跨日归零、已学身份及暂停状态保留；空历史刷新后仍为空。所有示例状态只保存在当前浏览器。

## 检查与交付边界

- 计划规则 8 项、状态检查 27 项通过，覆盖历史存储迁移、当日／本轮口径、临时额度、评分与撤销、客观题回答、跨日、空历史、牌组边界、暂停及草稿幂等。
- TypeScript 检查通过；构建与发布结果以同轮 GitHub 交付记录及 `.source-snapshot.json` 为准。
- 浏览器核对防剧透／牌库区别、12／10 口径、额外新卡与次日额度、客观题建议及刷新撤销、草稿编辑入组丢弃、编辑／反馈／暂停恢复、日期／断档／空状态／用时不足／未来到期、明暗与 390 像素布局，以及键盘与减少动效。

本轮不修改 `desktop/` 业务。真实 Windows／Android 的新增体验、触屏、实际评分与调度仍需独立实现及验收；#16 已交付基础不重做。#46 保持打开，不能用本原型的检查数量替代桌面完成。
